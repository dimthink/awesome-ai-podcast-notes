# ChatGPT 全面焕新：Dev Day 20 项重大更新深度解析

你可能已经听说了，OpenAI 在 Dev Day 上发布了 **20 项新更新**。这将彻底改变我们使用 Codex、ChatGPT 以及 AI 的方式。坦白说，他们这次发布的内容非常多。

他们推出了一个名为 **Dot** 的全新智能体平台，你可以与它通话数小时，它可以帮你处理各种事务，并且直接集成在 ChatGPT 桌面应用、iOS 应用和网页应用中。OpenAI 还发布了一款全新的模型，性能几乎媲美 Astra，但成本仅为后者的**五分之一**。此外，他们还推出了新的快速模式，使代码生成速度提升 **8 倍**，更有海量其他更新。在本视频中，我将逐一解析全部 20 项更新及其重要性。

## 一、Dot：你的专属个人 AI 智能体

### 1. 全新智能体平台 Dot

首先需要了解的 ChatGPT 应用更新，是他们的新智能体平台 **Dot**。

打开电脑上的 ChatGPT 应用，你会发现界面有些不同——下方出现了不同的模型选项，侧边栏也完全改变，新增了大量功能。

首先要介绍的就是 **Dot**。你可以把 Dot 理解为一个**具名的个人 AI 智能体**，它运行在自己的虚拟计算机上，并与你使用的所有工具相连接。你可以**给 Dot 打电话**、**通过 Slack 给 Dot 发消息**，甚至可以**给它发短信**。

正如你在这里看到的，我刚刚与我的 Dot——我给它取名为 **Bluey**——结束了一个小时的通话。如果你使用的是 ChatGPT 桌面应用但尚未设置 Dot，只需将鼠标悬停在主页图标上，选择“创建你的 Dot”（或界面会直接显示“你的 Dot”），点击后即可进行设置。设置过程中，它会要求你连接邮箱。

### 2. Dot 可以完全控制你的邮箱和日历

这是第二个需要了解的更新：**Dot 可以完全控制你的邮箱和日历**。

以下是我与 Bluey 的对话演示：

> 我：“嘿，Emily 刚才说了什么？我们买了什么打印机？她给我发了封邮件，我想知道我们可以用这台 3D 打印机做哪五样东西——要能真实生成的那种。帮我想一些提示词。”

然后 Bluey 就会去检查邮件，你可以看到它在查询 Emily 邮件中的打印机型号，然后给出五个可生成打印设计的提示词建议。在 Bluey 工作时，我们可以实时看到它的思考过程，还可以按暂停键暂停。每次它产生想法时，都会出现一个小灯泡图标。

它完成工作后，我切换到了一个新的聊天窗口——因为我想展示，当你悬停主页图标打开侧边栏时，可以看到 Bluey 有了一条新消息。点击进去就能看到它的处理结果。

Bluey 提取了 Emily 邮件的信息：你订购了一台 Bamboo Lab H2S AMS 组合——这是一台耗材 3D 打印机，还订购了一些其他配件。然后它给出了五个打印提示词。我回复它：“好的，我喜欢这些。请把这个整理到 Pages 里（这是个小剧透，我们稍后会讲到这个功能），设为公开，然后通过邮件发送给 Emily。”

完成后，Bluey 向我们展示了它的操作结果：创建了五个 Bamboo Lab H2S 的 3D 打印项目。我们可以直接点击查看，这就是它在 ChatGPT 全新的 Pages 功能中创建的文档（稍后会详细介绍）。然后它通过已连接的 Gmail 插件把邮件发送给了 Emily。

由于 Dot 可以使用你在 Codex 中配置的所有插件，连接邮箱和日历对于使用这个新智能体平台来说非常实用。

### 3. 直接给 Dot 打电话

第三个要了解的更新是：**你可以直接给 Dot 打电话**。

在 ChatGPT iOS 应用中，点击左上角按钮进入菜单，你就能看到你的 Dot。点击后，可以立刻拨打给 Dot。

以下是我与 Bluey 的通话演示：

> 我：“嘿，Bluey。我发给 Emily 的那封邮件发出去了吗？你能帮我查一下邮箱，看看我发给 Emily 的最后一封邮件是什么？”
>
> Bluey：“让我检查一下你的已发送邮件。稍等。”
>
> Bluey：“找到了。你今天下午 3:22（东部时间）发送的，就在已发送文件夹里。就是那封包含五个 Bamboo H2S 项目创意的邮件。”
>
> 我：“太棒了。你能不能在 Slack 上给 John 发一条消息，把同一份文档发给他？”
>
> Bluey：“好的，我现在就发给 John。Slack 上的 John 是 John Cam，这个页面是团队可见的。我会把提示词和页面链接一起放在 Slack 消息里。”
>
> 我：“好的，发送吧。”
>
> Bluey：“链接和前三个提示词已经发到他的私信了。正在发送最后两个提示词和打印建议。”
>
> 我：“太好了。我去 Slack 看看。”
>
> Bluey：“已完成。John 的私信里有链接、全部五个提示词和打印建议。”

看到了吗？因为我已将 Slack 插件连接到 ChatGPT 应用，我的 Dot 可以完全掌控我的 Slack，可以给团队里的 John 等人发消息——这真的非常酷。

但还有更酷的：**Dot 可以编辑 GPT Pages 中的文档**（稍后会介绍），你只需直接对它说话就行。我取消静音，让它做一些修改：

> 我：“嘿，Bluey。你知道吗，我们在那份文档里列出了所有内容。我想在‘简约桌面收纳盒’上方加一个表格，把不同的提示词列出来。”
>
> Bluey：“收到了。我会在第一节‘桌面收纳盒’上方添加该表格，完整提示词仍保留在下方。”
>
> 我：“好的，非常感谢。另外在表格下方加一句简短的话，让人们对下一部分内容产生期待。还有，把所有可复制的提示词改成像代码块那样的提示词格式，而不是纯文本。”
>
> Bluey：“好的，我来调整表格措辞和格式。”
>
> 我：“提示词格式要用在下面那些可复制的提示词上。”
>
> Bluey：“对，就是那些。”
>
> Bluey：“都改好了。我在表格下方加了一句引流语，并把五个可复制的提示词全部转换成了提示词代码块，方便直接复制。页面链接已在聊天中更新。”

看到了吗？它添加了这句话，然后把这些改成了提示词格式。这些提示词现在可以直接复制并运行。就这样，我可以通过 Bluey（我的 Dot 智能体）来编辑文档——这是 ChatGPT 应用内的一项全新功能。

### 4. 将 Dot 添加到 Slack

第四个新功能是：**你可以将 Dot 添加到 Slack 中**。

设置好 Dot 后，点击上方你的 Dot，就可以轻松添加 Slack 集成。添加完成后，你会看到这个界面。我可以直接点击“在 Slack 中打开”。在这里，我可以直接在 Slack 内给 Bluey（我的 Dot）发消息，它位于“智能体与应用”分类下。

例如我可以问：“嘿，能给我说说我的 Convex 视频的最新进展吗？”这和在 ChatGPT 桌面应用、网页应用或 iOS 应用里发消息基本一样，只不过是通过 Slack。

这里显示有一条未读回复。我点开它，Bluey 回复说“我会检查最新的 Convex 消息和审批状态”，它还在处理中。然后它就根据我的邮件和其他 Slack 内容给出了回复，并附上了所有完整链接。比如我点击视频链接，会直接跳转到我在 Slack 中发送视频的脚本位置。所以它对 Slack、邮件和一切都有完整的上下文理解。

不仅如此，我还可以进入频道——比如这个 Riley Emily 频道——点击所有成员，直接搜索 Bluey，就能把 Bluey 添加到这个频道中。现在 Emily、我和团队其他人就都可以给 Bluey 发消息了。我可以 @Bluey 说：“请给 Emily 和我列出最重要的下一步行动。”然后就能看到它的回复，展开后能看到它列出的事项摘要。

### 5. 即将支持通过 iMessage 给 Dot 发消息

第五个更新：你将可以给 Dot 发 iMessage。这项功能其实还**尚未正式上线**，但不久的将来你就可以发送 iMessage 给 Dot。

这意味着，这个拥有所有插件权限、拥有自己虚拟计算机的智能体，不仅可以放进 Slack、在 ChatGPT 应用内直接呼叫，还可以添加到你的 iMessage 中。

### 6. Dot 拥有专属的计算机和浏览器

第六个也是最后一个关于 Dot 的核心更新：**Dot 拥有一台计算机和浏览器**。

还记得我提到过可以点击 Bluey 打开侧边菜单吗？你也可以点击这个按钮来打开详情面板。在这里，点击 Bluey 的计算机，你会发现这是一台**真实的计算机**。我可以点击、拖拽，使用这台虚拟计算机。这是一台运行在云端的真实计算机，我可以使用，Bluey 也可以使用。

这对于许多场景非常有用，比如填写表单、检查你正在开发的网站是否能正常工作，或处理任何涉及计算机的事务——而计算机几乎涉及一切事务。

OpenAI 真正想做的，是创建一个**虚拟员工**、一个**有名字的虚拟助手**。它是一个具名的个人智能体，基本可以做任何人类虚拟助理能做的事情——这就是为什么它需要一台计算机。

以上就是 Dot 的基本介绍，涵盖了 Dev Day 的前六项更新。

## 二、新模型与速度革命

### 7. 全新模型 6.1 Soul

现在进入第七项更新：**新模型 6.1 Soul**。

我之前提到过，无论在手机、桌面还是网页端的 ChatGPT 应用中，你都会看到一个新模型 **GPT 6.1 Soul**。我初步体验下来，这个模型表现相当不错——它是一款扎实的模型，给人一种前沿模型的感觉，而且价格比 Astra 便宜得多。

对比一下输入和输出 token 的成本：

- **GPT 6 Astra**（之前引爆全网、备受追捧的智能模型）：输入 **$10/百万 token**，输出 **$50/百万 token**，合计 **$60**。
- **6.1 Soul**：输入 **$2/百万 token**，输出 **$10/百万 token**。

所以，使用这个模型的成本便宜了 **5 倍**。OpenAI 对这个模型的定位是：**低成本、面向编码和计算机使用**，是一个“务实的多面手”。就我目前的感受而言，确实如此。

### 8. 全新的 Ultra Fast 模式

第八项更新是全新的 **Ultra Fast 模式**。

这个新模式在输出 token 方面速度提升了 **8 倍**——在 Codex 中生成代码或任何输出内容时，速度大约提升 8 倍。这是惊人的速度飞跃。

不过我认为这项功能主要面向企业用户使用，因为它只在 OpenAI 新推出的 **$500/月套餐**（Pro 500）中提供。目前唯一能使用 Ultra Fast 模式的途径就是这个 $500 月费套餐。

如果你订阅了 $500/月套餐，打开设置可以看到：

- **Fast 模式**：消耗更多使用额度，速度提升 1.5 倍。
- **Ultra Fast 模式**：图标上有三个闪电标识。使用 Ultra Fast 消耗的额度是普通模式的 **6 倍**，但速度大约是 **8 倍**。

如果你尝试在 Blender 中创建东西、制作游戏或进行其他视觉化工作，甚至只是使用 Excel，它的运行速度快得惊人。它能以近乎实时的速度完成这些高智能任务，这种体验真的令人叹为观止。我见过很多很酷的演示，只是我个人还没准备好每个月为 AI 套餐花 $500。

## 三、GPT Space：全新工作空间

### 9. GPT Space——最被低估的更新

第十项更新我认为是**最重磅也最被低估**的：**GPT Space**。

OpenAI 发布了一个新空间，让你和你的智能体可以在其中**创建并协作处理内容**，你可以创建**Pages（页面）、演示文稿和站点**。

其实你在使用 Bluey 创建文档时已经瞥见过这个功能了。在 ChatGPT 中进入 Space，点击 Pages——这就像一个**Notion 风格的完整笔记应用**。

你可以创建页面。比如我新建一个页面，输入“新的 GPT Pages 能做什么？”，底部会出现一个聊天窗口。我可以直接给智能体发消息：

> “我正在写关于 GPT Pages 新功能的文章。请帮我写出它能做什么，但要用不同的方式展示，比如代码块、标注框等等。请直接在页面上写下来，开头用四个 mermaid 图表来说明 Pages 是什么以及能做什么。”

可以看到它还在运行，但已经直接在文档中添加了这些 mermaid 图表。这非常类似 Notion——你可以创建不同的内容块。

- 这里可以写文本，还可以设置标题
- 可以做删除线
- 可以创建标注框
- 可以做列表和任务清单
- 可以有可复制的文本内容
- 可以创建表格和更多内容

这就是所谓的**提示词格式（Prompt Formatting）**。让我展示一下具体用法——你只需输入“提示词”，就会出现这种提示词格式的示例，比如“请制作一个图表”。点击这些示例，它会自动填入对应提示词。

此外这里还有一些交互式图表。你可以让 AI 直接创建这些图表。如果你想生成这些可视化内容，可以点击上方的“可视化”按钮，然后描述你想要的可视化形式，比如“Pages 中最常用功能的饼图”。

看，它完成了！我们可以在这里接受更改，然后页面上就出现了一个交互式饼图——直接在 Pages 内部实现。这个文档编辑器直接内置在 ChatGPT 里，实在太强大了。

现在打开侧边菜单，我们还可以看到子页面。我可以轻松添加一个子页面，命名为“调研”。然后我可以找到 Bluey 说：

> “嘿，这里有个新文档，叫‘调研’子页面。请帮我比较一下 GPT Space 和 Notion，要用表格和图表来展示。”

我把这个任务交给 Bluey 后，就能看到 Bluey 的工作过程——它正在子页面中创建内容，包括表格和图表。完成后它就完成了与 Notion 的对比。

我们可以把 **Space 理解为 Google Drive**。GPT Space 里，除了刚才创建的 Pages，还有我们之前视频中聊过的**站点（Sites）**，以及**图片（Images）**——这里存放了我们在 Codex 中创建的所有图片。还有一个集成的 **Google Drive** 入口，你可以直接在 GPT Space 中查看和控制 Google Drive。

文档完成后，点“分享”就能轻松分享给团队任何人，复制链接即可发送。你甚至可以让 AI 帮你发送——我可以说“嘿，把这个发给 Emily”，它就会通过邮件把链接发过去。

## 四、ChatGPT 集成与生态扩展

### 10. 在 Slack 中使用 ChatGPT

接下来的更新演示成分较少，我会讲得快一些。第十一项更新：**ChatGPT 可直接在 Slack 中使用**。

我们之前讲了添加 Dot 到 Slack，同样你也可以直接添加 ChatGPT 到 Slack。

让我演示一下如何在 ChatGPT 网页应用中操作。进入工作区设置，找到“智能体”，点击进入。在 GPT Agent 区域，你可以创建新智能体，也可以添加 Slack 智能体——我已经添加了一个，这就是 ChatGPT 智能体。

添加到 Slack 后，我就可以直接给 ChatGPT 发消息，可以给它配置插件和任何访问权限。而且你可以**控制模型**——Dot 无法选择使用哪个模型，但 ChatGPT 智能体可以。我点击这个设置，可以看到这里对智能体有更多的控制选项：

- 可以限制为仅特定频道
- 可以修改模型（当前是 6 Astra，可以改为 6.1 Soul 以节省 token）

和 Dot 一样，我可以进入任何频道——比如进入我们的 packaging 频道，把 ChatGPT 直接添加到这个频道里，然后直接在 Slack 里和 ChatGPT 对话，给它配插件和技能。

### 11. 全新的会议插件

第十二项更新是新的 **会议（Meetings）插件**。

这个插件目前**还没有正式推出**，但它将是一个内置在 ChatGPT 中的 AI 会议记录工具。我推测它将集成在 GPT Space 中，并有一个专门的 Meeting 标签页——这一点大家听听就好，别引用我，但我相当确定会是这样的方向。

当会议开始时，如果你打开了 ChatGPT 应用，它会**自动开始录音**，然后直接把记录保存在 ChatGPT Space 中。之后你可以就会议内容提问，并自动采取后续行动。你还可以设置一个日常流程：自动回顾所有会议记录、自动执行任务，或提醒你处理会议中提到的所有事项。

### 12. 插件扩展（Plug-in Extensions）——真正的 Agent Native 应用

下一项更新在我看来是被严重低估的，而且非常酷：**插件扩展**——它相当于 ChatGPT 应用内的 **App**，一种真正的 **Agent Native（智能体原生）** 应用。

之前确实已经有插件了，你可以添加 Figma 插件等，在上方可以看到所有已创建的插件。但现在更进一步了——这些插件扩展可以被视为 ChatGPT 中的应用。

举个例子：我有个应用叫 **Magic Path**，我把它添加为插件。但如果一个应用支持插件扩展，点击右上角的三个点，就能看到它。在这个界面中，Figma 和 Magic Path 是扩展应用，其余的是 ChatGPT 内置功能。

点击 Magic Path，这个应用**直接构建在 ChatGPT 之中**，它可以与 ChatGPT 通信。让我演示一下：

> “我想设计一个看起来很酷的落地页，风格类似 agentnative.inc，但内容是一个所有最酷工具的数据库。”

你注意到刚才发生了什么吗？我在 Magic Path 中按了回车——这个应用是由别人、另一家公司开发的——但当我按下回车，它直接进入了 ChatGPT 应用，**消耗的是我的 ChatGPT token**。它在这里用浏览器查看了 agent native 的网站样式，然后在 Magic Path 应用中创建了设计。Figma 也可以做同样的事。

这就是一个基本上内置在 ChatGPT 中的应用，是已有插件体系的延伸。看看 Magic Path CEO Petro Kirano 发的帖子：

> “停下你手头的事，去为 ChatGPT 构建插件扩展吧！自公告发布以来，我们增长了超过 2000%。如果你是产品构建者，这是一个巨大的机会——让你的产品触达更多用户，前提是把它做成完全 Agent Native，或直接集成在 ChatGPT 桌面应用中。”

### 13. 使用 ChatGPT 账号登录（Sign in with ChatGPT）

这引出了第十四项更新：**使用 ChatGPT 登录（Sign in with ChatGPT）**。

这和前一项很相似。现在你可以非常轻松地为任何你构建的应用添加“使用 ChatGPT 登录”功能。未来更多应用将支持你用 ChatGPT 账号登录，并且你可以在登录的应用中使用 ChatGPT 账户内的额度或 API 额度。

这个例子展示的是 **Devon**——你通过 ChatGPT 登录的应用。登录后，你可以使用 ChatGPT 的额度。比如你订阅了 $200/月的 Pro 套餐，就可以在登录的应用（如 Devon）中使用该账户的额度。

OpenAI 正在让开发者更容易构建支持这种登录方式的应用。例如，如果你想构建一个 vibe coding 平台，你可以让人们用 ChatGPT 账号登录，而不需要自己构建智能体——用户可以直接在你的应用中使用他们的 ChatGPT 额度。

这对应用开发者来说将会非常有趣，我会在后续视频中详细讨论。

## 五、Codex 的全面进化

接下来的四项更新都与 Codex 相关，我们一起来看。

### 14. Codex CLI 大幅改进

### 15. Codex Cloud——无需本地运行

第二项也是最大的一项：**Codex Cloud** 的改进与发布。这意味着你在使用 Codex 时**不需要保持电脑开机运行**。

通常我做几乎任何任务，尤其是编码任务时，都会使用 Codex。在新建聊天时，你可以选择使用 ChatGPT（包含聊天和工作区功能），或使用 Codex。

为什么有些人会专门配置一台 Mac mini 来处理编码任务？因为如果你想做编码工作，你需要一台计算机来运行。通常是在本地执行的——至少我是这样——我会用自己的电脑。我现在同时在开发两个应用：一个是 Agent Native 落地页及其内部应用，另一个是几周后即将开源的 App。

现在，他们推出的新功能叫 **Cloud**，并且把它做得更强大、更好用。打开 iOS 应用，你会看到这个云朵图标。它允许你设置一个**环境**——本质上是一台配置好特定开发环境的计算机。你可以在第一次设置好 Clerk、Convex、Vercel、GitHub 等所有登录信息，之后就可以在任务中**重复使用这个环境**。这让云端编码任务变得异常简单。

## 六、面向开发者的全新 API

### 18. Decisions API——Jeeves 的竞争对手

第十九项是 **Decisions API**——这是 Jeeves 的竞争对手。

Decisions API 的工作方式与传统 LLM 不同。传统模式下，比如我在 Codex 里输入内容、按回车，它就会输出结果。但 Decisions API **不是这样工作的**。

它接收固定数量的输入 token——比如“新收到的客户邮件”——然后**做出非常快速的智能决策**。它只训练用于在给定选项中做出选择。比如判断这封邮件应该转给销售、账单部门还是技术支持。因此它非常适合对公司内部发生的大量事务进行分类。

你可以让它分析每一封邮件、分类并判断紧急程度。它在基于特定输入做出快速决策方面非常出色，**且没有输出 token**。等这个 API 发布后，我可能会做一期完整视频来讲解——记得订阅，别错过。

### 19. Cloud Computer Use 与 Agents API

终于来到今天的最后一项更新，它是一对组合：**Cloud Computer Use（云端计算机使用）和 Agents API（智能体 API）**。

OpenAI 在这次活动中最重要的目标之一，是让任何人都能轻松构建使用 **Codex 智能体**的应用。他们在让 Codex 智能体变得更强大上做了很多工作：模型与 Codex 配合得很好，智能体也拥有非常出色的计算机使用能力。现在，他们希望你能用 **Agents API** 创建自己的应用。

**Agents API** 是 OpenAI 的开发者服务，用于在你的产品中运行他们的智能体。你可以构建 agentic（智能体驱动）应用。以前这样做需要一大堆不同的 API 密钥，现在只需要一个平台项目和一组 API 密钥。

如果你一直看我视频的话会知道，用 OpenAI API 密钥就能做一个 AI wrapper（ChatGPT 包装器）。现在，你可以做一个 **Codex wrapper**——也就是 agentic 应用。不仅如此，你创建的智能体还可以使用**计算机操作**，你可以在自己的应用中构建由 Codex 驱动的、能够使用 OpenAI 托管浏览器进行计算机操作的智能体。

这就像你的 Dot 有这台计算机可供使用一样——现在你可以轻松创建自己的应用，让你构建的任何东西都能访问类似的浏览器。我觉得这太棒了。

我很快就会有更多有趣的项目用到这个 API，不过那会是个更长的视频。我会在视频描述中放上 Agents API 的链接。如果你想真正构建一个 agentic 应用，或者就像我——我想做一个充当智能体的小型硬件设备，这将会是最酷的视频和项目，我超级期待——建议你读一读那个文档，真的很有意思。
