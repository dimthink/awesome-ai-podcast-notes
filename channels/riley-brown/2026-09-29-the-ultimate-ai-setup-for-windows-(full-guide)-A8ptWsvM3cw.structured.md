## 工具一：Raycast —— 启动器 / App 切换器 / 剪贴板管理器

我会在 Windows 电脑上首先下载 **Raycast**。

按 `Alt+Space` 即可打开 Raycast；从这里可以打开所有其他工具。例如：

- 输入 `ChatGPT` 并回车，即可打开 ChatGPT。
- 按 `Alt+Space`，输入 `Grockbot`，即可打开 Grockbot。

这是在我所有不同应用程序之间切换的最快方式。

**作为 App 切换器**

按 `Alt+Space`，输入 `Chrome`，就能快速打开 Chrome。但你也可以让打开 App 变得更简单：

- 连按两次 `Alt`（`Alt+Alt`），会自动打开 ChatGPT。
- 这个功能是在 Raycast 里配置的：按 `Alt+Space` 打开 Raycast，输入 `shortcuts` 并回车。
- 在这里，你可以录制一个热键，用来打开电脑上的任何 App。
- 我把 ChatGPT 的热键设置为 `Alt+Alt`。

想为 Claude（Anthropic 的 AI 助手）创建热键，只需点击 `record hotkey`，然后按 `Windows+C`。之后按 `Windows+C` 就会自动打开 Claude。

**作为剪贴板管理器**

Raycast 内置剪贴板管理器。按 `Alt+M`，就能看到所有保存到剪贴板的文字。这个功能特别适合搭配 ChatGPT 或任何 AI 工具：我经常复制内容，之后要用。如果复制了任何文字，再按 `Alt+M`，就会看到文字自动保存到剪贴板；按 `Enter` 即可粘贴到当前光标位置。

设置方法：

1. 按 `Alt+Space` 打开 Raycast。
2. 输入 `clipboard history`。
3. 右键点击，选择 `configure command`。
4. 打开 `command settings`。
5. 设置热键为 `Alt+M`。

之后按 `Alt+M` 就能打开剪贴板历史。这里可以按类型查看：

- `text only`：只看文字
- 图片
- 文件
- 链接

## 工具二：ChatGPT 桌面应用 + Codex

第二个要下载的是 **ChatGPT 桌面应用**。主要原因是我最喜欢的 Codex 功能——它独立成为一个 App 也不为过。

- 我刚刚发布了一期 2 小时的 Codex 视频，如果你想了解 Codex 的 28 个最佳使用场景。
- 我喜欢这个 App 的原因是：它几乎可以在电脑上做任何事情。
- 可以使用 **GPT-6 Astra**，也就是他所说的“世界上最好的模型”。
- 你不必频繁使用 Extra High 模式。
- 它可以创建任何 App、创建任何类型的演示文稿，并完全控制电脑。

**第一步：连接插件**

使用 Codex 时，第一件事是进入 `Plugins` 标签页，连接你正在使用的所有现有工具。

例如，输入 `Notion` 并点击 `install`，就能把 Codex 连接到 Notion：

- ChatGPT 桌面应用因此可以完全控制 Notion。
- 点击 `try now` 可以搜索所有内容、更新页面、上传照片。
- 任何你手动能在 Notion 里做的事，现在 Codex 也都能做。

**计算机控制（computer use）**

另一个很酷的功能是 `Computer`。你可以使用计算机控制功能执行这样的指令：

> 请在画图（Paint）里制作一张关于 AI 初创公司营收增长的图表。

然后运行它。这就是让 Codex 完全控制电脑并使用 computer use 的方式。

另外，很快我会展示如何用手机连接并控制这台笔记本，前提是你在 iPhone 或 Android 上安装了 ChatGPT 应用。

**设置 ChatGPT 热键**

装好后的第一件事：

1. 按 `Alt+Space`，找到 ChatGPT。
2. 右键点击，进入 `configure command`。
3. 打开 `command settings`，把启动热键改为 `Alt+Alt`。

现在双击 `Alt` 会打开 Codex，而 Raycast 可以调出我最常用的 ChatGPT 桌面应用。

## 工具三：Whisper Flow —— 语音转文字工具

第三个工具是 **Whisper Flow**。

正如我前面所说，我整天都在使用 AI 工具。实际上，我在这些提示词输入框里打字的时间，比在任何其他文档里都多。我是一个很喜欢说话的人（yapper），不喜欢打字，所以我使用 Whisper Flow。

第一次下载 Whisper Flow 后，你可以使用 `Ctrl+Windows` 键进行语音转文字。例如：

> 你好。我需要你做一些关于 Whisper Flow 的研究。我想让你找出它多少钱，以及下载网址。请现在就去查。忽略我们之前正在做的任何任务。

然后回车发送。这是在任何电脑上打字的最佳方式。

- Whisper Flow 同时支持 Mac 和 Windows。
- 我在所有 Windows 电脑上都会使用它。
- 免费版包含每周 **2,000 词**。
- Pro 版价格为每月 **15 美元**，我相信我订阅的就是这个方案。

**免费替代方案：Handy**

还有一个免费替代方案，有人告诉我它最适合 Windows，就是 **Handy（handy.computer）**。

- Handy 的默认控制键略有不同，是 `Ctrl+Space`。
- 例如：`Ctrl+Space`，然后说：“你好，呃，能请你告诉我更多关于 Handy 的信息以及它是怎么工作的吗？”
- Handy 是免费的，运行一个非常非常非常便宜的模型。
- 我认为它是在我电脑本地运行的，或者至少你可以选择在本地运行的版本。
- 它免费且开源，是一个非常不错的免费选项。
- 但在我看来，它的格式排版效果比 Whisper Flow 稍差一些。

## 工具四：Google Chrome + ChatGPT 扩展

第四个工具是 **Google Chrome**，特别是配合 **ChatGPT Chrome 扩展**一起使用。

- 打开后可以看到一个侧边栏。
- 可以点击退出按钮，也可以点击 ChatGPT 图标重新打开。
- 可以直接在 Chrome 内部使用之前展示过的 ChatGPT 应用。
- 所有聊天记录都会完美同步。

例如，刚才创建的聊天记录，2 分钟后就会出现在侧边栏里。我可以点开一篇新闻文章，然后说：

> 嘿，我需要你再跟我讲讲这个内容。

这样我甚至不需要复制粘贴任何东西，ChatGPT 就直接在 Chrome 里工作。

更重要的是，ChatGPT 对你在 Chrome 里正在看的内容有完整上下文，所以它能提供非常相关的信息。我甚至可以这样说：

> 嘿，你能完全重建这个网站吗？

它其实是可以做到的，因为这基本上就是在和 Codex 对话。不过我这次得到的是侧边栏里一份高质量的研究报告，由世界上最好的模型 GPT-6 Astra 驱动。我们会看到更多信息，把 ChatGPT 直接放在侧边窗口里真的非常有用。

## 工具五：Grockbot —— 创建你的 AI 智能体团队

**Grockbot** 已经成为我最喜欢的个人智能体平台之一。

Grockbot 可以让你创建一支智能体团队。例如：

由于 Grockbot 已经连接了我所有工具，就像 ChatGPT 一样，它能够检查我所有不同的工具，并给我关于业务中一切事项的最新答案。

1. 按 `Alt+Space`，找到 Grockbot。

## 工具六：Claude 扩展 —— 在 Excel 里创建专业表格

下一个工具是 **Claude 扩展 for Excel**。

如果你已经有 Claude 订阅，可以非常轻松地把 Claude 添加到 Excel 中。Claude 模型运行在 Windows 电脑上的这个扩展里，是创建电子表格的最佳方式。无论因为什么原因，Windows 版 Excel 的表现总比 Mac 上好得多，所以我非常推荐。

- 可以直接使用 **Opus**。
- **Opus 5** 非常好用。
- 你也可以使用 **Fable**，但它更贵、更慢，所以我推荐 Opus 5。

例如，我可以直接说：

> 嘿，我想让你现在就为一个业务编造一些假数据，然后制作一个非常出色的电子表格，要非常可视化、非常专业。你可以自己设想一个场景，让数据以有趣的方式讲一个故事，展示数字，并做一个仪表盘。

运行提示词后，它会真的列出自己的步骤：创建表格结构、构建月度数据引擎，等等。

最棒的是，在 Claude 帮我做所有工作时，我可以去倒杯水喝。等我回来，它已经生成了一个非常专业的演示级表格。Claude 对 Excel 的掌握能力真的不可思议。如果你工作里要用 Excel，一定要下载这个扩展。

- 当然，这份表格还可以改进，例如把日期改成更简短的格式。
- 但除此之外，这些图表做得实在太漂亮了。
- 而且它还在继续运行，会一直检查、一直优化，这就是现在的 AI 模型在做的事。
- 所以，这就是你成为 Excel 高手的方式。
- 如果你想关闭它，只需点击右上角的 `X`。

## 工具七：Notion —— 与 AI 协作的知识库

第七个工具是 **Notion**。

我很喜欢使用 Notion，尤其是配合我们已经下载的 AI 工具一起使用。

- 按 `Alt+Alt` 调出 ChatGPT。
- 我可以对它说：请在 Notion 的 Key Docs 中创建一个关于这个内容的新文档。
- 并在指令中 `@` 提及 Notion。
- 运行后，打开 Notion 并进入 Key Docs，就会看到它添加了一个新页面。

ChatGPT 刚刚创建了这份 Notion 文档。我认为无论你使用 Windows 还是 Mac，都应该使用 Notion，原因是 AI 真的很擅长使用 Notion：

- AI 使用 Notion 的效果比使用 Google Docs 更好。
- 也比使用 ClickUp 更好。
- 因为 Notion 特意让自己的工具很适合被 AI 控制。
- 他们设置了最好的 **MCP（模型上下文协议）** 和工具，让你可以非常简单地把它接入 Codex，并让它创建内容。

我也可以回到 ChatGPT，按 `Ctrl+Space` 说：

> 我想让你使用内置的 tabs 功能来跟我说这个内容，而不是把它写成一篇小文章。然后，把关键词用红色标出来，并加粗。

运行这个提示词后，回到 Notion，等 ChatGPT 做修改。结果它把整个文档改成了 tabs 视图。

Notion 有非常多不同类型的块，tabs 就是其中之一。你可以按 `/tabs` 调出来。

- 我最常用的就是这个 tabs 格式。
- 我可以手动更改 tab 名称，AI 也可以非常轻松地完成。
- 只需要提出要求，它就能在文档顶部创建出这样一个小小的“幻灯片式”页面。
- 由此可见，AI 真的很擅长控制 Notion。

## 工具八：用手机远程控制 ChatGPT 桌面应用

第八个也是最后一个需要掌握的“桌面工具”，其实是在你的手机上。

无论你用的是 Android 还是 iPhone，都可以用手机控制 ChatGPT 桌面应用。

设置方法：

1. 打开 ChatGPT 桌面应用。
2. 点击个人资料，进入 `Settings`。
3. 输入 `remote`。
4. 点击 `Remote`。
5. 选择 `Control this PC`。
6. 点击 `Add`，选择连接到手机。
7. 用手机扫描二维码。

之后，手机端就会显示远程控制界面。我可以进入之前创建的任何一个对话，比如：

> 创建一个 AI 初创公司营收图表。

它已经更新了 Notion 文档。我还可以继续说：

> 太棒了。干得好。能不能请你在我的电脑上打开这个？不过在打开之前，先在最下面用橙色加上几段文字？

我把这些内容输入到 ChatGPT Remote 中，就可以从手机控制 ChatGPT 桌面应用。这对 Codex 来说至关重要。

如果我把电脑一直开着（这很容易设置），我就可以直接从手机使用 ChatGPT 桌面应用。此时它会：

1. 添加一些摘要段落。
2. 然后在电脑上打开 Notion。

因为 Codex 可以完全控制电脑，而 Remote 功能又让你完全控制 ChatGPT 桌面应用。我甚至可以要求：

> 我想让你在我的电脑上打开真正的 Notion 应用，而不是浏览器版本。

它就会使用 Codex 的 computer use 功能把 Notion 应用带到前台。并且可以看到，它已经在文档底部添加了这些段落。这种完全控制电脑的能力非常强大。
