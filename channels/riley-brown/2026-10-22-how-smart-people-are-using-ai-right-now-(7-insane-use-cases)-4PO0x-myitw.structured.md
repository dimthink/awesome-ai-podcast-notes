# 聪明人现在如何用 AI：7 个疯狂用例——用 AI 删除 Slop

每个人都在说，AI 正在让互联网充斥垃圾内容（slop）。然而，当我观察高能动性（high agency）的人正在用 AI 做什么时，我看到的恰恰相反。他们在用 AI 删除 slop，这让他们能拥有更多乐趣、变得更高产，并赚到更多钱。这一切都是因为他们用 AI 来移除 slop。而我实际上有七个例子。

## 第一种方式：你可以 vibe code 你自己的电视软件

所以，AI 真正移除 slop 的第一种方式是，你其实可以 vibe code（氛围编程，即用自然语言让 AI 写代码）你自己的电视软件。让我解释一下。

这个人最初是用葡萄牙语发的推文。他发推说：“我用 Claude 给我的电视做了 vibe code。所有预装的臃肿软件和广告都被移除了。除此之外，我还重建了它的操作系统，并做了一个受 Apple TV 启发的干净设计。RAM 使用量减少了 70%，界面速度快了 3 倍。”就在这个时刻，我意识到可能有一种叙事违规正在流传。AI 实际上正在移除人类制造的 slop。我不知道你有没有智能电视，但它用起来真的太烦人了。这是另一个人移除所有 slop、所有广告、所有在这台电视上做出的糟糕用户界面决策的例子。他为自己 vibe code 了一个版本。现在他有了一个容易得多的电视界面，可以随时用它看自己的节目、看 YouTube 等等。而且这不仅仅是一个人。这个人说：“今天下午给我父母的电视做了 vibe code。它甚至在你进入 Netflix 之前就会先显示赞助广告。”我把型号给了 Claude Code。它在 Wi-Fi 上找到了电视，移除了 25 个小米软件包，并写了一个新的启动器。现在它看起来像 Apple TV。然后这个人甚至为他的电视做了一个语音控制器 >> 反复发现那句话 >> Destin Farmers 是天才。所以我把车停在外面 >> 它就切换到 Netflix，并立刻开始播放《怪奇物语》。关于这一点非常有趣的是，这些电视实际上是亏本或以极低利润出售的。你知道，80 英寸电视的价格在过去 10 年里大幅下降。而这些电视经常亏本或利润极低出售。这是因为它们用大量广告轰炸你，并从你那里收集大量数据。它们就是这样赚钱的。它们在后端赚钱。它们把硬件便宜卖给你，然后通过广告和收集数据赚钱。你几乎可以说，这种商业模式，对吧，这整个商业模式就是为 slop 而生的。我们会给你这个硬件设备，按成本价来说它是个相当不错的设备，只不过我们会一直给你喂 slop，直到你死。而疯狂的是，人们把 Claude 接入这些电视，然后直接为电视构建自己的定制软件。这实际上会成为本期视频剩余部分的一个巨大主题：你拿像电视这样的东西，它拥有所有这些不同功能，然后你挑选你想要的那一小部分功能，并用 AI 只保留那一小部分功能，对吧？我只想访问 Netflix、Hulu、YouTube 和另外几个功能。我要 vibe code 一个解决方案，把所有其他东西，也就是所谓的 slop，全部去掉。

## 第二种方式：把第一点应用到家里的任何设备

AI 移除 slop 的第二种方式是，你可以把我们在第一点里谈到的内容应用到你家中的任何设备。基本上，你拥有的任何设备都可以被越狱，你可以移除 slop。Adrian 是这么说的。他说：“这太疯狂了。我用 USB 连接了 Kindle，然后让 Claude Code 越狱了 Kindle。我移除了所有亚马逊臃肿软件，并添加了 Tailscale。”为了理解为什么这么做，这个叫 Brandon 的人说：“一开始我想，为什么要这样？”然后我又想：“因为你可以。”但这其实很实用，因为 Adrian 说：“任何时候我想稍后读点东西，我就用 Reed Deck 保存文章，然后它会下载并与我的家庭服务器同步。当我的 Kindle 同步时，我就能在 Kindle 上拿到它。”所以，他可以把他在互联网上读到的任何东西保存到这台 Kindle 上。因为他越狱了它，他基本上可以对这台电子阅读器做任何他想做的事。显然，要学会怎么做，有一个叫 kindlemoddding.com 的网站，或者更准确地说是 .org，你可以弄清楚如何越狱你的 Kindle。所以，这和智能电视的情况非常相似，只是有点不同，因为他还添加了额外功能。所以，他不仅保留了他喜欢的所有 Kindle 功能，并挑选了他想保留的少数功能，他还添加了额外功能，因为他完全越狱了它，添加了 Tailscale，他基本上可以给自己的 Kindle 添加任何功能，或者至少成千上万的潜在功能。当然，这不仅仅是因为 AI，对吧？这些以前也全都可能。但既然 Claude Code 写代码比几乎任何开发者都好，这意味着任何人都可以越狱它。据我所知，如果你有一根 USB-C，如果你有一根 USB-C 线插到你的电脑和 Kindle 上，你现在就可以直接越狱它，并且可以用 AI 添加任何功能。就像你可以去 Lovable vibe code 一个 app 一样，你现在也可以用 Claude Code 在 Kindle 上 vibe code 一个 app，这相当疯狂。然后我也在我的 Mod Retro 上这么做了。这个在我 Instagram 上，如果你想看的话可以去看。我基本上把 Muse，这个 Meta 的 AI agent，添加到了这个 Mod Retro 上，结果很棒，对吧？我添加了这个，呃，我越狱了它，或者我把它插到我的电脑上，然后我告诉 Codeex 创建一个新版本的 app，让我可以和 Muse 聊天，这太疯狂了。这是一个 AI agent。现在，一台 Game Boy 被变成了一个 AI agent，所以这太棒了。

## 第四种方式：让 AI 成为你信息流的过滤器

AI 移除 slop 的第四种方式是，它实际上可以充当你的信息流的 AI 过滤器。让我解释一下。这是 Nick Dobos，我最喜欢在 Twitter 上关注的人之一。信息饮食因为 AI 完全改变了。我不再读我的电子邮件了。那是 AI 的工作，为我过滤并通知我。我的 agent 已经清理了 99% 的邮件之后，我每周做一次收件箱清零扫荡。这增加了电子邮件的价值。现在我真的会注册更多电子邮件通知，而我以前会避免这样做，因为那极其浪费时间。例如，我现在会选择接收电子邮件收据，这样我的 Postmaster 邮件机器人就可以把它们转发给我的小饰品购物机器人和我的膳食规划机器人。现在我在最喜欢的咖啡店刷我的卡，它就会被自动记录到我的饮食里。好吧，这一部分我觉得有点过度优化，但第一部分基本上是在讲用 AI 作为过滤器。所以，让我们现在过两个例子，你可以在任何 AI agent 上用不到 2 分钟做到。Nick 讲的是，他的收件箱里塞满了大量邮件。以前，呃，他害怕 slop，对吧？因为如果他必须打开他的邮件 app，而我实际上用 Superhuman 做这件事，我会手动浏览并过滤掉大部分邮件，其中一些会被自动分类到垃圾邮件，但有时我确实需要进去检查那些，因为有些其实还挺重要。AI agents 变得越来越聪明，而且它们拥有关于你的完整上下文，所以它们实际上知道什么对你重要。所以你现在的确可以去 Claude，连接你的 Gmail，这只需要 30 秒，然后说：“嘿 Claude，你能不能把我过去两周的所有邮件过一遍，把明显是垃圾邮件的那些归档？”然后你可以加上类似“基于我的目标”。你还可以进一步指定哪些是空白。但如果你使用的是常驻 agent，比如你可能用 Grockbot，可能用 GBT dots 或 Meta Muse，这些 agents 正变得非常擅长理解什么对你重要。而一个独立的邮件 app 实际上不会知道什么对你重要。所以对它们来说过滤更难。而如果你使用一个了解你的 AI agent，它会更好地理解该过滤掉什么。所以，Nick Dobos 在这里说的是，他实际上，在这件事里，它增加了电子邮件的价值。所以他现在实际上更愿意增加进入他收件箱的邮件量，因为他知道他的 AI agent 会把它们送到正确的地方，并过滤掉所有 slop。所以这是另一个清除电子邮件 slop 的例子。而且我认为这是你应该做的事情。再说一次，这需要能动性。你实际上必须设置它。它不会为你设置好。而且这不仅仅是电子邮件。这基本上适用于互联网上的一切。最近我最喜欢的一个是，我花更少时间看 Twitter 上的 slop，我花更多时间让我的 AI agent 搜索 Twitter，并在 Grockbot 上把相关的东西展示给我。现在它们实际上内置了 Twitter。所以，我可以这样说：我最近对 AI 如何编辑视频很感兴趣。我想让你找到可信的人，不是那种像骗子一样试图引用转发（quote tweet）自己文章的人。我想让你找到那些以有趣方式拆解它的人，然后给我一份所有这些不同人的列表。所以，我可以把这个提示词丢给 Grock。而且它内置了 Twitter。所以你不需要给它 API 密钥。这不是，这是包含在你的 Grockbot 订阅里的，它可以为你搜索 Twitter。这意味着我可以花少得多的时间刷 X。也许我今年或这个月只会刷 200 个小时。重点是，我真的很想从刷 X 中获得好处，但我不想为了找到相关视频而穿过所有 slop。使用 AI 让你可以在 X 上做到这一点。还有 Meta Muse，对吧，你可以用 Meta Muse 在 Instagram 上做这件事。它们有类似风格的功能，对吧？你可以通过 Instagram 使用 Muse 做研究。你可以搜索 Instagram。我还在 Muse 上有一个自动化：它把关注我的人保存到电子表格里，然后通知我所有关注我的人中哪些会对我的业务有好处，对吧？无论是我想要雇佣的人，还是想为 AI agents 做咨询的人，等等。它还会保存任何超过，呃，10,000 粉丝的人，只是为了让我知道他们关注了我。所以这意味着我不需要去 Muse 手动检查这个。你知道事情是怎样的。如果你去一个社交媒体平台，你只会被算法吸进去。你会被 slop 吸进去。通过让 AI agents 为你做所有这些，你实际上绕过了大量 slop。所以这大概就是我想在这一条里表达的观点。

## 第七种方式：把 Apps 换成 Agents
