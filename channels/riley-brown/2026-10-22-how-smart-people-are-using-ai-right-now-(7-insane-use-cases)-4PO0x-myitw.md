## 开篇引入

当所有人都在哀叹"AI 正在用垃圾内容淹没互联网"时，Riley Brown 看到了截然相反的趋势。在他看来，真正高能动性（high agency）的人正在用 AI **删除**垃圾——那些强加于人的广告、臃肿的预装软件、无休止的推销漏斗、算法投喂的信息噪音，以及团队根本用不上的功能冗余。这个视角的翻转本身就是一个"叙事违背"（narrative violation）：当大众叙事把 AI 描绘成垃圾制造机时，聪明人正把它变成垃圾清除器。

Riley Brown 以自己最近几天的真实实践为线索，总结了七种用 AI 删垃圾、提升效率、甚至赚钱的具体方式。这不是泛泛而谈的"AI 工具推荐"，而是一套完整的、关于**如何在 AI 时代重获数字生活控制权**的方法论。

## 详细内容

### 用 AI 为自己的电视写操作系统 `[Use Case 1]`

**核心观点**
智能电视是"为垃圾内容而生的商业模式"的典型代表，而用 Claude 直接为电视 vibe code 一套自定义系统，正在成为一个越来越普遍的现象。

**深度阐述**

Riley 首先讲述了一位巴西开发者的故事。这位开发者在 Twitter 上用葡萄牙语发文，大意是："我用 Claude 为我的电视做了 vibe coding。所有预装的臃肿软件和广告都被移除了。除此之外，我重做了它的操作系统，做了一个受 Apple TV 启发的简洁设计。内存占用减少了 70%，界面速度快了三倍。" `[Use Case 1]`

正是这个案例让 Riley 意识到，一个"叙事违背"正在发生：AI 并不是在制造垃圾，而是在清除人类留下的垃圾。

他进一步解释了智能电视令人厌烦的本质。如果你有一台智能电视，你一定能体会那种体验有多糟糕——你打开电视，还没看到 Netflix，就已经被迫看完一段赞助广告。这不是偶然，而是商业模式的设计。

**关键洞察**：这些电视实际上是亏本或极低利润出售的。过去十年间，80 英寸电视的价格大幅下降，原因就在于厂商在硬件上不赚钱，而是通过广告和数据收集在后端获利。Riley 一针见血地指出：

> "这个完整的商业模式就是为垃圾而生的。我们给你一个相当不错的硬件设备，价格也合理——只是我们要一直给你投喂垃圾，直到你死去。" `[Use Case 1]`

但事情正在起变化。另一位用户分享道："今天下午我给父母的电视做了 vibe coding。它在你能打开 Netflix 之前就播放赞助广告。我把电视型号给了 Claude Code，它找到了 Wi-Fi 上的电视，移除了 25 个小米软件包，写了一个新的启动器。现在它看起来像 Apple TV。" `[Use Case 1]`

还有人甚至为电视做了语音控制器。视频中展示了一段演示：用户说出一句台词，电视立即切换到 Netflix 并开始播放《怪奇物语》。

Riley 将这一模式提炼为贯穿全视频的核心主题：**你有一台拥有各种功能的设备，你只想要其中一部分功能，于是你用 AI 只保留那一部分，去掉其余所有——也就是垃圾。** 比如他只想看 Netflix、Hulu、YouTube 和少数几个功能，那他就会 vibe code 一个方案，把其他所有东西都删掉。

**延伸思考**

这揭示了一个更深层的经济命题：当硬件厂商把成本转嫁为用户的注意力消耗时，AI 恰好赋予了用户"反叛工具"。电视的封闭系统曾经是厂商的护城河，而 AI 让"越狱"这件事从极客专属变成人人可为。这可能预示着一种新型消费主义——人们不再为"完整功能"付费，而是为"恰好够用"重新夺回控制权。

### 越狱家里的任何设备 `[Use Case 2]`

**核心观点**
任何你拥有的设备都可以被越狱并删除垃圾内容，而 Claude Code 让这件事从"极客专属"变成"人人可为"。

**深度阐述**

Riley 引用了 Adrian 的案例："这太疯狂了。我把 Kindle 通过 USB 连接，让 Claude Code 越狱了它。我删除了所有亚马逊的臃肿软件，并添加了 Tailscale。" `[Use Case 2]`

另一位用户 Brandon 的反应很典型："一开始我想，为什么啊？然后我明白了——因为你可以。" 但 Adrian 的用途其实是实用主义的：他有一个完整的阅读工作流。每当他看到想稍后阅读的内容，就用 ReadDeck 保存文章，然后它下载并同步到他的家庭服务器。当他的 Kindle 同步时，内容就出现在 Kindle 上。由于他越狱了设备，他基本上可以对自己的电子阅读器做任何事。 `[Use Case 2]`

Riley 指出了一个学习资源：kindlemodding.org，可以了解如何越狱 Kindle。

**与智能电视案例的异同**：这是和智能电视非常相似的情况，但有一点不同——Adrian 不仅保留了 Kindle 上他喜欢的少数功能，还**增加了新功能**，因为他完全越狱了设备，添加了 Tailscale，基本上可以添加任何功能。

Riley 特别强调了一个关键转变：

> "当然，这并不全是因为 AI，这些事以前也能做到。但既然 Claude Code 写代码比几乎任何开发者都好，这意味着任何人都可以越狱它。据我所知，如果你有一根 USB-C 线插到电脑和 Kindle 上，你现在就可以越狱它，然后你可以用 AI 添加任何功能。" `[Use Case 2]`

他做了一个精彩的类比：就像你可以去 Lovable vibe code 一个应用一样，你现在可以直接用 Claude Code 在 Kindle 上 vibe code 一个应用。

Riley 还分享了自己的实践：他把 Meta 的 AI 智能体 Muse 添加到了自己的 ModRetro（复古掌机）上。他把设备插到电脑，告诉 Codex 创建一个新版本的应用，让他能和 Muse 聊天。"现在，一台 Game Boy 变成了一个 AI 智能体，"他兴奋地说。 `[Use Case 2]`

**个人感受**

Riley 在讲述这个案例时流露出明显的兴奋和"玩心"——他承认 Brandon 的"因为你可以"本身就有一部分解释力，但更打动他的是这种能力背后的**门槛崩塌**。以前越狱是少数技术高手的特权，现在任何有 USB-C 线的人都能做到。这种"平民化"让他看到了巨大的机会。

**延伸思考**

这里隐含着一个关于"所有权"的哲学问题：当你买了一台设备，你真的拥有它吗？厂商通过封闭系统和软件锁定实际上保留了控制权。AI 越狱不仅是技术操作，更是一种**数字所有权的重新声明**。而 Tailscale 的加入暗示了一个更大的图景：个人设备正在变成个人云的一部分，每个设备都可以是服务器的延伸，而非厂商服务的终端。

### AI 视频编辑正在超越大多数人类剪辑师 `[Use Case 3]`

**核心观点**
AI 视频编辑在大多数事情上已经比大多数人类剪辑师更好，特别是在创建高质量 3D 动画和 B-roll 方面，这让个人创作者能够拥有媲美团队的视觉效果。

**深度阐述**

Riley 直接展示了自己的实践。他打开 Claude Code，使用 Claude projects 功能，为明天的视频创建开场动画，并且一直在迭代。他播放了一段由 Claude Code 和 Blender 一次性生成的视频片段，效果令人印象深刻。 `[Use Case 3]`

但真正让他震惊的是另一个案例。有人用 Ultra Code 运行了大约 12 小时，提示词如下：

> "制作一个关于 Claude 吉祥物的 1 分钟视频。你可以在网上找到资源，比如 SVG，然后自己重新创建和动画化。尽可能有创意。渲染 3D 物体、Claude Code 终端等等。不要制造垃圾。我想看到艺术和创造力。不要字体，不要文字，只要 Claude 的干净动画。" `[Use Case 3]`

Riley 指出，这样的 3D 动画对人类来说需要数小时，甚至可能需要数周才能用 Blender 手动完成。而这个人只是打开 Claude，调到 Ultra Code，说"花大量时间确保它不是垃圾"，然后就能得到他想要的精确结果。

**视觉/结构信息描述**：视频中展示的这段 3D 动画获得了 Riley 的高度评价——"这段视频看起来不可思议。" 他认为未来模型将能创造更疯狂的 3D 图形。

**个人感受**

Riley 在这里展现了清晰的自我认知和雄心。他说：

> "我不如其他人做得好，但我想在我的视频中使用这个，为任何场景制作我想要的精确 B-roll。我认为我可以让我的 YouTube 频道好得多。比如 Cleo Abrams，她有一个完整的动画师团队为她的视频工作，这是理所应当的。她通过视频赚了数百万美元。她创造了惊人的图形。所以现在我在想，作为一个 YouTuber，我如何为我的视频打造视觉识别，并通过动画让它们更好？我真的认为这是一个巨大的机会。" `[Use Case 3]`

**延伸思考**

这不仅是效率问题，更是**创意民主化**的问题。当一个人的产出能力接近一个团队时，个人创作者与媒体公司之间的竞争格局将发生根本变化。Cleo Abrams 有一个动画师团队是"理所应当"的，但 Riley 的潜台词是：这个"理所应当"还能持续多久？当 AI 能用 12 小时生成过去需要数周的 3D 动画，创作者的瓶颈将从"执行能力"转向"审美判断"和"创意方向"。

### 让 AI 成为你的信息过滤器 `[Use Case 4]`

**核心观点**
AI 智能体凭借对你的完整上下文理解，能够比任何独立应用更好地过滤信息流——无论是邮件、Twitter 还是 Instagram——从而让你重新掌控注意力。

**深度阐述**

Riley 引用了 Nick Dobos 的观点，这是他最喜欢的 Twitter 关注之一：

> "信息饮食因为 AI 完全改变了。我不再读我的邮件了。那是 AI 的工作，它为我过滤并通知我。我每周做一次收件箱清零，那时我的智能体已经清理了 99% 的邮件。这增加了邮件的价值。现在我真的会注册更多的邮件通知，而以前我会避免，因为那太浪费时间了。比如，我现在会选择接收邮件收据，这样我的 Postmaster 邮件机器人可以转发给 Trinket Shopper 机器人和 Meal Planning 机器人。现在我在最喜欢的咖啡店刷卡，它就会自动记录到我的饮食中。" `[Use Case 4]`

Riley 坦率地评价最后一部分"有点过度优化了"，但核心观点是**把 AI 当作过滤器**。

他分享了自己的实践。以前他害怕垃圾邮件，因为他必须打开邮件应用手动筛选。他用 Superhuman 手动过滤，有些邮件会自动分到垃圾箱，但有时他确实需要进去检查，因为有些其实挺重要。

**操作指南**：AI 智能体变得如此聪明，而且对你拥有完整上下文，它们真正知道什么对你重要。你可以直接去 Claude，连接 Gmail（只需 30 秒），然后说：

> "嘿 Claude，你能不能帮我浏览过去两周的所有邮件，把明显是垃圾的归档？" `[Use Case 4]`

然后你可以加上"基于我的目标"，进一步指定哪些是垃圾。但如果你使用始终在线的智能体——比如 Grokbot、GPT dots 或 Meta Muse——这些智能体非常擅长理解什么对你重要。而独立邮件应用实际上不知道什么对你重要，所以它们更难过滤。使用了解你的 AI 智能体，它在理解该过滤什么方面会更好。

Nick Dobos 的洞察在于：**AI 过滤实际上增加了邮件的价值**。他更愿意让更多邮件进入收件箱，因为他知道 AI 智能体会把它们送到正确的地方，过滤掉所有垃圾。

Riley 强调了一个关键点：这需要能动性。不会有人替你设置好，你必须自己去搭建。

**不只是邮件**。Riley 最近最喜欢的是用 AI 智能体搜索 Twitter，找到相关内容展示给他，而不是自己花时间看垃圾。Grokbot 现在内置了 Twitter，不需要 API 密钥，订阅就包含搜索功能。

**他的提示词示例**：

> "我最近对 AI 如何编辑视频感兴趣。我希望你找到有声望的人，不是那种想转发自己文章的骗子。我想找到那些以有趣方式拆解这个话题的人，给我一个所有这些人名单。" `[Use Case 4]`

这意味着他可以大幅减少刷 X 的时间。他想要刷 X 的好处，但不想经历所有垃圾来找到相关视频。

他同样使用 Meta Muse 来处理 Instagram。你可以用 Muse 做研究、搜索 Instagram。他还设置了一个自动化：把关注他的人保存到电子表格，然后通知他哪些关注者对他的业务有用——无论是他想雇用的人，还是想做 AI 智能体咨询的人。它还保存任何超过 1 万粉丝的人，只是让他知道他们关注了他。

**个人感受**

Riley 在这里点出了一个很多人都有共鸣的体验：

> "你知道的，如果你去社交媒体平台，你就会被算法吸进去。你会被垃圾吸进去。通过让 AI 智能体为你做这些事，你实际上绕过了大量垃圾。" `[Use Case 4]`

**延伸思考**

这实际上是对"注意力经济"的一次反向操作。过去二十年，平台通过算法最大化你的停留时间，把注意力卖给广告商。而现在，AI 智能体成为你的**个人注意力守护者**——它替你进入平台，只把有价值的内容带出来。这可能从根本上改变社交媒体的商业模式：当用户不再亲自刷信息流时，平台的广告价值将如何维持？

### 用智能体取代应用 `[Use Case 5]`

**核心观点**
许多应用可以被 AI 智能体直接替代，你不再需要忍受应用内的推销、付费墙和留存机制。

**深度阐述**

Riley 分享了一个有趣的反转。他开玩笑说："任何说软件已死、AI 会杀死应用的人都是错的。我一直在疯狂下载应用。" 然后展示了他手机上一堆 AI 工具。但他真正想表达的是：**很多人说 Grokbot 这样的工具会杀死应用商店，因为你的智能体可以直接使用你的应用，甚至做应用能做的事。**

他举了一个非常具体的例子：Cal AI。这是一个每年 50 美元的应用，用来记录卡路里。你拍张食物照片，它就记录卡路里。

**替代方案**：你可以去 Grokbot 说：

> "嘿，每次我发给你一张照片，比如我拍张照发给你，我要你把它放到电子表格里，记录我当天摄入的卡路里，然后立即告诉我食物里有多少卡路里。" `[Use Case 5]`

Riley 承认可能有 API 能让它更准确，但大多数 AI 模型已经能做得和 Cal AI 一样准确。

**关键优势**：你不会遇到的垃圾包括：

- 应用为了最大化留存而设计的机制
- 极具说服力的付费墙，试图让你注册每周 7.99 美元的订阅
- 不断的追加销售

Riley 用自己的经历说明：他用 Cap Cut 编辑视频时，主要就是剪切和加字幕，但不断被"嘿，试试这个新 AI 功能"、"升级到最高级计划以便导出特定宽高比"等提示轰炸。所有这些他根本不需要的东西，在使用应用时都会遇到。

而他发现，AI 智能体只要你开口，就能替他完成大部分事情。结果就是：他取消了几乎所有应用，只和 AI 智能体交互——通过文字或语音模式（他预告了未来的视频会讲这个）。他移除了生活中的"应用垃圾"，基本上只和智能体交互，甚至在工作中也是如此。

**视觉/结构信息描述**：Riley 展示了自己几乎空空如也的手机主屏幕，作为这一转变的直观证明。

**延伸思考**

这提出了一个关于"应用经济学"的尖锐问题。应用商店的模式建立在**下载量、留存率、订阅转化**之上，这必然导致应用不断添加功能、推送通知、设计付费墙。而 AI 智能体模式建立在**对话和任务完成**之上——没有留存指标的压力，没有追加销售的动机。当智能体能直接调用 API 完成任务时，"应用"这个中间层是否还有存在价值？Riley 的"空主屏幕"可能是未来的一种预演。

### 用 AI 删除视频中的废话 `[Use Case 6]`

**核心观点**
AI 可以分析视频转录文本，识别并删除所有不必要的部分——跑题、重复、无意义的段落——这不仅节省观众时间，还能提升留存率。

**深度阐述**

Riley 再次以自己为例。他使用 Tella 录制视频（包括正在观看的这个视频），过去他手动编辑或发给剪辑师。但现在很多视频他直接用 AI 编辑。

**他的提示词示例**：

> "嘿，请找到我上周做的一个视频，我要你分析这个视频，告诉我所有我可以或应该删除的部分。我的目标是删除垃圾。不重要的部分、不重要的跑题、如果我真的尊重我的观众就不会留下的部分，因为他们的时间很宝贵，我想在不浪费他们时间的情况下把核心观点传达出去。你能不能找到一个视频，告诉我所有你会删除的部分？" `[Use Case 6]`

Riley 强调，无论你用 Premiere Pro、Descript 还是 Tella，现代编辑软件都可以用 AI 分析转录文本，让它删除垃圾，而且这实际上**更有利于留存**。如果你删除所有不必要的部分，你实际上能节省人们的时间。这些在 pre-AI 时代要手动删除所有内容会困难得多。

**他实际做的**：用 AI 最多的事情就是删除、精简。他会加速无聊的部分，让人们留在视频上而不是感到无聊。他能够用 AI 减少垃圾、减少视频时长，只传递他想传达的要点。

**视觉/结构信息描述**：视频展示了 AI 生成的分析结果，包含几个类别：
- 应该完全剪掉的部分
- 重复的观点，应该合并成一个
- 需要收紧的部分
- 应该修复而非剪掉的部分

Riley 称之为"**垃圾探测器**"（slop detector），他可以用 AI 提升自己的技艺，做出越来越少的垃圾。这些建议质量很高，他可以直接告诉 AI 在编辑这个视频时做这些修改。

**个人感受**

Riley 在这里表达了一种对观众的**尊重伦理**："如果我真的尊重我的观众，我就会想删除这些部分，因为他们的时间很宝贵。" 这把 AI 编辑从效率工具提升为一种创作伦理——用技术手段强制自己对内容负责。

**延伸思考**

这可能重新定义"内容质量"的标准。在注意力稀缺的时代，**删除**可能比**添加**更有价值。AI 让"精简"从一种需要高度自律的手艺，变成一种可以系统性执行的流程。未来的优秀创作者可能不是最会"加内容"的人，而是最会"删内容"的人。

### 为公司构建你自己的内部软件 `[Use Case 7]`

**核心观点**
任何你使用的软件都有大量你根本用不到的功能。用 AI 提取你真正需要的少数功能，组合成一个"超级应用"，这是 Riley 每天都在使用的最重要方式。

**深度阐述**

Riley 展示了他用 Opus 构建的 "Native Note"。这个工具汇总了他喜欢的 Notion、My Mind、Typefully 和许多其他应用的功能。总共花了大约 3 小时。

**核心功能展示**：

- **视频脚本管理**：所有脚本都在这里
- **Excalidraw 集成**：可以非常容易地附加一个 Excalidraw 白板，这是他自己的 Excalidraw 版本。点击"New Board"就能为视频创建一个附加白板，讨论 AI 视频编辑。白板上的步骤 1、2、3、4 会以预览形式出现在脚本顶部 `[Use Case 7]`
- **AI 可编辑一切**：这是关键区别。他以前用 Notion 做这个工作流，但很烦人，因为白板不是附加的，而且 AI 不能编辑 Excalidraw 图表。在这个应用里，AI 可以做任何事。他可以在散步或用手机时说"嘿，能不能创建一个 Excalidraw 白板"，AI 就能为他创建视频的图表 `[Use Case 7]`
- **直接发推**：可以直接从他的平台发推，不需要去 Twitter
- **品牌交易记录**：所有品牌合作都记录在案
- **内容流**：这是所有正在制作的视频的 feed，可能涉及不同剪辑师、赞助商等。这个 feed 每 30 分钟监控他的邮件，把所有需要知道的信息记录到 feed 中
- **YouTube 选题机会**：所有需要的选题都在这里
- **YouTube 分析**
- **剪辑师协作**：他可以直接在视频里输入评论。点击"Comments"，输入想改的内容，这会给 Claude Code 发一个 webhook，让它实际执行编辑 `[Use Case 7]`

Riley 承认这个功能"还有很多工作要做"，但重点在于：**任何他想要的软件功能，都可以非常容易地添加。这里没有任何他不用东西。如果不用，他就删掉。**

**关键洞察**：想想你公司用的所有工具。很多你根本不用。它们是杂乱，是垃圾。当你为团队构建软件时，你可以只构建你想要的。你可以创建完全符合团队需求的工作流。你不需要依赖 Notion 这样的外部开发者，他们功能太多了。Riley 说他只用 Notion 5% 的功能。为什么要付钱买席位来获取他们的 AI 功能，而我可以只克隆他们用到的少量功能？

**第二个案例：桌面应用**

Riley 还构建了桌面应用。Raycast 是他最喜欢的应用之一，他构建了一个类似的应用，让他能快速找到 logo 并放到 Excalidraw 白板上。

**工作流演示**：
- 打开应用，搜索"AI slop"
- 点"remove background"，自动变成贴纸，可以复制到应用里
- 从库中取任何保存的图片（所有复制过的图片都保存到库中）
- 用它们做图像生成。比如输入"Riley Brown"，说"Riley Brown 穿着 @Claude Code T 恤，屏幕上有这个 logo 文字" `[Use Case 7]`
- 这就是他制作一些缩略图的方式

**视觉/结构信息描述**：Riley 展示了他用单个提示词创建的桌面应用，内置图像搜索和图像生成功能。"我不是开玩笑。它就在这里。我不付钱给任何人。我只是用 Vercel AI Gateway，它让我能访问所有必要的 AI 模型。我可以这样创建缩略图。我不需要使用别人的软件。它只有我需要的功能。"

他展示了自己的使用量——数月来他一直在用自己的桌面应用，成本就是 API 费用，仅此而已。他不为别人的服务付费，因为不需要。**构建应用太容易了**，这为他节省了大量金钱和学习别人软件的时间。

**个人感受**

Riley 在这一段展现出最强的成就感和掌控感。他的语气是"这太简单了，为什么还要用别人的软件"。这种态度本身就是一个信号：当构建软件的成本趋近于零时，**"使用别人的软件"这个行为本身需要被重新审视**。

**延伸思考**

这可能是对 SaaS 行业最直接的挑战。SaaS 的核心假设是"企业愿意为标准化软件付费，因为自建成本高"。但如果自建成本从数月工程降低到 3 小时提示，这个假设就崩塌了。未来可能不是"每个公司用同样的 Notion"，而是"每个公司有自己的 Notion"。软件不再是产品，而是**即时的、个人化的、可演化的工具**。

### Riley 的七点总结 `[结尾总结]`

在视频结尾，Riley 用极快的节奏回顾了七个要点：

1. 你可以 vibe code 自己的电视软件
2. 你可以越狱家里的任何软件或硬件，把它变成你想要的任何东西
3. AI 在 Blender 使用和创建高质量 3D 视频方面正在超越大多数人类

## 精华收获

**认知层面**：
1. **"AI 制造垃圾"是叙事偏差**——真正高能动性的人正在用 AI 删除垃圾，这是一个被主流叙事掩盖的反向趋势
2. **切片思维**——任何设备、软件、信息流都有大量你不需要的功能/内容，AI 让你只保留需要的那一片
3. **构建成本趋近于零**——当 vibe coding 让软件开发从数月变成数小时，使用别人软件的理由正在消失

**行动层面**：
1. 用 Claude 连接 Gmail，让它归档过去两周的垃圾邮件（30 秒设置）
2. 用 Grokbot 搜索 Twitter，只获取你关心的领域的优质内容，而非自己刷信息流
3. 用 AI 分析你的视频/播客转录文本，让它识别可以删除的部分
4. 列出你团队使用的所有软件，找出你只用 5% 功能但付 100% 费用的工具，考虑自建替代

**方法论层面**：
- 所有案例的共同模式：**识别垃圾 → 用 AI 删除 → 只保留你真正需要的 → 按需添加新功能**
- 关键前提是**能动性**——这些都不会自动发生，你必须主动设置
- 从"接受默认"到"主动设计"的心态转变是核心
