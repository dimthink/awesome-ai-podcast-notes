# Claude 历史上最重磅的一周：全新工件、会议助手与模型更新全解析

Anthropic 不仅发布了 Fable 5.2，还几乎推出了他们自己的 Microsoft Office 版本，包含三种全新的工件（Artifact）类型：**Sheets、Whiteboard 和 Data**。除此之外，你现在还可以把 Claude 加入视频会议，它可以在你和团队交谈时执行操作。今天我会把这一切拆解清楚。但本周发生的事还不止这些。Google 刚刚发布了他们的新模型 **Gemini 4 Carbon**，我有很多想法，有些好、有些坏。另外，**Dots** 也有三项重大更新，其中一项我每天都在用。

所以，今天我想首先谈的是 **Anthropic 发布了三种全新的工件类型**。

## 一、Anthropic 发布三种全新工件：白板、表格与数据

### 1. 官方公告与白板工件上手

这是他们 3 天前发布的公告。他们说：从今天开始逐步推出 **Claude Whiteboards、Claude Sheets 和 Claude Data**。

这里演示一下新的白板工件。昨天我打开 Claude Code，给 Fable 5.2（他们最新的模型，我们稍后会讲到）的提示语是这样的：

> “嘿 Claude，我想让你创建一个新的白板工件。分析我是如何编辑视频的，从我使用的电脑开始，一直到最终输出。包括分析、抓取和提示。把它做成一个易于理解的白板。”

然后 Fable 5.2 实际上遍历了 70 个我在 Claude Code 中编辑视频的不同对话线程，生成了一个大纲。在工件顶部你会看到这个聊天按钮。如果我点击它，就可以回到聊天中说：

> “我想让你创建这种概览，它应该非常视觉化，把它们放进一个层级结构里，并且列出步骤，做一个视觉化的概述。”

这会更精简一些。Claude 可以操纵和编辑每一种工件类型。这个模型正变得越来越视觉化，而且它非常擅长在这个新的白板工件上创建内容。

你会注意到我这里使用的是 **Fable 5.2 Extra**。对于这个任务来说，这完全没必要。所以我要把它停掉，切换到 **Opus 5.5**。我们不用 Extra，只用中等模式。然后直接说“继续”。你可以看到它即将开始工作，这里显示它正在忙碌运转。我稍微缩小一点。好了，我们就得到了这种概览幻灯片。然后你可以立刻直接编辑它。我可以在这里添加这个小部分，把它命名为“概览”。然后我可以拖动它，我可以抓住这整块，把它移动到我想要的位置。也许我们想把它放在这个上面。看，简单多了。

现在用 AI 创建这些白板变得非常容易。

### 2. 表格工件：内置版 Excel

但实际上还有一种新的工件类型，而且这个我用的比白板还多。看看这个。

> “我想让你创建一个新的 Sheets 工件，包含所有这些内容。如果我要做一个关于这个主题的视频，并发布一份表格，给人们提供开始创作视频所需的所有资源，那就是我想要的效果。”

你可以看到它开始工作时，会打开一个新的 Sheets 侧边面板，看起来和 Microsoft Excel 或 Google Sheets 一模一样。你可以非常容易地全屏显示它。底部有所有这些不同的选项。你可以看到 Claude 正在工作。看，它开始添加这些内容了。它在往下走，刚刚添加了所有这些不同的工具。哇，它在给所有东西打标签。看看这个效果有多好。

> “在一个新表格上添加一些图表，展示按类别划分的工具细分。”

这里你可以看到这个细分正在生成，因为它上面有个小渐变。如果我点击它，看，工具包细分出来了。它可以创建这些图表，非常棒。

我无法告诉你，把这种功能直接内置到 Claude Code 里有多有用。顺便说一下，你可以在 **Claude Duet** 里做同样的事。它们都拥有相同的工件，而且全部同步。所以从 Claude Code 切换到 Claude Duet——他们全新的智能体平台——非常容易。

所以，他们创建了自己的 Excel 版本，叫 **Claude Sheets**；他们创建了自己的白板应用，可能有点像 Miro、Whimsical Diagrams 或 Excalidraw，叫 **Claude Whiteboards**。

### 3. 数据工件：实时仪表板

我还没有展示的是 **Claude Data**。这种新的工件类型可以被看作一个 Claude 实时仪表板。它把你拥有的集成连接起来，让你能够创建一个仪表板。无论数据是用户数量，还是你在 YouTube 上的观看次数。这种工件与你在普通工件中创建的仪表板之间的区别在于：这些数据会保持实时更新，并且它实际上会显示所有数据的来源。

## 二、Claude 会议：实时参与视频讨论

昨天他们发布了一项新公告，叫 **Claude Meetings**。他们说：

> “推出 Claude Meetings。把 Claude 添加到你的团队视频通话中，它会在你说话的同时生成文档、白板和其他工件。”

我直接看这个演示视频。请注意，这需要一些时间逐步推出，并且只在部分团队版和企业版计划中提供。

演示视频中的对话大概是这样：

> “大家好。”
> “嘿，早上好。”
> “早上好。”
> “嘿，嘿。”
> “早上好。”
> “嗨 Claude。嘿 Claude，你能开始一个白板吗？”

所以，这绝不是一个会议记录工具。这是把 Claude 作为**主动参与者**加入会议中。你可以说：“嘿，Claude，在我们讨论想法时，你能在白板上实时保持整理吗？”所以这几乎就像在会议里加入了一名积极的员工。

总而言之，我们现在有了 **Sheets 和 Whiteboards**，有了 **Claude Data**，还有了 **Claude Meetings**。

## 三、Anthropic 与 Google 的新模型：Fable 5.2、Mythos 5.2 与 Gemini 4 Carbon

### 1. Fable 5.2 与 Mythos 5.2

我想讨论的前两个模型是 **Fable 5.2** 和 **Mythos 5.2**。现在，如果你使用标准的 Claude 应用或 Claude Code，进入模型选择器，你会看到全新的 Fable 5.2。但是，你看不到 Mythos 5.2。

正如很多人所知，几周前，很多公司都在发布消息说他们遭受了攻击。科技领域发生了大量网络攻击。如果你当时去找 Opus 5.5，说类似：“嘿，我正在遭受网络攻击。我需要你分析一切，找出问题并解决它。”如果你用这样的提示语去问 Opus 5.5，你会得到类似“抱歉，我们无法帮助处理这个问题”的回复。这是因为 Opus 5.5 在网络安全问题上的限制极其严格。

现在，Claude 发布了两类模型。一类是任何人都可以使用的，你现在就能用。另一类限制较少，你可以用它来处理不同的网络攻击场景。相比 Fable 5.2，这个模型在分析你代码库中的漏洞时限制更少。这个模型叫 **Claude Mythos 5.2**。

所以，每个使用 Claude API 和 Claude 应用的人都能使用 5.2。而 Mythos 只有通过 Anthropic 网络与生命科学验证计划审核的组织才能使用。获得 Mythos 5.2 的权限要困难得多。

### 2. Fable 5.2 与 Opus 5.5 的对比及使用建议

我认为大多数人想问的是：Fable 5.2 与 Opus 5.5 相比如何？Opus 5.5 已经是世界上最好的公开可用模型了。

我可以告诉你，**Fable 5.2 就像 Opus 5.5，但更加精炼**。它对细节的关注度更高，尤其是在 3D 工作流和视频编辑工作流中。它更擅长理解“真正的好”是什么样子，并且会花更多时间和精力打磨那些小细节。我发现它在各方面都有更好的输出。

然而，它的价格是 Opus 5.5 的两倍。所以在 Claude 应用里，你有每周限额，也有每周 Fable 限额。在每月 200 美元的计划上，我仅用正常业务任务就已经触顶了。Opus 以前感觉是无限的，现在感觉不是无限的了。我认为你不应该用 Fable 处理所有事情。

这里有一个关于我如何使用这两个模型的概览：

- **对于大多数任务**：使用 Opus 5.5。
- **对于非常困难、消耗大量 token 的任务**：用 Fable 5.2 做规划，然后让 Opus 5.5 执行。Fable 非常擅长制定非常好的计划。但如果你的任务需要大量子智能体，并且可能持续一小时甚至两小时，比如大量 Blender 工作、制作视频游戏或创建应用，这些会消耗大量 token。Opus 可以做大部分工作。只要让 Fable 制定非常详细的计划，然后派 Opus 5.5 去做数小时的苦力。质量可能稍微低一点点，但大致相同，而且你会节省大量 token 费用。
- **对于我来说，Fable 非常可靠**。如果我现在正在构建的应用出了问题，或者我需要立即以非常高的质量完成一个剪辑，比如我们只有两小时的时间，我会直接去找 Fable。我会直接说：“嘿，你有这么多时间。把它搞定。”很多时候我根本不在乎它花多少钱，我只是需要为我的业务完成某件事。我会依赖 Fable。

所以，就像 Fable 5.2 极其可靠，但它更贵。记住这一点。

### 3. Google Gemini 4 Carbon 的测试感受

除了 Fable 和 Mythos，我们还有 **Gemini 4 Carbon**，这是 Google 在 Claude Fable 5.2 发布一天后推出的最新模型。

我花了大约两个半小时测试他们的新模型 Gemini 4 Carbon，我会说这是他们创造过的最好的模型。这是他们的 Fable 版本，被认为是他们最好的模型。但在我测试的两个半小时里，我找不到任何一件它比 Opus 做得更好的事。

我不认为这个模型比 Opus 更好。我认为 Opus 的品味好得多，尤其是在前端方面。它在 3D 上更好，在创建视频游戏方面也更好——我认为这其实是对通用智能的一个很好的测试。而且在视频编辑方面，它远不如 Opus。

除此之外，我不喜欢使用 **Antigravity**。Antigravity 是我访问 Gemini 4 Carbon 所需使用的应用。Claude 应用和 Codex 应用都比它好得多。所以我真的不知道我应该用哪个应用来配合 Gemini。我希望未来会有所改变。我希望作为一个想要使用智能体来完成工作的企业主，我能更清楚应该使用哪个平台。我仍然不知道该用哪个应用，因为我太喜欢使用 Claude 桌面应用和 Codex 应用了。我现在看不到任何切换的理由。

我想特别指出的一点是价格。如果你看 Gemini 4 Carbon 的价格，在限时期间，它实际上是 Opus 价格的一半，然后会在 11 月 30 日前上涨到与 Opus 相同的价格。所以，我们还有 17 天更便宜的 Gemini 4 Carbon，但即使半价，我也看不到从 Claude 桌面应用切换到 Antigravity 的理由。

## 四、Grok Bot 的小幅更新

因为很多关注我的人都在使用 **Grok Bot**，我想用大概 20 秒的时间讨论一下他们本周做的一些小更新。

本周他们宣布的第一个更新是，你现在可以使用你电脑上的 Mac 应用。在 Mac 上，Grok Bot 现在可以使用**信息、邮件、备忘录、提醒事项、日历、定位和通讯录**。他们在 11 月 12 日更新了这个功能。总体而言，他们正在进行大量更新，以便更容易地将它添加到你的团队中。把 Grok Bot 添加到 Slack 的集成也获得了很多新更新，我很快就会做一个相关视频，因为它对我和我的团队非常有用。

下一个更新是他们添加了 **Tailscale**。Grok Bot 可以加入 Tailscale 网络，这将使你能够访问私有的 MCP（模型上下文协议）服务器和内部工具。对于那些经营初创公司的人来说，这非常有用。

## 五、Dots 的三大更新：多电脑控制、ChatGPT 钱包和速度提升

### 1. 连接多台电脑，控制整个电脑集群

现在我想谈谈 **Dots** 的一些更新。Dots 刚刚发布了一个新功能，你可以把你的 Dot 连接到许多不同的电脑上。

如果我们现在导航到我们的 Dot，你可以看到我们的 Dot 连接到了两台电脑。一台是我现在正在拍摄用的 MacBook Pro，这是我最强大的电脑。我这里还有一台 Mac Mini，也连接到了它。

我可以这样说：

> “请列出我下载文件夹中最新的视频。就列出文件。在两个 Claude Code 会话中执行。一个在我的 MacBook 上，一个在我的 Mac Mini 上。”

我想表达的重点是：有了你的 Dot，它不仅拥有自己的小电脑，可以在不需要你的电脑时使用，而且你还可以完全控制你的电脑。而且因为 Claude Code 的计算机使用能力非常好，你只需要让你的 Dot 启动 Claude Code 会话，让它做任何你需要做的事情，它就会通过计算机使用来完成。

你看，这里显示“最新下载视频”。如果我们点击“最近”，可以看到在下载文件夹中直接找到了六个视频文件。这些是我 Mac Mini 上的最新下载，而这些是我 MacBook 上的最新下载。

所以，我只需要和一个智能体——我的 Dot——对话，就可以控制一整群电脑。一些我聊过、正在使用 AI 进行视频编辑的人正在专门为视频编辑购买一台新的强大机器。所以他们的想法基本上是：这台电脑只用于视频编辑，它一直不停地在编辑视频、制作片段、在电脑上渲染。现在你可以通过 Dot 来控制它。你只需要说：“嘿，我们用来编辑的那台 Mac Mini，你能完成这个任务吗？”所以它在某种程度上就像一个电脑协调员。

### 2. ChatGPT 钱包：让智能体替你安全购物

Dots 的最新更新来自大约 30 分钟前，那就是全新的 **ChatGPT Wallet（ChatGPT 钱包）**。OpenAI 刚刚发布了这个功能。现在，你的 Dot 可以在你批准的情况下，安全地代表你完成购买。

使用 ChatGPT 钱包，智能体付款时不会访问你的真实卡号详情。每笔购买都需要安全验证。ChatGPT 钱包从今天开始向美国的 Dots Pro 订阅用户推出。抱歉，欧洲的朋友们，你们没戏了。

这是刚发布的功能，所以我还没测试过。而且，由于我是一家企业，我其实想花些时间了解它，而不是立刻设置。但我们来看看这个演示视频。

你可以说：

> “我想在假期前为我的朋友 Amelia 找一份礼物。她喜欢烹饪、做陶器，还喜欢植物。预算大约 100 美元。”

我太渴望这样的功能了。

“我会找一个节日礼物……我买这个。”

好的，我们看看它会做什么。它正在询问寄到哪里。是的。然后在这里，你可以看到它说你可以审查购买，然后允许你批准。所以它不会立即替你买东西。你会收到一个小通知，然后显示“购买完成”。接着订单就会送达。

我认为消费者可能不会对此特别兴奋，但作为一个几乎每隔一天就要订购东西的企业主，我无法告诉你我有多兴奋，能够和一个我使用的、了解我的上下文、并且接入了我已在使用的工具的智能体对话，让它代表我购买东西并寄到我家或公司。我真的很想要这个功能。但问题是它并不总是有效。我们稍后会讨论这一点。

### 3. 速度提升与 GPT 6.1 Terra 驱动

Dots 的最后一项更新是它们变得更快了。大约一个月前，我公开说过 Dots 变得有多慢。现在它们明显快多了。它们使用的行话也更少了，尤其是在实时语音中。

如你们所知，我和 AI 交谈的方式是：我通常在手机上跟 AI 说话，因为我可以启动 Claude Code 会话。我走路时更有创造力，我会使用实时语音，而它用的行话更少。它有了新的自定义指令。最后，现在驱动 Dots 的是 **GPT 6.1 Terra**。

对我来说，这有一点不利。我更希望能选择用哪个模型驱动 Dots。但好的一面是，我可以让我的 Dot 启动一个使用任何我想要模型的新 Claude Code 会话。所以这很好。我只是希望有更多可定制性。不过这确实意味着它更快了。

## 六、AI 智能体与企业的对抗：联合航空和亚马逊的封锁

说到智能体无法进行支付的问题，我想谈谈最后两项更新。

一项是**联合航空（United）正在阻止 AI 智能体**。这实际上是我在整个行业看到的一个趋势。亚马逊也做了类似的事，他们不允许智能体购买东西和使用他们的网站，因为这对他们的商业模式不利。

联合航空将限制 AI 智能体预订航班或管理预订。他们这样做的原因——至少我高度怀疑——是：根据你是谁，当你去订机票时，如果他们觉得你愿意付更多钱，他们就会显示更高的价格。这是他们采用的一种非常有问题的策略。

所以，这些公司可能不想让你使用智能体的原因是：智能体愿意花几个小时来寻找最好的交易。而这实际上对他们不利。他们希望你去他们的网站，然后在某张机票上被宰。智能体会阻止这种情况发生。

如果人们开始使用智能体买机票，智能体总会寻找最划算的交易。他们会搜索所有不同的竞争对手，因为它们会花时间。如果你让你的智能体去做，你就不需要付出努力；而有些人很懒，会直接买更贵的。这会损害联合航空的利益。

亚马逊同理。亚马逊可以通过让智能体在亚马逊上买东西来赚很多钱。然而，他们在亚马逊上赚钱的主要方式是广告。如果人们不再访问网站，只剩智能体，智能体就会直接过滤掉广告。智能体会只看最好的选项。所以，你实际上无法向智能体投放广告。这会损害他们的商业模式。

所以，我们目前正处于一场拉锯战中：一边是我们作为用户使用智能体购买东西的便利性，另一边是我们的智能体去购买的那些公司的商业模式。我会非常详细地报道这个议题，因为我认为这是一场会持续很多年的战斗，并且将成为真正有效使用智能体经营整个企业的最大障碍。

最后，我想以一个小的推荐阅读作为结尾。我会开始每周都这样做，给你们一些可以深入挖掘的内容，深入探讨我发现非常有趣的 AI 领域基础设施层面。

本周有一个非常有趣的 Twitter 帖子，来自 **Will Depw**。他说他有取证证据表明，**DeepSeek、Moonshot、MiniMax 和 Ant Group**——这些中国公司——是在 **Nvidia Blackwell 芯片**上构建它们最新模型的。而这些芯片实际上是禁止在中国使用的，你不能把它们运到中国。
