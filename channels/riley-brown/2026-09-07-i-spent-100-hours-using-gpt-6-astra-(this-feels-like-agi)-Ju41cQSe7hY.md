### 3. 游戏创作的爆发：下一个 vibe coding 大浪潮 `[字幕 第2点/第3点之间]`

**核心观点**  
作者认为 AI 让高质量 3D 多人游戏可以在 30 分钟到 1 小时内诞生，这会催生专注游戏的 vibe coding 平台、托管和交易生态，也会让创作者为自己的受众做游戏。

**深度阐述**  
在 3D 案例之后，作者把视角推到游戏产业。他要求读者认真想一件事：AI 现在可以在 30 分钟到 1 小时内创建高质量 3D 多人视频游戏。人们已经在做完整的 Rocket League 克隆，并定制自己想要的玩法，让游戏更有趣。也有人在做 Fortnite 风格游戏。作者自己做了《使命召唤》风格游戏，并说如果投入更多时间，还能继续完善。

他预测这会带来“next vibe coding boom”——下一波氛围编程浪潮。会出现一个只专注游戏的平台，也许只是一个托管平台。他设想在 ChatGPT 里直接 @mention hostmygame.com，游戏就能被托管，托管免费，还可以加入游戏内货币和交易。他认为，如果有公司能解决“让人们托管游戏并在游戏内卖东西”，那它一定会成为亿万级公司。这个模式有点像 Roblox，但他强调不应该限制人们能创造什么。

另一个趋势是创作者经济。作者认为，创作者会开始像制作 PDF、课程、社群一样，为自己的受众制作游戏。过去这些数字产品是“低保真”的：PDF、课程、社群。未来可以是一个视频游戏或一个小世界，人们进去互动。它有点像元宇宙，但更轻：只是一个链接，点进去就能玩，进入创作者的世界。他认为这会是未来的一大趋势。

**个人感受**  
作者对游戏创作的机会表现出强烈的产品直觉。他不是只说“AI 能做游戏”，而是在推演平台、托管、交易、创作者分发和受众互动。他的语气是兴奋且确信的，认为这是一块正在打开的巨大空地。

**延伸思考**  
如果游戏制作成本坍塌，竞争会从“开发能力”转向“玩法创意、社区运营、变现设计、分发渠道”。Roblox 式平台的关键不只是工具，而是经济系统、审核、托管、支付和创作者激励。谁能让普通人轻松发布、被发现、赚到钱，谁就握住新平台入口。

**精华收获**  
- 游戏可能成为创作者的新内容格式：像 PDF、课程、社群一样可发布。  
- 托管 + 游戏内交易 + 低门槛创作，是潜在平台机会。  
- 不要只做生成工具，要做分发、运营和变现闭环。

### 4. 第三个醒悟：Vibe coding 已经被解决 `[字幕 第3点]`

**核心观点**  
作者认为“按需生成软件”已经实现：个人软件的知识门槛为零，他能在 16 分钟内用单条提示做出一个自用桌面应用，并通过 ChatGPT Sites 快速托管带认证、数据库和后台的网站。

**深度阐述**  
作者说，第三个让他感到 AGI 的醒悟是：“vibe coding is just solved.”——“氛围编程已经被解决了。” `[字幕 第3点]` 他非常认真：你可以“on command”生成软件；创建个人软件所需的知识水平是零。

他举了自己当天早上的例子。他在咖啡店做演示，厌倦了反复去 Google Images 找图、复制、切回 Excalidraw 或演示文稿、粘贴、再去背景。他想要一个类似 Raycast 的应用。Raycast 是他的剪贴板管理器和应用查找器，他喜欢它随手弹出的感觉。于是他打开 Codex，说：我想创建一个桌面应用，可以通过快捷键使用；它是 Raycast 风格；能搜索 Google Images 并去除背景；我复制或保存的图片都保存到 saves 文件夹。他还加了一堆想法。16 分钟后，应用做好了。

他演示：Command + Shift + Space 打开应用，输入 “codeex logo”，按 Enter 搜索，复制，然后粘贴到任意地方。在 Excalidraw 里不能直接去背景，所以他让应用能一键去背景。他还想要多搜索：输入 “open AI logo; Microsoft logo; Bing logo; Google logo enter”，应用会自动创建四个 Google 图片搜索，一个加载时他可以切到另一个。他还加了 AI 功能：输入 Microsoft logo、Satya Nadella、Sam Altman、Dario Amodei、Steve Ballmer、Jensen Huang，按 Command + Enter，AI 自动创建正确的搜索。搜索后可以去背景、复制、粘贴到白板。因为保存或复制过，图片会自动进入 saves 文件夹，未来输入时会出现，能复用已有图片。

他强调，这个应用非常小众，但是为他自己做的，现在就是一个键盘快捷键，活在他电脑上。它是桌面应用。过去会花很长时间，现在他用 Codex 单条提示就创建了。他还指出 OpenAI、Anthropic 等公司看到了其中价值，所以加入 Sites 功能。Sites 内置托管、数据库、存储、认证。他可以创建站点，托管在 chatgbt.site 一类地址，分享给团队，并要求团队成员用团队账号登录。

他还谈到一个具体用例：lead magnets。他想让人们注册 Call of Singularity，于是说：“以我的 Modern Singularity 游戏风格，创建一个站点，让人们上传信息，方便我联系他们。” 很快就生成了。他还指定只有自己的邮箱可以访问 admin dashboard。网站创建后，他用自己账号登录，就能看到后台，只有他能看到提交信息的人。于是可以创建安全站点，并给自己管理员权限。

**个人感受**  
作者的语气是“我认真地说”。他并不是在炫耀技术，而是在表达一种门槛消失后的解放感：只要有一个小冲动，就能为自己造一个软件。这种个人软件的自由度让他非常兴奋。

**延伸思考**  
当每个人都能生成自用软件，软件会变得更碎片化、更个性化、更短生命周期。大公司产品可能被“只满足我一个人”的微型工具侵蚀。与此同时，托管、认证、数据库、支付、分发会成为新的基础设施战场。ChatGPT Sites 这类产品把“生成”与“上线”合并，可能改变独立开发者和企业内部工具的构建方式。

**精华收获**  
- 从想法到桌面应用，可以压缩到单条提示和十几分钟。  
- 用 Sites 做 lead magnet、登录收集、管理员后台，是当前高价值用例。  
- 学会把需求写成完整规格：快捷键、搜索、去背景、保存、复用、AI 搜索、权限。

### 5. 第四个醒悟：Computer use 简直疯狂 `[字幕 第4点]`

**核心观点**  
作者认为电脑控制能力正在指数级加速。GPT-6 Astra 在 Microsoft Paint 绘画测试中明显优于 Fable 5.1，OpenAI 与 Anthropic 都在用数万台 Mac Mini / Mac Studio 训练 computer-use agents。

**深度阐述**  
作者的第四个醒悟是：“computer use is simply just insane.”——“电脑使用简直疯狂。” `[字幕 第4点]` 他说模型，尤其是在 Codex 里使用时，控制电脑的能力正在快速加速。他展示了一个很有说服力的测试：有人让 Fable 与 GPT-6 Astra 对战，给它们一张自己的照片，然后打开 Microsoft Paint，让两者画他。视频可能加速了 10 倍。重点是 GPT-6 Astra 和 Fable 5.1 在 computer use 上的差异非常明显。

画面中，GPT-6 Astra 使用 Microsoft Paint 一段时间，画出的结果按作者说法“高于两周前 AI 通过 computer use 画人的平均水平”，而 GPT-6 Astra 的结果更是“insane”。它能控制电脑，有空间感知，能尝试重绘图像。作者认为，如果你在 ChatGPT 里说“use this at computer please control my computer”，这是 Codex 内置的技能或插件，它可以完全控制你的电脑。这个能力在远程使用时尤其有用：你可以从手机控制 Codex，基本等于控制桌面应用；你不在电脑前，也能让 AI 完全操作电脑。

他还提到竞争态势：看起来 OpenAI 在 computer use 方面正在稍微拉开与 Anthropic 的距离。然后他引用报道：OpenAI 据称购买了数万台 Mac mini 和 Mac Studio，用于强化学习和训练 computer-use agents；Anthropic 则通过 AWS 租用 Mac mini。两家公司都有数万台 Mac mini 和 Mac Studio 一直在运行，训练 AI、评估 AI 控制电脑的能力。

**个人感受**  
作者用“insane”反复形容。他惊讶的不只是模型会点按钮，而是它具备空间感知、能打开软件、操作画图、重绘图像，并且这种能力还在指数级提升。对他而言，这已经非常接近“AI 住在电脑里替你做事”。

**延伸思考**  
Computer use 是代理从“聊天框”进入“操作系统”的关键。一旦模型能可靠控制任意软件，所有软件都会变成 AI 的可调用工具，所有 UI 都可能被代理绕过或重写。安全、权限、审计、支付确认会成为核心问题。远程控制电脑也会让个人算力与代理常驻变得更重要。

**精华收获**  
- Computer use 的进步要关注“空间感知 + 软件操作 + 自我评估”组合。  
- 远程让 AI 控制家中电脑，是移动办公的新形态。

**核心观点**  
GPT-6 Astra 能在长任务中执行、评估、修改、再评估，甚至自己玩自己做的游戏来检查地图，直到达到指定结果。作者因此对 AI 产生了前所未有的信心。

**深度阐述**  
作者说，使用 GPT-6 Astra 后，他发现模型在“self-testing”上显著变强。意思是：你让它做一件事，不管任务多长，它会做；然后评估自己做得多好；决定需要改什么；做出修改；再重新评估，反复循环。他说这个话题从早期 Claude Code 时代就在谈，尤其在 vibe coding 中已经能自我迭代，但现在变得更好。

他的关键例证来自 Blender 和《使命召唤》地图。他让 AI 把整个地图加入《使命召唤》游戏，AI 跑了很久。它创建地图，然后生成一张图像：它让 Blender 在电脑上打开，截图，查看，评估，然后说：

> “the state now builds successfully as the third map on the game. I'm extending the vehicle system to helicopter boarding.”  
> “现在状态成功构建为游戏中的第三张地图。我正在把车辆系统扩展到直升机登机。” `[字幕 第5点]`

然后它开始玩游戏。它启动一场比赛，作为角色在地图中移动，进入直升机，驾驶直升机测试，检查地图看起来是否正常。它还去查看那栋房子。作者强调：他们要求 AI 把 PDF 变成 3D 模型，再变成视频游戏；在每一个阶段，AI 都通过实际玩游戏和查看图像来检查自己的工作。房子一开始非常白，纹理不对，AI 看到后重新提示自己。它在循环中自我重新提示。

作者说，他从未像对这个模型这样对 AI 有信心。他知道，只要自己指定想要的最终结果，并且这个结果在他电脑上现实可行，AI 就会一直工作到到达终点。除非遇到硬性付费墙，比如某个软件需要付费，它才会告诉他去付费。代理会迭代、迭代、迭代，测试、测试、测试，直到最终状态。

**个人感受**  
这是一种从“希望它一次做对”到“相信它会自己闭环”的转变。作者说“I've never felt so confident in AI”。这种信心不是盲目的，而是因为他亲眼看到 AI 在玩自己创建的游戏、检查自己生成的地图、自己发现纹理问题并修正。

**延伸思考**  
自我测试是代理可靠性的核心。未来软件工程、设计、游戏测试、数据清洗、运营任务，都可能由代理在“执行—评估—修正”的循环中完成。人类角色会转向定义目标、验收标准、权限边界和异常处理。

**精华收获**  
- 给 AI 明确、可验证、现实可达的最终状态，它更可能自主迭代。  
- 自我测试包括截图、运行、玩游戏、查看结果、重新提示。  
- 代理的瓶颈会从“不会做”转向“付费墙、权限、硬件资源”。

### 7. 第六个醒悟：GPT-6 Astra 与 Codex 配合时强得多 `[字幕 第6点]`

**核心观点**  
作者认为 GPT-6 Astra 是为 Codex 的工具环境打造的。在 Codex 中，它能控制电脑、使用浏览器、调用本地应用和 API key，因此是目前最值得学习的工具。

**深度阐述**  
作者说，这个模型“much better with codecs”——在 Codex 中好得多。他不确定是否绝对如此，因为你也可以在 Cursor 等其他工具里使用 GPT-6，但用 Codex 应用时，模型会显著更好。原因是这个模型是为 Codex harness 和 Codex 内的工具打造的。Codex 有大量有用工具，比如 computer use、browser use。浏览器可以本地启动、运行、快速填表、快速测试网站。模型就是为这种应用场景设计的。

他说：“I do not think there is a more important tool.”——“我不认为还有比这更重要的工具。” `[字幕 第6点]` 他会把学习 Codex 作为现在第一件要学的事。Codex 的 UI 很好，像 ChatGPT，但它能完全控制你的整个电脑。只要你打开完整访问权限，它就能做任何你想做的事。它可以用 Blender，可以查看 Blender，可以截图并发回 Codex，可以创建游戏、构建网站、编辑文件、删除文件、移除文件，做电脑上任何事。它有完整访问权，这是它强大的原因。

另一个关键点是：你在电脑上登录了所有应用，尤其是 GitHub 和 Vercel 等工具，Codex 拥有系统上的所有 API key。因此它运行在你的电脑上，能更快做事。你的浏览器标签都登录着，因为这是你的电脑。作者认为，这种“模型 + 本地环境 + 已登录账号 + API key”的组合，是 Codex 真正的威力。

**个人感受**  
作者把 Codex 称为“第一名要学的工具”。他的兴奋不只是模型智能，而是环境整合：模型不再是一个孤立聊天框，而是坐在你的电脑里，拥有你的工具、文件、账号和权限。

**延伸思考**  
未来 AI 代理的竞争力可能不只来自模型本身，而来自 harness：工具集、权限管理、浏览器、文件系统、API 集成、上下文持久化。模型公司会同时竞争“模型 + 代理框架 + 操作系统入口”。学习使用这些工具，可能像当年学习搜索引擎、Excel、Git 一样重要。

**精华收获**  
- 同一模型在不同代理框架中表现可能差异巨大。  
- Codex 的价值在于完整电脑访问、浏览器、本地运行、已登录账号与 API key。  
- 现在最该投入时间学习的工具之一，就是 Codex 式代理环境。

### 8. 第七个醒悟：Mac Mini 配置仍然至高无上 `[字幕 最后]`

**核心观点**  
作者的最大醒悟是：应该让一台 Mac Mini 常开，24/7 运行 Codex，并从手机、iPad 或笔记本远程控制，让 AI 代理随时可用。

**深度阐述**  
作者说，最后一个也是最大的醒悟是：“the Mac Mini setups remain supreme.”——“Mac Mini 配置仍然至高无上。” `[字幕 最后]` 他刚买了另一个 Mac Mini，还会用一台 Linux 机器，准备让 Codex 跑在这些电脑上。原因是：他现在在笔记本上用 Codex，但旅行或移动时，不能一直用笔记本跑 Codex。如果有一台常开的 Mac Mini 留在家里，他就可以随时随地远程使用。

他说自己和一些非常聪明的朋友聊过，准备本周做一个视频，讲运行 Codex 和其他代理的绝对最佳配置。你可以在 Mac Mini 上运行 Anthropic、Grok 等各种“超级应用”，然后从手机控制它们。如果你有 iPad 或 MacBook Pro，你可以远程控制家里一直开着、永不关机的 Mac Mini。他认为，如果你能完全远程控制 Mac Mini，让它运行 Codex，并且随时有一个 Codex 实例 24/7 在线，那会极其强大。

他还提到自己一直在用 GPT work，做工作自动化很有用，但很多编码工作与他创建文档、演示文稿相关，他希望所有东西都在一台机器上。所以他至少想要一个 Codex 实例或一台电脑 24/7 运行。他本周就会设置。

然后他做了总结：如果 AI 可以完全控制电脑，创建 3D 资产，创建视频游戏，按需 vibe code 任何应用，轻松托管，还能利用电脑上的一切自我测试、自我改进，直到“够好了，我们做到了”，而且它在 Codex 中强得多，那为什么不想要一台 24/7 运行 Codex 的电脑？这就是他最大的醒悟。

**个人感受**  
作者非常兴奋，不只是对模型，而是对“个人 AI 基础设施”的想象。Mac Mini 从一个便宜桌面电脑，变成常驻代理服务器、个人自动化中枢、随时可远程调用的工作机器。

**延伸思考**  
当代理需要长时间运行、控制 GUI、访问本地文件和登录态，云端纯 API 可能不够。个人或团队需要“代理主机”：常开、稳定、安全、可远程、可备份。Mac Mini 因为功耗、性能、macOS 生态成为作者首选。未来可能出现专门为 AI 代理优化的家用服务器、权限沙箱和远程控制协议。

**精华收获**  
- 让 Codex 24/7 常开，可以摆脱笔记本开关机和移动限制。  
- Mac Mini / Linux 机器可作为个人代理服务器。  
- 远程控制 + 本地登录态 + API key，是代理效率的关键组合。

### 9. 结尾：我们正进入 AGI 时代与指数级竞争 `[字幕 结尾]`

作者认为我们已跨入 AGI 时代：AI 会更快、更会控制电脑、更会 vibe coding。Anthropic 与 OpenAI 的竞争、IPO 压力与模型发布节奏，会继续推动指数级进步。

AI 会显著更擅长控制电脑，会继续变聪明，会更好地 vibe coding，会更好地完成电脑上的一切。他说自己现在“感觉到 AGI 了”——“I'm feeling it now. I'm feeling the age of AGI.” `[字幕 结尾]` 他认为我们处在 AI 的不同时代。第一个门槛是 Claude Code 在 2025 年初发布，但直到 2025 年中人们才真正感受到。现在，我们已经跨入类似 AGI 的时代。

**延伸思考**

**精华收获**

**整体精华收获**

这段视频的核心价值，不是证明“GPT-6 Astra 是否真的 AGI”，而是展示一个重度用户如何在真实工作流中感受到代理式 AI 的临界点。作者用 100 小时和 1,500 美元 credits 换来的不是几个炫酷 demo，而是一套正在成型的新工作方式：

6. **Codex 是当前最该学的工具**：模型 + 工具 harness + 本地登录态 + API key + 文件系统，构成强大的代理环境。
