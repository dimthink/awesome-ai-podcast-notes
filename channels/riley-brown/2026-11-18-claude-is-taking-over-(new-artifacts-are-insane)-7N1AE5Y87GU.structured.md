## 一、第一个原因：七种 Artifact 类型都非常出色，尤其是新的那几个

首先，Claude Code 之所以是企业最佳智能体平台，是因为它所有的 Artifact 类型都非常好用，尤其是新增的那些类型。现在我就在 Claude Code 里。让我给你展示你可以在 Claude Code 内部直接创建的七种 Artifact 类型：

- **白板 Artifact**：这是我为虚构公司 **Howyard Agent Works** 用一条提示创建出来的白板。就是这样一块白板，Claude 可以编辑所有这些内容。
- **设计系统 Artifact**：它允许你设置颜色、字体排印、间距、圆角半径。基本上，你可以为一个品牌创建一套设计系统，而 Claude 只用一条提示就完成了。
- **设计 Artifact**：这是 Howyard 的网站改版，展示在设计 Artifact 中，基本上就像 **Figma（协作设计工具）**。Claude 可以非常轻松地编辑它。你需要做的只是在不同部分发表评论；比如我可以直接说“我不喜欢这个颜色”，系统就会自动向 Claude 发送提示，让它进行修改。
- **幻灯片 Artifact**：这是幻灯片，它同样使用我们刚才创建的那套设计系统。
- **文档 Artifact**：这很像 **Google Docs（在线文档工具）**，就是一个可编辑的文本文件，非常好用；你可以在文档里创建多个标签页。
- **数据 Artifact**：这是数据 Artifact。
- **表格 Artifact**：这是我最常用的一个，它和 **Google Sheets（在线表格工具）** 几乎完全一样。

另外还有一个表格 Artifact 示例，真的非常出色，可视化效果很好。所有这些都可以在 Claude Code 内部创建，而且每一种 Artifact 类型都随时可以用 Claude Code 编辑。
