# 第二部分：八个工具全解

# 工具一：Raycast——所有AI工具的"中枢神经"

## [视频第1个工具演示段]

**核心观点**
Raycast是Riley整个AI工作流的启动器和调度中心。它不仅仅是应用切换器，还内置了剪贴板管理器。通过设置热键，你可以瞬间打开任何工具——包括AI助手——不碰鼠标、不点开始菜单。

**深度阐述**

Riley把Raycast列在第一位，因为它解决了"当我需要AI时，如何最快到达AI"的问题。他说"这是在我的所有应用之间机动的最快方式。" [视频第1个工具演示段]

**1. 变身超级启动器：热键直达所有AI入口**

演示开始时，Riley按下 `Alt + Space`，一个简洁的输入框浮现在屏幕中央。他输入"chatgpt"，按下回车，ChatGPT桌面应用应声打开；再按 `Alt + Space`，输入"grockbot"，又瞬间切到了另一个AI代理平台。这就是Raycast最基础的用法——**它取代了开始菜单和任务栏的结合体**。

但Raycast还能更进一步：为每一个常用应用绑定**专属热键**。Riley展示了几个自己常用的例子：
- `Alt + Alt`（连续按两次Alt）：打开ChatGPT桌面应用。
- `Windows + C`：打开Claude桌面应用（他在视频中现演示了设置过程）。
- `Alt + G`：打开Grockbot（团队AI代理平台）。
- `Alt + M`：打开剪贴板历史管理器。

设置路径也很简单：`Alt + Space`呼出Raycast → 输入"Shortcuts" → 回车 → 在延伸的列表中找到目标应用 → 点击"Record Hotkey"（录制热键）→ 按下想绑定的组合键。录完后，系统即设即用。

这个操作有多快？Riley在将Claude绑定到 `Windows + C` 后，立刻原地演示："我可以按下Windows C，Claude就会自动打开。这是现在在我电脑上打开的Claude应用。" [视频第1个工具演示段] 这种"零思考"的唤起方式，将AI工具的调用从"鼠标点击 ➜ 找到图标 ➜ 双击等待"的漫长过程，缩短为一次肌肉记忆级别的按键组合。

**2. 剪贴板管理器：给AI时代的信息流装上"内存"**

Raycast的第二个核心功能是剪贴板管理器。Riley说，这个功能在跟AI工具配合时尤其救命："我一直在复制东西，之后还想再用。" [视频第1个工具演示段]

他设置的是 `Alt + M`，呼出后可以看到所有曾经复制过的文本、图片、文件和链接。演示中，他复制了一段文字，打开面板后这段文字果然躺在列表顶部，按下回车即可直接粘贴到当前光标位置。更贴心的是，面板顶部还有筛选标签：文本、图片、文件、链接。你复制过的所有内容都自动保留，等于给剪贴板装上了"时间旅行的能力"。

设置方法：`Alt + Space`呼出Raycast → 输入"Clipboard History" → 右键点击 → "Configure Command" → "Open Command Settings" → 设置热键为 `Alt + M`。

**核心逻辑**：AI时代的信息流动变得极其频繁——从邮件复制一段指令到ChatGPT，从网页复制一段代码到Claude，从Notion复制一段文案到邮件……如果没有剪贴板历史，你随时可能丢失之前复制过的内容，而每一次"重新复制"都是生产力的隐性损耗。Raycast的剪贴板管理在这场信息接力中扮演了"记忆缓存"的角色。

**个人感受**

Riley在演示热键绑定和剪贴板功能时，就像一个老朋友在展示自己整理得井井有条的书桌。他语气轻快："这样，Alt M 就会自动打开剪贴板历史。就是这么简单。" [视频第1个工具演示段] 这种自信来自日常重复使用积累的肌肉记忆，而不是对工具的"纸面了解"。

**延伸思考**

这里有一个更深层的变化：**从"管理应用"到"管理指令"**。传统上，我们打开应用是为了在里面干活；而在AI工作流里，打开ChatGPT、Claude、Grockbot等一系列应用，最终都是为了"发送指令"。Raycast把你从"找图标"的琐碎中解放出来，让"指令"成为交互的核心。这是一种计算范式的转变，而Raycast在Windows上很好地扮演了这个角色。

# 工具二：ChatGPT桌面应用 + Codex——让AI真正拥有"手和眼睛"

## [视频第2个工具演示段]

**核心观点**
ChatGPT桌面应用是整套AI工作流中的"大脑"。特别是它内置的Codex功能（OpenAI的AI智能体），可以通过自然语言指令操控电脑、连接外部工具（如Notion）、创建应用和演示文稿，甚至在你不在电脑旁时由手机远程指挥它干活。

**深度阐述**

如果说Raycast是中枢神经，那ChatGPT桌面应用（以下简称ChatGPT）就是Riley这套系统的**执行力核心**。Riley毫不掩饰对它的偏爱："它能在你电脑上做任何事……你可以创建任何应用，创建任何类型的演示文稿，它还能完全控制你的电脑。" [视频第2个工具演示段]

**1. Codex：从"对话"到"操作"的关键一跃**

Codex加入了ChatGPT桌面应用，意味着ChatGPT不再是一个只会对话的聊天框，而是一个能调用电脑能力的Agent（智能体）。你可以让它：
- 在Paint软件里画一张图，并配上有意义的图表标题。
- 把Notion里的页面重新排版、添加内容、修改格式。
- 编写并运行代码，创建小型应用。
- 控制鼠标键盘，像人一样操作软件。

Riley在视频开头提到，"其中一个是ChatGPT桌面应用，这样我就能用上Codex" [视频第1个工具演示段]。他为此专门发布过一个2小时的长视频，详细介绍了Codex的28个使用场景。

**2. 连接插件：让AI掌握你的工作工具**

Codex的第一站是插件。Riley建议所有用户第一时间进入**插件（Plugins）标签页**，把现有工作流中用到的工具全部连接起来。他在视频中演示了与Notion的对接：只需在插件列表里找到Notion，点击安装，授权后ChatGPT就获得了"完全控制Notion"的能力。这意味着，过去你得自己手动打开Notion、逐页查找、点击编辑的操作，现在只要一句话，Codex就能替你做。

这背后的技术原理是MCP（Model Context Protocol，模型上下文协议），它让AI可以像人类一样通过标准接口读写外部工具。Riley在后面的Notion部分再次强调：Notion之所以和AI配合得最好，正是因为"他们有最好的MCP和工具设置，你可以非常容易地把它接入Codex"。

**3. Computer Use：让AI接管鼠标和键盘**

接下来是整段视频中最具未来感的演示之一。Riley打开ChatGPT，发出了一个几乎匪夷所思的命令：

"请你在Paint（画图）里创建一个图表，主题是AI创业公司的收入增长。"

然后他直接点击运行（Run）。ChatGPT的Codex开始接管电脑：打开Paint、选择画布、绘制图表、输入标题文字……Riley说："这是你让Codex完全控制你的电脑，并使用Computer Use功能的方式。" [视频第2个工具演示段] 在几秒钟内，一个原本需要人工打开画图软件、手动绘制标题和柱状图的任务，变成了一句话的事。

这个演示的意义是深远的：**AI不再只是分析数据或生成文字，它已经可以像一个虚拟员工一样操作软件界面。** 尤其当你面对的是那些没有API接口、没有命令行工具的传统软件，Computer Use提供了一种"人性化"的操作路径——它会模拟人的方式点击、输入、拖拽。

**4. 无缝集成进Raycast**

因为ChatGPT桌面应用是Riley最常用的工具，他专门在Raycast里为它设置了 `Alt + Alt`（双击Alt）热键。于是整套流程变得像连招一样流畅：`Alt + Alt`呼出ChatGPT → 输入指令 → Codex开始干活 → 完成后用 `Alt + Space`切换到其他应用查验结果。工具之间的切换，几乎不需要视觉搜索。

**个人感受**

Riley在演示ChatGPT控制电脑时，语调中带着一点"你看到了吗？"的兴奋感。特别是当他让ChatGPT在Paint里画出图表，以及向观众预告"很快我会展示如何用手机控制你的笔记本电脑"时 [视频第2个工具演示段]，那种对技术演进的兴奋是真实的。他把这种能力视为个人工作效率的"杠杆"，而不是一个玩具。

**延伸思考**

"Computer Use"背后代表着一场更彻底的自动化革命。当AI能控制界面时，**"整合"的成本突然大幅下降**。过去，两个软件如果API不开放，就要靠人肉复制粘贴来打通。而有了Computer Use，AI可以像人一样在中间"搬运"，哪怕两个软件之间毫无技术关联。这使得"让AI替你把活全干完"不再是一个遥远的设想，它正在发生。

# 工具三：Whisper Flow——把"说话"变成"打字"

## [视频第3个工具演示段]

**核心观点**
Whisper Flow是一个强大的语音转写工具，让你用嘴巴"打字"。这对每天要向AI发送大量指令的创作者来说，是效率的巨大跃升——尤其适合"话多手慢"型用户。免费版每周2000词；Pro版每月15美元。

**深度阐述**

Riley动情地坦白："我给这些AI提示框里打字的时间，比任何文档都多。而且，我是一个话痨（yapper）。我不喜欢把东西打出来。" [视频第3个工具演示段] 这句话捕捉到了AI时代的一个新场景：提示词正在成为我们最重要的"写作对象"。过去你打字最多的是邮件、文档、聊天软件；现在，你可能一天要向ChatGPT、Claude、Grockbot、Notion AI发出几十条指令——这些指令加起来，工作量大得惊人。

**Whisper Flow的用法**：
- 安装后，默认热键为 `Control + Windows` 键，按住即开始听写，松开即结束并自动将文字送入光标所在的位置。
- 首次使用时，只需在任何可输入文字的框里按下热键，开始说话，松开后文字就会自动"打"出来。
- 它在Mac和Windows上都能使用，Riley称自己在所有Windows电脑上都装了这个工具。

回顾这8个工具，我们可以梳理出一条清晰的"角色分工"：

3. **Whisper Flow** = 输入器官，把语音快速转化成文字指令。

6. **Claude Excel扩展** = 专业数据分析师，专门攻克表格和可视化。
7. **Notion** = 记忆库/知识中枢，存储和结构化管理AI产出的内容。
8. **手机远程控制** = 移动指挥中心，将"电脑前才能用AI"升级为"随时随地都能指挥AI"。

这套系统展示了未来个人生产力工具的几个关键词：**语音优先**（Whisper Flow）、**Agent化执行**（ChatGPT桌面/Codex、Grockbot）、**上下文常驻**（Chrome扩展）、**跨端遥控**（手机远程控制）、**知识沉淀**（Notion）。

**精华收获：你可以立即落地的行动清单**

2. **给ChatGPT桌面应用一个专属热键**（如`Alt + Alt`），养成"任何问题先呼出AI"的习惯。
3. **下载一个语音输入工具**（Whisper Flow或免费的Handy），凡是给AI下达长指令时，开口说，不要打字。
4. **在Chrome里装ChatGPT扩展**，浏览网页时顺手用侧边栏写总结、抓要点、甚至让它基于网页内容做深度分析。
5. **把Notion接入ChatGPT的插件**（通过MCP），让AI可以帮你创建、修改、整理笔记——把笔记库变成AI能操作的知识资产。
6. **如果你的工作需要大量Excel**，订阅Claude并使用其Excel扩展，用一句话生成专业表格。
7. **开启ChatGPT远程控制**，让手机成为你电脑的遥控器；如果你愿意让电脑一直开机，你相当于拥有了一位7x24小时的AI员工。
