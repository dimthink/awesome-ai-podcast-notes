# 嘻哈起源故事：传奇人物亲述从哈莱姆街头到全球的文化缔造

## 开场：致敬嘻哈文化的建筑师

在嘻哈成为一门全球生意之前，在世界理解这种音乐可能意味着什么之前，柯蒂斯·布洛（Curtis Blow）就已经在那里帮助创造历史了。

我们是从零开始建立了这种音乐和文化。我们当时甚至不叫它“嘻哈”。它被称为“摇滚”（rocking）、“霹雳舞”（breaking）、“燃烧”（burning）、“派对”（partying）。

**柯蒂斯，看着小乔伊（Joey）变成 Run-DMC，你是什么感觉？**

我记得他13岁时的样子。［音乐］

我以前保护他，不让他被拉塞尔（Russell）欺负。没人能碰他。就像电影《粉碎节奏》（Crush Groove）里那样。这个家伙，他曾经是我的心肝。现在依然是。

这位老兄说：“如果我能统治世界，你就已经统治过世界了。所以我必须和劳伦·希尔（Miss Lauren Hill）一起重做你的那首歌。兄弟，你喜欢那首歌吗？”

>> 天哪，老兄。我站在舞台上，和……对。所有我心目中的英雄。所有我心目中的英雄。嘿，你们知道吗，你们那时候看起来就像收音机一样。我小时候就这样。那音箱面板就是我一直盯着看的东西。我盯着收音机，就像在好奇：他们的生活是什么样的？

>> 嗯，我觉得我应该系一下鞋带。

>> 布洛先生，那双鞋也很不错。布洛先生，很干净。

所以，女士们先生们，今晚我们要庆祝的是这位文化缔造者之一。在嘻哈成为一门全球生意之前，在世界理解这种音乐可能意味着什么之前，柯蒂斯·布洛就已经在那里帮助创造历史了。对我个人而言，他的音乐也成了我自己旅程的一部分。所以，这场对话更多关于遗产，而不仅仅是唱片。它关乎这个人、他所开启的运动，以及他承载的传承。那么，让我们直接开始吧。柯蒂斯·布洛先生，王者。

## 第一章：回到哈莱姆——年轻的柯蒂斯·沃克

**那是什么样的感觉？带我回到纽约哈莱姆（Harlem, New York），回到唱片合约之前，回到热门唱片之前。年轻的柯蒂斯·沃克（Curtis Walker）当时在梦想什么？你是否想象过嘻哈会带你走遍世界？**

>> 哇。嗯，你知道，回到那些嘻哈真的、真的是全新的时候。我是说，我们当时甚至不叫它嘻哈。它被称为“摇滚”、“霹雳舞”、“燃烧”、“派对”。你知道，我们就是热爱音乐，我们想玩得开心。你知道，整个状况的背景是，我们刚从20世纪60年代的民权运动中走出来。我记得马丁·路德·金（Martin Luther King）被暗杀。马尔科姆·X（Malcolm X），你知道，肯尼迪（JFK）、罗伯特·肯尼迪（RFK），你知道，社区组织者当时在和活动人士、政府官员进行辩论和抗议，他们在争吵。那个时期是创伤性的。

但有一位社区组织者写了一本书，他有一句话是这样的。他说：“你知道，街道一边的建筑在燃烧，但另一边的孩子们正试图把什么东西拼凑起来。”

你知道，我不知道你是否了解70年代的布朗克斯（Bronx）。有一部纪录片叫《布朗克斯在燃烧》（The Bronx is Burning），等等。还有，房东们会直接纵火，你知道，把自己的房子点着，只是为了骗取保险金。所以每个街区都有被烧成平地的建筑。所以我们也经常在这些废弃建筑里闲逛，你可以进去。我们第一次看到类似涂鸦的东西，你知道，一个人用马克笔在墙上写字：“我的名字是约翰。我在这里。现在我不在了。所以现在你知道了。”［笑声］

所以，你知道，那是涂鸦，但它像是城市的衰败。我还记得总统来到纽约，他拒绝给我们钱，因为当时纽约已经破产了。所以，我记得报纸上写着：总统拒绝向纽约市提供联邦援助来清理城市，因为那些建筑和一切的衰败状况。但是，你知道，我们就是从那个时代、那个时间点走出来的，那时我们一无所有。我们什么都没有。我们是从零开始，用一无所有建立了这种音乐和文化。

>> 绝对是。

>> 一无所有。只有对音乐的热爱，你知道，这非常非常重要。你知道，对我们来说，那更像是一种逃避。我记得去俱乐部，把脑袋贴到音箱上，听着低音一直震到脚趾，我会闭上眼睛，整个人就飘走了。对我来说，那就是嘻哈。

>> 你当时听的是迪斯科音乐吗？

>> 呃，这是个好问题，因为那确实是迪斯科。我是那个时代的狂热支持者。迪斯科音乐非常非常重要。就像我说的，你知道，我们刚从民权运动中走出来，然后我们有了投票权，然后有了嬉皮士和花童，你知道，“爱你的邻居”运动，跳舞成了我们最大的消遣。每个人都会工作一周。你辛辛苦苦工作一周。你去迪斯科舞厅或者市中心俱乐部，那里有频闪灯和迪斯科球，灯光闪烁，每个人都打扮得体面，西装领带、丝绸裙子，我们整夜跳舞，就是这样。所以，嘻哈就是从那个时代诞生的。

>> 是啊。我称之为迪斯科的突变。

>> 哇。更进一步说，它是“贫民区迪斯科”（ghetto disco）。

>> 对，我喜欢这个说法。［清嗓子］

我来自贫民区。我住在哈莱姆。我没钱付那些俱乐部的门票。所以，1975年，我16岁。我在42街（42nd Street）弄了张假身份证。对吧？它把我变成了21岁。

>> 哇。

>> 这样我就能进所有的俱乐部了，老兄。我去了利维戈塔斯（Levigotas）、尼莫（Nemo）、内金斯（Neguins）、超级明星（Superstar）、自助餐厅（Cafeteria）、外交官酒店（Hotel Diplomat）、伊波尼玛斯（Iponymas）、车库（Garage）。老兄，我都在场。你能说出来的，我都去过。我去了纽约市的每一家迪斯科舞厅，因为我在学习成为一名 DJ。所以，我想见识所有不同的风格，做我的研究，弄明白。好吧，是的。于是我跑到布朗克斯的 DJ 霍洛威（DJ Holloway）那里，371号俱乐部。

>> 我以为他来自哈莱姆。DJ 霍洛威？

>> 他来自哈莱姆，但他在371号俱乐部——“欢乐与乐趣之家”（House of Joy and Fun）是第一名。

>> 就是这样。我看见他。他外面排着绕街区的队，人们都想进去。老兄，我亲眼看见这人在麦克风上做出了一些我从未听过的不可思议的事情。我现在已经是一名 MC 了，对吧？我从1974年起就在哈莱姆的“沃姆”（Wham）俱乐部做 MC，或者说唱。

>> 74年。

>> 74年我就开始做 MC 了。我试图模仿我收音机里的英雄。他的名字叫汉克·斯潘（Hank Span）。WWRL 超级16频道，在服务器上。［笑声］

>> 哇。

>> 所以，我就在一家叫“沃姆”的俱乐部里模仿他的声音。那是一个旧警察局，在阿姆斯特丹大道（Amsterdam）的山丘上，152街，战场公园（battlegrounds）对面。我知道你听说过战场公园。151街和152街之间。那儿有个公园。我们就在那里对战。呃，但不管怎样，

>> 这是真实历史，各位。

>> 那是我的第一份工作。

>> 真实历史，真正的纽约历史，也是嘻哈历史。

>> 对。所以，对于一个亲历者来说。

## 第二章：被发现与被签约——首位签约大厂牌的饶舌歌手

**那么，你是怎么被发现的？抱歉打断你。柯蒂斯·布洛是怎么被发掘为饶舌歌手，并签约成为第一位签约大厂牌的饶舌歌手的？**

>> 嗯，随着岁月的流逝，你知道，我说服了拉塞尔。我和拉塞尔是77年在大学认识的。呃，其实我比他早一年上大学。我17岁时认识了拉塞尔，并说服他来我在哈莱姆的街区听我做 DJ。

所以，我一切都安排好了。我有我的团队，我的队伍，我整个街区的人都在那里。那里挤满了人。我们大概有150人在一个家庭派对上。我坐在那里，正在做我的全套好莱坞式表演。我喊着“举起你们的双手，像不在乎一样挥舞。如果你穿着干净的内裤，就喊‘哦耶’。”

“哦耶。”［笑声］

对。然后有人尖叫：“哦，所有这些花样。”人群的反应，他听到了，我们的人群，都是安排好的，你知道，当他进来的时候。我说：“好，开始。”对。然后我们放起了《美好时光》（Good Times）。天哪。［笑声］

诺·罗杰斯（Nile Rodgers），你知道，所以我为拉塞尔表演了《美好时光》，然后我们就成了朋友。呃，回到学校，我学的是传播学，那是我的专业。我在传播学课上学到：如果你想在大城市成功，你知道，纽约，我们当时竞争很激烈，至少50名 MC，在78、79年那会儿。所以，呃，我说，呃，我学到：如果你想竞争，就去城市的边缘，就是我们所谓的“荒郊野外”，给自己攒一份业绩记录，你知道，在这个市场拿第一，在那个市场拿第一，然后再回到大城市说：“嘿，老兄，给我个机会。我在这里是第一，我在那里是第一。你知道，我在做我的事。我有业绩记录，巴拉巴拉巴拉。”对，这就是你如何成功获得任何机会的方法。然后我就说：“拉塞尔，让我们在你的街区开一家俱乐部吧。”我们开了“夜热迪斯科”（Night Fever’s Disco），那里就是我遇见罗恩（Ron）和乔伊（Joey）的地方。所以，我过去常常周末去那里，住在他家。

>> 我以前经常给你们做早餐。

>> 对。［笑声］

所以，我们成了一个大家庭。我去了罗恩家，你知道。呃，我以前发传单，把传单贴到牙买加大道（Jamaica Avenue）上。那是我的第一份工作——贴传单。

>> 拉什制作公司（Rush Productions）。

>> 没错。

>> 拉什制作公司。而库尔特（Kurt）作为推广人，和拉什制作公司一起。他们推广库尔特。他们都上了纽约市立学院（CCNY），对吧？我当时只是个想入伙的小孩。所以只要能入伙，我什么都愿意做。无论是做早餐、给他们拿袜子，还是别的什么。我记得我父亲带他去商店。我只是伺候他们，想方设法混进去，然后库尔特把我纳入他的羽翼之下。

>> 没错。而且，你知道你讲的那个你摔断胳膊的故事。

>> 是的。

>> 是手腕。

>> 我的手腕。

>> 我以为是胳膊。

>> 不，是手腕。我摔断了手腕。好吧。

>> 我当时心碎了，因为不仅手腕断了，心也碎了，因为我没法去巡演了，因为我是他的 DJ。

>> 对。但你当时多大，罗恩？

>> 我大概14、15岁。

>> 你看。所以，我以前经常住在他家，对吧？因为我周末要出门，带着整整两箱唱片，坐火车、坐公交，等等。然后我开始开出租车。

>> 你在成为饶舌歌手之前就是 DJ。

>> 哦，对。对。

>> 他有点像 DJ 和饶舌歌手的混合体。

>> 当然。是的。是的。是的。我记得。你们两个都是。

>> 对。我一开始是当 DJ。但有一件事，像乔伊以前，他有个阁楼，在楼上，对吧？

>> 对。我从我哥那里接手过来的。

>> 他和整个团队以前都待在那儿。他爸给他买了一些唱机。

>> 唱盘。没错。但不，是你付钱给我买的唱盘。

>> 啊。

>> 以前每场演出给我35美元，那时候那可是一笔巨款。然后我买了一些昆塔斯牌（Quantas）唱盘。我没能买到技术牌（Technics）。还记得昆塔斯吗？我以前做 DJ。我变得非常快。我以前快到你只能抓住空气。

>> 他太棒了。不可思议地抓住空气。

>> 没什么。这位女士刚想说什么。我们有一场演出。他会自己出来 DJ 一小会儿，然后我出来，甚至都不自我介绍，就开始 DJ。然后他会拿起麦克风开始说唱。

>> 对。我就是在那儿认识我妻子的，在一个长岛（Long Island）的演出上。

>> 然后在他唱了几首之后，他会回到唱盘前，刮出我们的开场曲。对。然后我开始演出。这就是我想到介绍他的方式，然后他们喊：“柯蒂斯……［清嗓子］布洛！柯蒂斯·布洛！”是我想出来的。

>> 那是他的主意。

>> 然后等我成为独立的自己后，他再介绍我出场：“Run！”哇。所以，我当时想，我可以拿一张唱片，刮出他的名字，然后介绍他出场。我就是这么做的，直到我摔断了手腕，然后我就把它传给了戴维（Davey），他们就会放《圣诞说唱》（Christmas Rapping），然后你介绍柯蒂斯·布洛出场。等到我成为 Run Jay 的时候，我告诉杰（Jay）介绍我出场：“Run！”

>> 真是疯狂。

>> 真是不可思议。

>> 真实故事。

## 第三章：看着“小乔伊”成为 Run-DMC

**柯蒂斯，看着小乔伊变成 Run-DMC，你是什么感觉？因为你指导过他。**

>> 老兄。我的天。我记得他13岁时的样子。我以前保护他，不让拉塞尔欺负他。

>> 对。对。

>> 没人能碰他，在任何地方。就像电影里一样。

>> 他就像我的儿子。

>> 就像柯蒂斯·布洛的儿子。就像电影《粉碎节奏》里那样。

>> 一切。

>> 这个家伙，他曾经是我的心肝。现在依然是。

>> 是的。

>> 我的心肝。我很幸运能拥有他。

>> 是的。是的。

>> 他照顾我。我甚至不知道为什么。我想不通我是怎么和柯蒂斯·布洛搭上关系的，但能和柯蒂斯·布洛在一起，是我巨大的荣幸。然后我们一起拍了电影，《粉碎节奏》，还一起巡演。

>> 这是我最喜欢的电影之一。我不知道你们有没有看过《粉碎节奏》。如果没看过，你一定得看看。1985年上映。这些兄弟们当时就在做这件事。我去电影院看，整个人都疯了。实际上我昨晚和 Doc 聊过，他说他提到了这部电影，还说到你和兄弟争吵的那场戏。

>> 对。

>> 然后你走上舞台。我不知道你想不想分享这个。

>> 我会和观众分享的。你是从哪儿得到这句台词的？

>> “这是我他妈的地盘。”我是从艾迪·墨菲（Eddie Murphy）那里学来的，因为艾迪·墨菲讲过关于他父亲说“这是我的房子，这是我的房子”的笑话。［笑声］“如果你不喜欢，你可以滚出去。”我以前总这么说。然后杰说：“你应该在台上说这句话。”我就说：“什么？说这句话？”我当时说：“这是我他妈的地盘。”然后我告诉了艾迪。艾迪说：“滚开。”我说：“不，我是从你那儿学来的。”他说：“因为我受艾迪启发，因为他住在长岛，他离得很近，他太有趣了，我的‘我他妈的地盘’就是这么来的。”

>> 你想出了这段。有很多超级巨星。拉塞尔想出了那段，因为我和库尔特，还有他制作的“胖男孩”（Fat Boys）一起巡演。他制作了“胖男孩”。他制作了一些 Run-DMC。而我的工作……我是说，我知道他是我父亲，但你会和父亲有竞争感。所以我今天很高兴我能给他献花，因为我曾经是个坏孩子。我一度不是个好儿子。我不是个——

>> 不，我是个坏父亲。

>> 嗯，他是个坏父亲，所以我也坏。我当时只想诅咒所有人。所以我以前出场就说“这是我的房子”，我扔麦克风架，表现得疯疯癫癫。我不知道我从哪儿学来的，但呃——

>> 这是皇后的做派。

>> 是从库尔特那里学来的吧，我猜。

>> 而且库尔特是血亲。

>> 你知道他们以前在演出结束还会做什么吗？他们说——

>> 或者把麦克风砸下去。

>> 他们以前把麦克风砸下去。我们正处在——

>> 我能想到的每一种态度。

>> 他们每晚都在砸麦克风。于是音响师来找我。音响师说：“库尔特，库尔特，求你了，求你了，你能跟他们说，让他们别再砸麦克风了吗？因为他们每晚都在弄坏麦克风。我们还要——”他和我，还有杰西·杰克逊（Jesse Jackson）之间。

>> 对。让他们停止骂人。

>> 不，不。我当时说：“不，就让他们赔钱好了。”

>> 我赔了钱。［笑声］

>> 你会因此赚到钱的。我做了我该做的，但我没有停。而你就像是第一个和大型巡演一起演出的嘻哈艺人，和诺·罗杰斯以及所有其他大牌乐队一起，对吧？

## 第四章：与传奇同台——从鲍勃·马利到迈克尔·杰克逊

**那是什么感觉？作为那个说唱小子，在一大群还没见识过说唱音乐的大牌中间，参加那次大型巡演？**

>> 马文·盖伊（Marvin Gaye）、鲍勃·马利（Bob Marley），他是大咖中的大咖。

>> 你是说鲍勃·马利？

>> 他当时在巡演。有一天戴维生病了，我正准备架起唱盘为他做 DJ，在花园（Garden）演出，当时他和鲍勃·马利同台。库尔特就是那么老派、那么伟大。他和有史以来最伟大的乐队同台过。

## 尾声：致敬与“全额付费”荣誉

尚特（Shante），女王，你有什么最后的话吗？

>> 当我坐在这里的时候，大家都在想我会说些什么。我只需要你们明白这一点。你们现在眼前看到的，正是《全额付费》（Paid in Full）所真正反映的。看，《全额付费》不是关于任何人对行业中发生的任何事情的个人感受，而是关于对嘻哈的热爱，关于一个人的成就，以及他们的爱、他们的热情、他们对嘻哈的贡献。而当我坐在这里，我们所有人都坐在这里，我们听到这个人谈论他的热情，他从一开始就在那里，在斗争中确保嘻哈成为今天的样子。所以，他成为《全额付费》的荣誉获得者，才是唯一正确的。所以，我现在望向他，我对你说，我爱你。
