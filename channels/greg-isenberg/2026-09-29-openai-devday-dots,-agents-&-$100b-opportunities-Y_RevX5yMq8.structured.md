## 重磅发布一：Dots —— 个人智能体平台

正如我所说，今天有 20 多项功能发布。对我来说最重要的、也是我觉得最有趣的是——让我们先从 **Dots** 说起。

**Dots 是 OpenAI 推出的个人智能体平台**，是他们对 Meta 的 Muse 以及 Instinct 的回应。它最酷的地方在于，他们现在有了一个**前门入口**，让你能够触达 **12 亿周活用户**——这是 Sam Altman 今天公布的数据。

人们会去使用他们的个人智能体平台 Dots 并提出请求，他们会说：“我需要把这个许可证搞定”或“我有这个需求”或“我在找一家做某某菜的餐厅”。ChatGPT 会理解这个任务，然后你制作的插件——本质上就像一个**迷你应用**——会被选中来执行这项工作。我们稍后会讨论如何让插件被看到，但他们基本上已经宣布：**插件（Plugins）是未来重点，他们要加倍投入。**

我记得 Sam 说了类似这样的话——他不是原话，我是在转述——大意是插件之前收到过一些“褒贬不一的评价”。他们现在**加倍押注插件**。我相信 Sam 会让插件成为一件大事，他会尝试把 ChatGPT 打造成**AI 的应用生态系统**。这是今天一个巨大的公告，我们待会儿会更深入地聊。

所以，你的生意应该是：去解决客户的需求。比如，如果客户需要补办许可证，你的公司就去完成这个文件申请——以许可证公司为例——然后你把结果交付。**这就是新的应用生态系统，你需要把这个观念刻进脑子里。**

你必须想清楚如何专注于正确的客户。ChatGPT 会理解任务并完成分配，而你需要创建**正确的插件**来做正确的事，真正产生好的结果。因为如果你能做到这一点，你就可以在客户知道你的名字之前就被“雇佣”。你能触达 **12 亿周活用户**，我们说的是我在开场时提到的**数十亿美元的交易额**。

我说得甚至还算保守的。我认为，说 10 年、15 年、20 年后个人智能体平台上将发生**数万亿美元**的交易量，并不疯狂。但咱们保守一点，就说有数十亿美元的交易量吧。

现在明白了这一点，我们回到 DevDay 的官网上看一下——这就是他们的个人智能体平台。

## 重磅发布二：Decision API —— 实时决策能力

今天宣布的另一件事是 **Decision API（决策 API）**。我上周刚做了一个关于 **Jev** 的视频，这个 API 就是他们对 Jev 的回应。你看，他们有了对 Muse 的回应（Dots），这是他们对 Jev 的回应。

> **Decision API** 通过将 Luna 的智能聚焦于一组特定的、由用户定义且带有有限预定义答案的问题，实现**实时决策**。开发者可以提供文本或图像形式的上下文，并获得可用于**内容分类、请求路由或选择智能体下一步行动**的答案。

目前它处于**限量预览**阶段。我很期待去试试。我最近对 Jev 非常着迷——真的非常着迷。我觉得 Jev 有一大堆被大家忽视的、服务不足的使用场景。

其中一个我觉得特别有意思的是 **UI 设计**。你怎么用决策 API 来帮你生成转化率最高的应用商店截图，或者直效营销网站和应用？这里有巨大的机会。问题是：OpenAI 的 Decision API 会比 Jev 更差、持平还是更好？**答案未定（TBD）**，我们很快就会知道，但我觉得值得关注。

## 重磅发布三：Agents API —— 支持计算机操作

今天另一个我觉得非常有趣的重大发布是：**Agents API 现已支持计算机操作（computer use）**。

> 开发者可以构建**与软件交互以完成任务**的智能体。它还引入了 Codex 的多智能体能力、工具搜索、工具调用和上下文压缩功能，全部集成到你的应用中。**OpenAI 负责运行底层基础设施**，因此你的团队可以专注于构建应用程序。

我之前谈到过这一点，比如“垂直整合”（vertical harnesses）。你可以看到，OpenAI 是一个**托管式基础设施**。所以，如果你拥有优质数据、强大的品牌，或者你比其他人更懂某个垂直领域，那么构建应用就有巨大的机会。

这就是为什么我今天就会去玩 Agents API——去搞清楚你能构建什么，如何把你的业务延伸到这个世界。这是一个**全新的界面**，就像思考如何创建 AI 原生应用。我觉得这里面有很多机会，而且没有多少人在做——这显然让我很兴奋。

## 重磅发布四：使用 ChatGPT 登录 —— 被低估的巨变

另一个“低调但重磅”的公告——它的低调程度让我甚至不确定它是否在这个页面上。但当我看到它时，我简直**震惊了**。

简单来说：**你现在可以在第三方网站上用你的 ChatGPT 账号登录，并使用你的 Token 配额。**

这将以与当年 Facebook 推出登录功能相同的方式，打开**成千上万个商业机会**。Facebook 登录当年催生了数千家商业机会，实际上创造了许多数十亿美元的公司。

想想 **Yelp** 这个例子。我记得 Yelp 刚出来的时候——你可以去看看他们早期的产品——那基本上就是一个“用 Facebook 登录”的产品，你能看到本地评论，看到你朋友留下的评论。它利用了 Facebook 社交图谱，所以能做得更多。

那么我在哪里看到机会？我们稍后会深入讨论，但我在“使用 ChatGPT 登录”中看到的机会是：

现在你可以**创建一个免费应用**。你不向用户收费，所以你的漏斗顶部变大了——用 ChatGPT 登录即可。然后你可以从那里**向上销售**其他产品和服务。这是一个**非常非常非常重大**的事情。

### 为什么这对应用开发者是历史性的机会

回到我这边，这是我对 ChatGPT 登录的思考梳理。

我觉得很多人看到 AI 应用时会想：我真的要为另一个 AI 应用每月花 20 或 30 美元吗？不。现在你可以直接**用 ChatGPT 登录，开始使用你已有的套餐**。

所以，如果你够聪明，你会把核心应用做成**免费**的，然后对高级功能收费。你可以对企业版收费，对团队共享收费，对更多数据收费。但现在的机会是，**你可以免费提供核心应用了**。

在过去，你做不到免费提供核心应用，因为你得支付推理成本。但现在，你只需要专注于你的业务：建立分销渠道、建立品牌、获取数据集——显然要把这些用户从品牌带入应用，让他们使用它。当他们开始看到价值时，再向他们**向上销售**其他东西。

### 基于 ChatGPT 登录的创业点子

这里有一些你可以围绕登录功能去做的点子：

- 一个**清理建筑 CAD 文件**的智能体；
- 一个**监测某个特定科学领域**的研究助手；
- 一个 **Shopify 目录清理**桌面应用；
- 一个围绕**某种可重复剪辑工作流**构建的视频制作工具；
- 一个针对**某一种特许经营协议**的合同审查工具。

本质上，这里的机遇是什么？**这些微小的 AI 垂直品类，在今天是不可行的、经济上走不通的——但从今天起，它们变得可行了。**

你想构建这些**小众到不足以成为 OpenAI 主要功能**的产品，但你拥有足够的受众，可以通过向上销售和这个工作流来收费。所以我认为这真的是一件大事。我为此非常兴奋——我的思维在飞速运转，实际上我已经停不下来了。

### 卖工作流，而不是卖 Token

现在我们可以专注于**销售工作流**了，没错——**销售工作流，而不是销售 Token**。

所以，如果你正在构思，想在智能体时代建立一门生意，你要问自己：你拥有什么专有信息？

- 一个**专家级工作流**；
- 对**外部系统的访问权限**；
- **协作和审计追踪**能力；
- 一个**人力或供应商网络**；
- 一个**可衡量的业务结果**。

这些是我们应该关注的重点，我们不必真的再纠结于 Token。

而且，你的应用也会获得**更多用户**。你拿到他们的电子邮件，可能还有电话号码。然后你可以给他们发邮件，在那些邮件里卖广告。现在你能做的事情多太多了——这真的非常、非常有意思。

## 我的思维模型：触发 → 决策 → 行动 → 反馈

我想聊聊我对这个新世界的思维模型——现在我们有 Decision API、ChatGPT 登录、Dots、Agents API。我如何思考在这个世界里建立一门生意？

对我来说，这是一个**四步框架**：

1. **触发（Trigger）**
2. **决策（Decision）**
3. **行动（Action）**
4. **反馈（Feedback）**

会有某个**触发**事件发生。比如一张发票到期了，库存告急，或者报税季到了。发生了某件事，促使我去 ChatGPT 寻求帮助，或者它自主完成。

然后是**决策**。ChatGPT 会想：好的，我接下来该做什么？

然后是**行动**。比如有一个“更正”、有一个“提交”，应用程序有能力去做某件事。

然后是**反馈**：它是被批准了？还是被拒绝了？

我认为，**最强大的企业会拥有四个环节中的两到三个**。它们会拥有触发、行动和反馈。所以当你在构思和头脑风暴时，我会专注于这三件事。

## 值得关注的两个高潜力商业方向

我想给你一两个点子，让你的创意流动起来——想想在 Sam Altman 和 OpenAI 团队推出这些东西之后，你还能构建什么别的业务。

### 方向一：现实世界 API（Real World API）

在一个预计有数百万用户去 Dots 提出请求的世界里，有些请求是数字化的，但也有一些是**结构化的现实任务**。如果你能想办法找到经过审核的现实世界专家，我认为这是一个**巨大的机会**。

比如：永久性许可证加急办理员、报关经纪人。然后你收取交易费。

我的观点是：现实物理世界里正在发生大量的事情。很多人会关注数字领域的东西。**你怎么能在特定细分领域创建现实世界工作 API**，把 Dots 或 ChatGPT 连接到现实世界的工人，让他们完成交易的“最后一公里”？这是一个巨大的机会——我把这个点子放出来。

### 方向二：智能体发现的分析与优化平台

第二个方向：**谁会来构建用于智能体发现的分析和优化平台？**

我不是唯一一个现在在思考构建插件的人。此时此刻，可能有成千上万的公司正在想：我到底怎样才能在 Dots 里获得曝光？不仅是 Dots——怎么在 Muse 里获得曝光？怎么在谷歌的 Gemini 平台里获得曝光——我记得它叫 Spark？还有 Instinct、Grokbot，所有这些个人智能体平台——你怎么让你的插件被看到？

有些平台有插件，有些还没有。但我认为最终它们都会有的。

如果你能创建一个**分析平台**，它能：

- 生成现实的间接提示词；
- 衡量哪个插件被选中；
- 跟踪按客户意图划分的激活份额；
- 发现元数据和工具定义问题；
- 衡量调用是否转化为完成；
- 测试每一次插件更新。

这里有巨大的机会。就像在网络时代，出现了 Mixpanel、Amplitude，Google Analytics 是个巨大的产品。我认为会有大量的分析产品出现，帮助你在智能体生态中被看见。

你其实已经在 AEO（答案引擎优化）和 GEO（生成引擎优化）领域看到了这一点。Profound 公司以大约 20 亿美元甚至 10 亿美元的估值融资——一个高得离谱的估值。我觉得他们配得上，他们正在制造大量热度，产生大量收入，也在解决一个真实的问题。

我的重点是：**谁会成为个人智能体时代的 Profound？** 这是一个巨大的机会。我希望有人能抓住它。
