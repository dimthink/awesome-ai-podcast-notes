**核心观点**

Greg 原本不打算录这期，但 Sam Altman 的发布让他确信：围绕 ChatGPT 生态构建业务的人，将能瓜分数十亿美元的交易流。

**深度阐述**

Greg 的开场极具个人色彩。他没有用"今天 OpenAI 发布了什么"这种常规播报方式，而是以一种近乎道歉的口吻说："I got to be real with you. I didn't think I'd be making this episode of the podcast, but I just watched almost 60 minutes of Sam Altman up on stage and he launched a few things that I think are going to make people in aggregate billions of dollars."——"我跟你说实话，我本来没打算录这期节目，但我刚刚看了 Sam Altman 在台上近 60 分钟的演讲，他发布的一些东西，我认为将让一批人合计赚到数十亿美元。"

他紧接着强调："And I don't think that's a stretch."——"我不觉得这是夸张。"对他而言，这并非情绪化的断言，而是一个可推算的结论。

Greg 观察到的关键事实是：今天有大约 20 项功能发布，但其中只有三四个足够巨大——大到那些想明白如何利用这些功能的人，能够从 ChatGPT 平台内部正在发生的数十亿美元交易中分得一杯羹。他说："the people who figure out how to use those features and to grab a slice of those billions of dollars of transactions that are going to be happening within the chat platform... they're going to be able to create some really, really big businesses."——"那些想明白如何使用这些功能、并抓住 ChatGPT 平台内将要发生的数十亿美元交易中一份的人……他们将能创造出一些真正、真正的大公司。"

在简要自我介绍后（三次创办并出售风投支持的公司，Reddit 和 TikTok 前顾问），Greg 给出了这期节目的承诺：他会过滤掉噪音（cut through the noise），把当天最重要的商业信号提炼出来，并提供想法和框架，让听众能够"切一块蛋糕"（grab a slice of that pie）。

为什么一个人能从发布会中读出"数十亿美元"？这背后是一种平台迁移的历史直觉。从苹果 App Store 到 Facebook Login，每次平台开放新接口，都会有一批人通过抢占新渠道而暴富。Greg 显然在用这套历史剧本理解 OpenAI 的这次发布——而接下来的内容也确实按这个逻辑展开。

## 二、Dots：个人代理平台，AI 时代的"新应用商店" `[字幕位置：Dots 介绍部分]`

**核心观点**

Dots 是 OpenAI 对 Meta 的 Muse 和 Instinct 的回应——一个个人代理平台，背后连接着 12 亿周活用户。插件（Plugins）被重新押注，ChatGPT 要成为 AI 时代的应用生态系统。

**深度阐述**

Greg 将 Dots 定义为"the personal agent platform"（个人代理平台），并明确指出它是对 Meta 的 Muse 和 Instinct 的竞争性回应。这个功能之所以关键，是因为它给了开发者一扇"前门"（front door）——通向 Sam Altman 当天宣布的 1.2 billion weekly active users（12 亿周活用户）。

Greg 描述了一个未来场景：用户会走向 Dots，向它提出真实请求。他们可能会说："I need this permit fixed"（我需要把这个许可证办妥）、"I have this request"（我有这个申请）、或者"我找一家做这个的餐厅"。ChatGPT 会理解这个任务（job），然后从众多插件中选择一个来执行——而这个插件，本质上就是一个迷你应用（mini app）。"your plug-in that you have made... is going to get selected for the work"——"你制作的插件……会被选中来做这项工作"。

关于插件的往事，Greg 的转述很有意思。Sam Altman 并没有直接说"插件失败了"，但他说到了"mixed reviews"（褒贬不一的评价）。不过，OpenAI 现在的姿态是加倍押注插件（doubling down on plugins）。Greg 对此的判断是："I believe Sam that he's going to make plugins a thing, and he's going to try to make ChatGPT the app ecosystem for AI."——"我相信 Sam，他会让插件成为现实，他会努力让 ChatGPT 成为 AI 的应用生态系统。"

这背后的商业逻辑非常清晰：如果 ChatGPT 理解任务、而你的插件负责交付结果，那么你的业务就获得了前所未有的分发渠道。Greg 用一句话点破了这个时代的渠道权力转移："you can be hired before the customer knows your name"——"你可以在客户知道你的名字之前就被雇佣。"品牌认知不再是最重要的获客方式，出现在 ChatGPT 的插件推荐里才是。

关于市场规模的估算，Greg 给出了一个惊人的量级判断："I said in the intro like billions of dollars of transactions. I'm even being conservative. I don't think it's crazy to say that in 10, 15, 20 years that there's trillions of dollars of transaction volume happening within personal agent platforms."——"我在开场说了数十亿美元交易。我甚至觉得这是保守的。我认为 10、15、20 年后，个人代理平台内发生数万亿美元的交易量，这并不疯狂。"但他也刻意提醒：让我们保守一点，先聚焦于"数十亿美元"这个量级。

**视觉/结构信息描述**

在讲解 Dots 时，Greg 切换到了 DevDay 官网页面，边展示边说"here's their personal agent platform"（这就是他们的个人代理平台）。视频中应该有 Dots 的产品页面截图和官方介绍文字。虽然字幕没有给出页面细节，但可以推断 Greg 是在用官方页面作为视觉辅助，帮助观众把"个人代理平台"这个概念落到具体产品上。

**个人感受**

Greg 对 Dots 的态度是"必须刻进脑子里"级别的重视。他说："You need to drill this into your brain."——"你需要把这件事刻进你的大脑。"他反复强调的是：ChatGPT 负责理解任务，你负责创造正确的结果。这一分工意味着创业者的核心能力不再是"做出一个 App"，而是"做出一个能真正交付结果的工作流"。

**延伸思考**

Dots 的深层意义在于：AI 代理正在成为新的操作系统界面。用户不再"打开应用"来办事，而是直接告诉代理"我要什么"。这颠覆了传统 SaaS 的交互模式——过去是"用户在你的产品里完成任务"，未来可能是"用户在 ChatGPT 里表达需求，你的产品在后台完成任务"。对现有软件公司来说，这是一个生存级别的挑战：如果你的产品不能被代理调用，你可能会被排除在用户旅程之外。

**精华收获**

- 插件是新的应用商店入口，12 亿周活用户是前所未有的分发红利。
- "被雇佣在用户知道你的名字之前"——渠道权力从品牌转向平台推荐。
- 创业者应该聚焦"交付结果"，而非"理解意图"——后者是 ChatGPT 的事。

## 三、Decision API：把"决策"变成可编程的基础设施 `[字幕位置：Decision API 部分]`

**核心观点**

Decision API 是 OpenAI 对 Jev 的回应：它让开发者把模型智能聚焦在一组用户自定义的问题上，返回有限、预定义的答案，用于内容分类、请求路由或选择代理的下一步动作。

**深度阐述**

Greg 用一句话点明了 Decision API 的定位："This is their answer to Jev."——"这是他们对 Jev 的回应。"Jev 是近期备受关注的决策类 AI 工具，Greg 坦言自己已经沉迷其中（"I've been hooked on Jev"），上周还专门做过一期视频。所以当 OpenAI 推出同类产品时，他格外关注。

Greg 引用了官方的功能描述："Decisions API enables real-time decision-making by focusing Luna's intelligence on a specific set of user-defined questions with finite predefined answers. So developers supply context using text or images and they get back answers they can use to classify content, route requests, or choose an agent's next action."——"Decision API 通过将 Luna 的智能聚焦在一组用户定义的、带有限预定义答案的问题上，实现实时决策。开发者提供文本或图像上下文，获得可用于分类内容、路由请求或选择代理下一步动作的答案。"

这段话的关键词是 "finite predefined answers"（有限预定义答案）——这正是 Decision API 与传统大语言模型"自由发挥"的本质区别。它不是为了生成开放内容，而是把 AI 的能力约束在一个可控的决策空间里，保证输出是可预期的、结构化的。

Greg 特别指出一个被大多数人忽视的用例：UI 设计。他反问道："How do you use a decisions API to get you the most highly-converting App Store screenshots or direct response websites and apps?"——"你怎么用决策 API 得到转化率最高的 App Store 截图，或者直接响应式网站和应用？"换句话说，决策 API 可以用来做 A/B 测试的智能加速器——让 AI 在多个设计方案之间做出最优选择。

关于竞争格局，Greg 抛出了一个开放问题："will OpenAI's decision API be worse, as good or better than Jev? TBD. We will find out really soon."——"OpenAI 的 Decision API 会比 Jev 更差、一样好，还是更好？待定。我们很快会知道。"他提醒大家值得密切关注。目前 Decision API 处于 limited preview（限量预览）阶段。

**个人感受**

Greg 对 Jev 的沉迷是真诚的——他用了 "hooked"（上瘾）这个词。这种"上瘾"不仅来自工具本身，更来自他对"决策"这个环节的兴奋感：如果 AI 能可靠地做选择，那么无数过去依赖人工判断的流程都可以被自动化。他看到一个还没被大量讨论的蓝海：用决策 API 优化转化的每一个节点。

**延伸思考**

Decision API 标志着 AI 从"内容生成引擎"进化为"业务决策引擎"。对企业来说，这意味着：内容审核、客户请求路由、下一步动作选择——这些环节都可以被结构化地自动化，而且带着可审计的确定性。这比"让 AI 写一段文案"有更深的商业意义，因为决策是交易的核心。

**精华收获**

- 决策 API 的价值在于"确定性"——用有限预定义答案框住模型的自由发挥。
- 被低估的用例：用决策 API 驱动 UI 设计决策，优化转化率。
- 关注竞争格局：OpenAI 的入局可能挤压第三方工具的生存空间，但也验证了赛道的价值。

## 四、Agents API + Computer Use：AI 代理开始"动手操作电脑" `[字幕位置：Agents API 部分]`

**核心观点**

Agents API 现在支持计算机使用（computer use），开发者可以构建与软件交互并完成任务的代理。OpenAI 负责底层基础设施，开发者只需聚焦应用层。

**深度阐述**

Greg 引用了官方发布说明："The agents API now supports computer use. So developers can build agents that interact with software to complete tasks. It also brings Codex's multi-agent capabilities, tool search, tool calling, and context compaction into your application. OpenAI runs the underlying infrastructure so your team can focus on building applications."——"Agents API 现在支持计算机使用。开发者可以构建与软件交互以完成任务的代理。它还把 Codex 的多代理能力、工具搜索、工具调用和上下文压缩带到了你的应用中。OpenAI 负责运行底层基础设施，这样你的团队可以专注于构建应用。"

这里有两个值得注意的信号。第一，"computer use"意味着代理不再停留在聊天窗口里——它们可以打开软件、点击按钮、填写表格、操作界面，真正"替人干活"。第二，OpenAI 把基础设施的复杂性完全包揽，意味着开发者可以以极低的门槛，构建具有多代理协作能力的产品。

Greg 将这个概念与他之前讲过的"垂直马具"（vertical harnesses）联系起来。他的理解是：OpenAI 提供的是"managed harness"（被管理好的马具）——框架已经有了，重要的是谁来驾驭它。他的判断非常直接："if you have great data, if you have a great brand, if you understand a vertical better than other people, there's this huge opportunity to build apps."——"如果你有好的数据、好的品牌、比其他人更懂某个垂直领域，就有巨大的机会构建应用。"

他给观众的行动建议非常具体："That's why I would be playing with the agent API today. Like go and figure out what you can be building, how you can extend your business to this world."——"这就是为什么我今天就会去玩 Agents API。去搞清楚你能构建什么，如何把你的业务延伸到这个世界。"他还补充了一个判断："This is just like a new surface area... I don't think a lot of people are doing it."——"这是一个全新的表面区域……我不觉得有很多人在做这件事。"对于创业者来说，蓝海意味着时间窗口——现在入场，竞争最少。

**延伸思考**

Computer use 让人联想到 RPA（机器人流程自动化），但 AI 代理的语义理解能力远超传统脚本。过去，自动化需要工程师为每个业务流程编写精确规则；现在，代理可以"看懂"界面、"理解"任务，以近乎人类的方式操作系统。对垂直行业来说，这意味着：谁拥有行业数据和流程知识，谁就能用 Agents API 构建行业专属的"数字员工"，而非通用助手。

**精华收获**

- 从"会聊天"到"会操作电脑"是质变——代理从顾问变成了执行者。
- 机会在垂直整合：数据 + 品牌 + 行业理解 = 应用层护城河。
- 行动要快：新平台早期总是存在窗口期，先入场者享有最少竞争。

## 五、Sign in with ChatGPT：被低调发布的"核弹级"功能 `[字幕位置：登录部分]`

**核心观点**

这是 Greg 眼中当天最被低估的发布：用户可以用 ChatGPT 账号登录第三方网站，并消耗自己的 token 额度。这相当于 Facebook Login 的历史时刻，将催生数千个商业机会和一批十亿美元级公司。

**深度阐述**

在分析完 Dots、Decision API 和 Agents API 之后，Greg 停顿了一下，抛出了一个"low-key huge announcement"（低调的巨大发布）——低调到可能甚至不在 DevDay 的官方页面上："I don't even know if it's on this page. That's how low-key it is. But when I saw it, it sort of blew my mind."——"我甚至不知道它是否在这个页面上。它就是这么低调。但当我看到它时，我简直惊呆了。"

这个功能的核心机制是：Sign in with ChatGPT——用户可以用他们的 ChatGPT 账号登录第三方网站，并在这些网站上消耗他们已有的 token 额度（use your token allowance）。

Greg 立刻给出了历史类比："This is going to open up thousands of business opportunities in the same way that when Facebook launched their login, it opened up thousands of business opportunities and actually created many billion-dollar companies."——"这将打开数千个商业机会，就像 Facebook 推出登录功能时一样——当年它创造了许多十亿美元公司。"

他举了一个重量级案例：Yelp。"I remember when Yelp came out, it was basically log in with your Facebook and you're going to see local reviews and reviews that your friends have given... multi-billion dollar company."——"我记得 Yelp 刚出来的时候，基本上就是用 Facebook 登录，然后查看本地点评、查看你朋友给过的评论……一家多十亿美元的公司。"Yelp 之所以能靠"登录"起家，是因为 Facebook 社交图谱（social graph）提供了"朋友的评价"这一独特数据维度。同理，ChatGPT 登录之所以是核弹级功能，是因为它提供了一个全新的数据维度——用户的 AI 身份、token 额度、使用习惯。

Greg 看到了一个清晰的商业路径："Now you can create a free app. You don't charge people. So your top of the funnel becomes bigger. It's connect with your ChatGPT and then you can upsell them to other products and services from there."——"现在你可以创建免费应用。你不向用户收费，所以你的漏斗顶部变得更大。入口是用 ChatGPT 连接，然后你可以向上销售其他产品和服务。"

这个模式之所以可行，是因为它解决了两个历史性难题。第一，用户心理：没有人愿意为每个 AI 应用每月再付 20-30 美元。"Do I really want to spend $20 or $30 a month for another AI app? No, you can just sign in with ChatGPT and start using the plan you already have."——"我真的要为另一个 AI 应用每月花 20-30 美元吗？不，你只需要用 ChatGPT 登录，使用你已经购买的套餐。"第二，成本结构：过去你无法提供免费核心应用，因为你要为每一次推理调用付费（you were paying for inference）。现在，推理成本由 ChatGPT 订阅覆盖，创业者可以把全部精力放在构建分发、建立品牌、获取数据集上。

Greg 给出了具体的商业模式建议："If you're smart, you create your core app free and then you charge for advanced features. So you can charge for enterprise stuff, you can charge for sharing with your team, you can charge for more data."——"如果你聪明，你应该把核心应用做成免费的，然后对高级功能收费。你可以向企业收费，可以对团队共享收费，可以对更多数据收费。"

**视觉/结构信息描述**

Greg 展示了他在本地笔记中的"word dump"（文字倾倒），里面是一连串由 ChatGPT 登录催生的利基 AI 产品点子。他快速念出了五个示例：
1. 一个清理建筑 CAD 文件的代理
2. 一个监控某一特定科学领域的研究员
3. 一个 Shopify 目录清理桌面应用
4. 一个围绕单一可重复编辑工作流构建的视频制作工具
5. 一个只审一种类型特许经营协议的合同审查工具

这些点子的共同特征是"极其利基"——小到不可能成为 OpenAI 官方功能，但大到足够服务一个具体人群。Greg 说："These tiny AI categories that weren't viable, weren't economically viable today... as of today, are."——"这些微小的 AI 类别，过去在经济上不可行……而从今天起，它们变得可行了。"

**个人感受**

这是 Greg 情绪最激动的部分。他说："My mind is going absolutely... I can't stop thinking about it actually."——"我的脑子在飞速运转……实际上我无法停止思考这件事。"他意识到，ChatGPT 登录改变了 AI 创业的基本经济模型：免费获客成为可能，利基市场变得可服务。他反复说 "really really big deal"（非常非常大的事）。

**延伸思考**

Sign in with ChatGPT 的深层含义，比"免费获客"更广阔。它意味着 ChatGPT 账号正在成为一种"基础设施身份"——类似 Google 账号之于互联网、微信之于中国互联网。一旦用户习惯用 ChatGPT 登录各类应用，OpenAI 就拥有了跨应用的用户画像和分发能力。对创业者来说，这既是机会（低摩擦获客）也是风险（平台依赖）。历史经验是：Facebook Login 时代成长起来的公司，后来也不得不面对平台政策变化的风险。聪明的做法是：利用这个入口快速获客、沉淀自有用户关系（邮箱、手机号），而不是永远依赖平台。

**精华收获**

- "Sell workflows instead of tokens"——销售工作流，而不是销售 token。这是 Greg 最凝练的商业哲学总结。
- 免费核心 + 付费增值成为可行模式——推理成本不再是创业者的负担。
- 利基 AI 工具（tiny AI categories）从"经济上不可行"变为"可行"——这是一个历史性的成本结构变化。
- 创业者的重心应该转向：构建分发、建立品牌、获取数据，然后用数据形成飞轮。

## 六、四步框架：触发 → 决策 → 行动 → 反馈 `[字幕位置：框架部分]`

**核心观点**

Greg 给出了理解新世界的思维模型：Trigger（触发）、Decision（决策）、Action（行动）、Feedback（反馈）。最强的企业应该拥有"2 of 3"——即触发、行动、反馈这三个环节中的至少两个，而非中间的"决策"环节。

**深度阐述**

在 Decision API、Login with ChatGPT、Dots、Agents API 四大发布并存的世界里，创业者到底该如何思考自己的位置？Greg 给出了一个清晰的四步框架。

**第一步是触发（Trigger）**：一个事件发生，使得用户来 ChatGPT 求助，或者代理自主开始工作。"An invoice becomes due. The inventory runs low, or it's tax time. Like something happens such that I'm going to ChatGPT and I'm asking for some help, or it does it autonomously."——"一张发票到期了。库存变低了，或者到了报税季。某件事发生了，于是我去找 ChatGPT 帮忙，或者它自主地开始干活。"

**第二步是决策（Decision）**：ChatGPT 判断接下来该做什么。"ChatGPT is like, okay, what should I do next?"——"ChatGPT 就像在说：好，我下一步该做什么？"这是一个由平台主导的环节——这正是 Greg 认为创业者不应该正面竞争的环节。

**第三步是行动（Action）**：有一个正确的提交、一个设计好的动作、一个应用真正完成某事。"There's a correct, there's a submit, there's an ability for an application to do something."——"有一个正确的结果、有一个提交动作、有一个应用完成某件事的能力。"

**第四步是反馈（Feedback）**：结果如何？"Was it approved? Was it rejected?"——"通过了吗？被拒绝了吗？"反馈让系统知道行动是否成功，从而驱动下一轮循环。

Greg 的战略结论非常明确："I think that the strongest businesses are going to own two of three. So they're going to own trigger, they're going to own action, and feedback."——"我认为最强的企业将会拥有三个中的两个（环节）。他们会拥有触发、他们会拥有行动、以及反馈。"（此处字幕原文为 "two of three" 但实际列举了三个环节——可以理解为：除了"决策"这个由平台主导的环节外，触发、行动、反馈都应该尽可能自己掌控。）

这四步框架的价值在于为创业者提供了一个"机会定位器"：当你头脑风暴时，你应该聚焦于触发、行动、反馈这三个环节，而不是试图在"决策"上跟 ChatGPT 竞争。如果你能开发一个触发场景（比如一个专门提醒企业报税的工具）、一个行动交付（比如自动完成报税申报）、并获得反馈数据（申报是否成功），你就拥有了一个完整的数据闭环，而不仅仅是 ChatGPT 流程中的一个零件。

**延伸思考**

这个框架揭示了一个更深层的商业逻辑：数据飞轮。触发、行动、反馈三个环节共同构成了数据闭环——你知道客户遇到了什么（触发）、你能做什么（行动）、结果如何（反馈）。这个闭环产生的数据，比任何单个环节都更有价值，因为它是训练行业专属模型和优化工作流的燃料。反过来说，如果你只做中间的决策环节，你既不拥有客户入口，也不拥有执行结果，很难形成持久壁垒。

**精华收获**

- 不要在决策环节与 ChatGPT 竞争——那是平台的主场。
- 创业者的黄金位置：拥有触发场景（入口）、行动交付（结果）和反馈数据（闭环）。
- 四步框架让头脑风暴更有方向感：问自己"我在哪个环节创造价值？"

## 七、两个具体创业方向：真实世界 API 与代理分析平台 `[字幕位置：想法部分]`

**核心观点**

Greg 给出了两个具体的创业方向：(1) Real World API——把 Dots 连接到物理世界的专业服务人员，完成交易的"最后一公里"；(2) 代理发现的分析优化层——做个人代理时代的 Mixpanel、Amplitude 或 Google Analytics。

**深度阐述**

**方向一：Real World API（真实世界 API）**

Greg 指出，在一个数百万人都去向 Dots 提请求的世界里，有些请求是纯数字的，但很多是"structured jobs"（结构化的工作）——它们需要在现实世界中被完成。"Some of those are going to be digital, some of them are going to be structured jobs. So if you can figure out a way to get vetted specialists in the real world, I think that that's a huge opportunity."——"其中一些是数字任务，一些是结构化的工作。如果你能想办法找到经过审查的真实世界专家，我认为这是一个巨大的机会。"

他举了两个具体例子：permit expediters（许可证加急办理专员）和 customs brokers（报关行）。这些是需要专业资格、线下操作的业务。如果 Dots 的用户需要办理某个许可证，你的公司可以连接一个经过审核的专家来完成这个事务，然后收取交易费（transaction fee）。

Greg 在这里点出了一个核心判断：所有人的注意力都会集中在数字世界，物理世界的"最后一公里"反而是空白。"A lot of people are going to be focusing on the digital stuff. How can you create real-world work APIs in specific niches that you can connect Dots or connect ChatGPT to real-world workers who can finish the last mile of the transaction? Huge opportunity."——"很多人会聚焦在数字事务上。你能否在特定利基市场创建真实世界工作 API，把 Dots 或 ChatGPT 连接到能完成交易最后一公里的现实世界工作者？这是巨大的机会。"

**方向二：代理发现的分析与优化层（Analytics & Optimization Layer for Agent Discovery）**

Greg 第二个方向的推理非常精妙。他指出：我不是唯一一个正在想"如何构建插件"的人。就在此刻，全球可能有数千家公司正在苦思一个问题：怎么在 Dots 里获得曝光？不只是 Dots——还有 Meta 的 Muse、Google 的 Gemini（他提到 Google 平台可能叫 Spark）、Instinct、Grok 等等。"Some of these have plugins, some of them don't. But I think eventually they all will."——"有些有插件，有些没有。但我觉得最终它们全都会有。"

在这个背景下，一个巨大的机会出现了：谁能打造一个分析平台，帮助开发者理解并优化插件在代理生态中的表现？

Greg 展示了他笔记中的产品概念清单——这是一组非常具体、实战导向的功能需求：
- 生成真实的间接提示（generates realistic indirect prompts）
- 测量哪个插件被选中（measures which plugin gets selected）
- 按客户意图跟踪激活份额（tracks activation share by customer intent）
- 发现元数据和工具定义问题（finds metadata and tool definition problems）
- 衡量调用是否转化为完成（measures whether invocation turns into completion）
- 测试每次插件更新（tests every plugin update）

用大白话说：在代理时代，"被 AI 选中"就是新的"被搜索引擎收录"。开发者需要一套工具来理解：我的插件在什么场景下会被推荐？用户真正想要什么时才会激活它？插件更新后表现是上升还是下降？这套工具就是"代理生态的 Google Analytics"。

Greg 用历史类比支撑了这个机会："In the web era, you had huge companies. Mixpanel came out, Amplitude came out, Google Analytics was a huge product."——"在网页时代，你看到了大公司。Mixpanel 出现了，Amplitude 出现了，Google Analytics 是一个巨大的产品。"他认为未来会有大量围绕"帮助你在代理生态中被看见"的分析产品出现。

他甚至提到了当下已经验证这个需求的先例：AEO/GEO（AI 引擎优化/生成引擎优化）领域的公司 Profound——"I mean Profound raised at like a $2 billion valuation or billion-dollar valuation, some absurd, you know, large amount... They're solving a real problem."——"Profound 以大约 20 亿美元或 10 亿美元的估值融资，某个高得离谱的数字……他们解决了一个真实的问题。"这证明市场愿意为"在 AI 生态中被看见"付费。而 Greg 提出的终极之问是："Who's going to be the Profound for this personal agent era?"——"谁会成为个人代理时代的 Profound？"

**个人感受**

Greg 在提出"真实世界 API"时，语气带着一种发现猎场的兴奋。他敏锐地意识到：当所有人涌向数字赛道时，物理世界的服务交付反而成了稀缺资源。而在提出分析平台方向时，他展现出一种"卖水人"式的商业智慧：淘金热里最确定的生意，是卖铲子。他强调 "I hope someone takes that"——"我希望有人去做这件事"，既是对观众的鼓励，也透露出他对自己不能分身去做的遗憾。

**延伸思考**

这两个方向其实代表了两类截然不同的创业逻辑。真实世界 API 是"重资产+垂直深耕"逻辑：你需要建立专家网络、质量控制、信任机制，壁垒高但护城河也深。分析优化层是"轻资产+横向铺开"逻辑：一个产品服务所有代理平台，网络效应强但竞争也会更激烈。创业者需要根据自己的资源禀赋选择：你更擅长搭建线下服务网络，还是更擅长做数据产品？

**精华收获**

- 物理世界的"最后一公里"是被最忽视的空白市场——所有竞争者都在抢数字层。
- 代理生态的"SEO"刚刚开始：能被代理选中，就拥有生意。
- 分析优化层是一个服务所有平台的"卖水人"机会——Mixpanel、Amplitude 的故事将在代理时代重演。

## 八、其他发布与最终总结：GPT-6.1 Soul、UltraAst、Private Intelligence、Spaces `[字幕位置：结尾部分]`

**核心观点**

除了四大核心发布外，OpenAI 还发布了 GPT-6.1 Soul（重大模型升级）、UltraAst（超高速模型）、Private Intelligence（企业数据隐私方案）和 Spaces（云端协作空间）。但对创业者来说，商业机会的精华集中在前述四个功能上。

**深度阐述**

Greg 在节目最后快速掠过了一些"预期之中"的发布。首先是模型升级——字幕中出现了一段乱码（"G G G G..."，可能是转写错误），但可以辨认出他提到了 GPT-6 6.1 Soul，"which was huge, which is obviously a major upgrade to GPT-6"——"这很重磅，显然是对 GPT-6 的重大升级。"不过 Greg 表示，"we kind of expected that"——"我们多少预料到了"。

另一个让他真心推荐的产品是 UltraAst："which now, which is amazing, by the way, if you haven't tried UltraAst, it's absolutely amazing... you're going to love it, just way faster."——"它太棒了，顺便说一句，如果你还没试过 UltraAst，它绝对令人惊叹……你会爱上它的，就是快太多了。"不过他也不忘补了一句现实主义的观察："of course it's a lot more tokens"——"当然，它也消耗多得多的 token。"

关于 Private Intelligence，Greg 的分析带着创业者的敏锐："I think a lot of companies are scared to use frontier AI because their data isn't really protected. So I'm not surprised that they're doing things like that and doing stuff like Codex security cloud."——"我认为很多公司不敢使用前沿 AI，因为他们的数据没有得到真正的保护。所以我对他们推出这类功能并不感到意外，Codex 安全云也是一样。"他理解这是企业采纳 AI 的真实障碍——数据安全不是锦上添花，而是准入门槛。

至于 Spaces（Greg 描述为"their version of having cloud slides and docs"——"他们版本的云端幻灯片和文档"），它的亮点在于可以带上你的 AI 代理一起工作（"you can bring your AI agent to work with it"）。Greg 的评价是："It's cool, and it's going to help make people more productive."——"这很酷，会帮助人们变得更高效。"

但 Greg 始终在提醒观众什么才是重点。他明确地说："I think the point of this whole episode was: there's a few main features——decision API, agents API, the login with ChatGPT, and Dots——that I think, if you're listening to this, you're a founder or you're someone who wants to build a company, wants to bet on yourself, that's going to be huge."——"我认为这期节目的重点是：有几个主要功能——Decision API、Agents API、ChatGPT 登录和 Dots——如果你正在收听这期节目，你是一位创始人，或者你想创建一家公司、想赌一把自己，那么这些功能将是巨大的机会。"

他在结尾处展现了对观众群体的认同感："For people listening to this, for my people, for the idea junkies, the people who want to build businesses, I thought this would be most interesting to you."——"对于正在收听的人，对于我的人，对于那些想法上瘾者、那些想创业的人，我觉得这些内容对你们是最有意思的。"他还承诺会阅读每一条 YouTube 评论，并回复其中的许多。最后，他以一句标志性的祝福收尾："Have a creative day."——"祝你度过一个有创造力的一天。"

**个人感受**

这期节目的情感弧线非常完整：从开场"不得不录"的兴奋，到中段"无法停止思考"的痴迷，到结尾"对同类人说话"的归属感。Greg 没有被大公司的声势淹没，他始终以创业者的视角在筛选信息：什么能帮我赚钱？什么能帮我建立公司？这种实用性导向贯穿始终。他理解的"创造"不只是产品创新，更是一种生活方式——"have a creative day"不是客套，而是他对观众最深切的祝愿。

**延伸思考**

Greg 对"非核心发布"的快速处理方式，本身就是一种值得学习的信息处理策略。在一个信息过载的时代，创业者最稀缺的资源不是信息，而是注意力。Greg 的筛选标准始终如一：这个功能能否成为新商业模式的地基？如果不能，它就只是背景噪音。这种"以终为始"的思维方式，可能比这期节目中的任何具体观点都更有价值。

**精华收获**

- 企业数据隐私是前沿 AI 普及的真实障碍——Private Intelligence 类产品有长期价值。
- UltraAst 的"更快"伴随着"更多 token"——性能提升与成本增加并存，创业者需要精细化算账。
- 模型升级（如 GPT-6.1）是"预期之中"的；真正的机会在"预期之外"的生态发布。
- 保持"想法上瘾者"（idea junkie）的身份认同——持续的好奇心和热忱，是创业者的元能力。

## 全文升华：为什么这届 DevDay 能催生"百亿美元机会"？

回到 Greg 的核心命题：为什么他敢说今天的功能发布将让一批人合计赚到数十亿美元？

答案藏在一系列结构性变化的叠加中：

**第一，分发权的转移。** 12 亿周活用户 + 插件机制 = 新的应用商店。在传统互联网中，获取 100 万用户需要巨大的营销预算和品牌投入；而在 Dots 生态中，一个高质量的插件可以在用户未知你名字的情况下就被"雇佣"。这是渠道权力的根本性再分配。

**第二，成本结构的颠覆。** Sign in with ChatGPT 让第三方应用可以免费提供核心服务，因为推理成本由用户的 ChatGPT 订阅覆盖。过去，AI 创业公司的单位经济模型（unit economics）经常被推理成本压垮；现在，这个负担被平台承接了。利基产品从"不经济"变为"经济"——这是一个历史性的拐点。

**第三，能力边界的扩展。** Agents API + computer use 让 AI 从"聊天"走向"操作"，从顾问变成执行者。代理可以真正完成工作——而完成工作意味着可以收费，意味着交易发生。这是"数十亿美元交易流"这一判断的技术基础。

**第四，生态基础设施的缺失。** 当无数开发者涌入代理生态时，他们需要分析、优化、发现、监控的工具。这些工具就是代理时代的"卖水人"生意——它服务的不是某个具体行业，而是整个生态。

**第五，物理世界的最后空白。** 数字世界的竞争已经红海化，而真实世界的最后一公里服务（许可证、报关、线下交付）还没有被系统性连接。这可能是最大的结构性套利空间。

Greg 的终极建议可以用三句话概括：**不要再卖 token，要卖工作流；不要再做通用 AI，要做利基工作流；不要再试图与平台争夺决策权，要拥有触发、行动和反馈。**

这不是一篇冷静的行业分析，而是一个创业者在发布会当天的真实脑内活动——带着兴奋、紧迫、草稿式的思考，以及毫不掩饰的行动号召。在这个意义上，它比任何事后复盘都更有价值：因为它捕捉的是机会诞生的那一刻，一个嗅觉敏锐的人如何理解它、消化它、并且立刻开始构思如何抓住它。
