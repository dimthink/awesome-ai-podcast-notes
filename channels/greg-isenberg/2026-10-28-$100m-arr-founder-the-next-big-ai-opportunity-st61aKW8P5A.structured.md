# 揭秘 Agent Harness：Gamma 的 1 亿美元 ARR 增长之路与垂直 AI 创业机会

今天我们邀请到 Gamma 联合创始人兼首席产品官 John Noronha，一起深入探讨 **Agent Harness（智能体挽具）** 及其周围的大量机会，尤其是垂直领域的 Agent Harness。我非常期待这次对话。特别感谢 **Anthropic**——Claude 背后的团队——赞助今天的节目。

## 本期你将学到什么

**Greg Isenberg**：John，非常感谢你来参加播客。听完这期节目，大家会学到什么？

**John Noronha**：谢谢你邀请我，Greg，我很兴奋能来到这里。今天我们会深入探讨在实际中构建一个智能体到底意味着什么，包括揭开什么是 Agent Harness 的神秘面纱，以及它在 Gamma 的具体形态——Gamma 是一个 **创意型 Agent Harness**，一个用于视觉沟通的智能体。

**Greg**：你太谦虚了。Gamma 增长极快，我认为它已经达到了 **1 亿美元 ARR**。你们刚刚重新发布了平台，是个巨大的版本发布，而且你正在实时学习很多东西。我希望从这期播客中获得的是关于 Agent Harness 领域的机会、你正在实时学到的东西，以及其他存在的机会、创业想法等具体洞察。John，你能承诺在这期节目结束之前让我学到这些吗？

**John**：我承诺，让我们开始吧，让它发生。

## 什么是 Agent Harness？

**Greg**：我想从最基础的部分开始——什么是 Agent Harness？因为我觉得很多人在 X 上刷到“Agent Harness”这个词，但并不真正理解它是什么。你能清楚地解释一下吗？

**John**：当然。让我们把它拆成两个词：**Agent（智能体）** 和 **Harness（挽具）**，我会用 Gamma 的发展历程来说明。

为了让大家了解背景，**Gamma 主要是一款制作演示文稿的工具**，也可以制作文档、网站、社交图片等。我们其实已经存在好几年了，早在“智能体”这个概念出现之前就开始了。我们在 **2020 年**创办了公司，**2023 年**真正起飞。早期我们只是做一些一次性的 LLM（大语言模型）调用，比如写一页幻灯片或为一份演示大纲。我们非常手工地把它们串成预设的工作流，比如生成一个 10 页幻灯片的演示文稿。

过去一两年发生的最大革命是 **智能体革命**。现在最强大的 AI 产品不再手工串联单个 LLM 调用，而是让一个更高层级的 LLM 循环运行：它会做一些工作、检查自己的工作、使用工具，然后通过一系列执行调用将其转化为某个成果。我们今年其实经历了整个重建产品的过程，把产品重建为智能体。而把产品构建成智能体就需要构建一个 **Harness（挽具）**。

所以，**Harness 就是智能体用来在其环境中执行任务、检查自己的工作、并向用户交付最终成果的所有工具**，包括向用户询问他们真正的偏好是什么。

可能最著名的 Agent Harness 是 **Claude Code**。Claude Code 是一个用于编程的 Harness。它教会智能体如何浏览你系统上的所有文件并查看内容，教会它如何运行测试，甚至用某些规则提示它，比如在某些情况下进入计划模式，或者完成执行后运行这些测试，或者在 GitHub 上做这些事情。

而在我们的案例中，**Gamma 不是编程智能体，而是创意智能体**。它需要理解你的艺术风格和创意偏好，帮助你构建一个故事，而且我们非常注重视觉设计。我们会生成图像并布局它们，所以我们需要知道它们看起来如何，并确保它们看起来正确。因此，我们的 Harness 将所有这些转化为智能体可以使用的工具。我可以详细讲讲。

**Greg**：好的，请讲。另外我也很好奇，你是否同意我的说法——我一直在说 **Agent Harness 是新的 GPT 套壳（GPT Wrapper）**，或者说新的套壳。这只是一个好段子，还是确有其道理？

**John**：有道理，虽然我一直对最初“GPT 套壳”这个概念有异议，因为它暗示 90% 的工作是 LLM，上面只有一层薄薄的包装来回传递。我认为 Harness 说明的事实恰恰是：**包装本身就是大部分工作**。你有很多核心能力相当相似的 LLM——不是说它们没有差异，但一般来说，把它们变成产品的所有魔力都来自于围绕它们构建 Harness。甚至像 OpenAI 和 Anthropic 这样的模型公司也在 Harness 开发上投入大量工作。所以它们自己也在对这些东西进行“包装”，以实现不同的能力。

## Gamma 的智能体工作流：输入一个 Prompt 后发生了什么？

**Greg**：你能带我走一遍，当某人在 Gamma 上输入一个提示后 30 秒内发生了什么吗？实际会调用多少个模型？因为我觉得很多人不清楚这到底是怎么运作的。

**John**：让我带你走一遍。我们用一个示例提示来说明。一个非常典型的 Gamma 使用场景是：有人粘贴一堆杂乱笔记或文档或 PDF，然后说“帮我把这个变成 20 页的演示文稿”。

所以当你输入那个提示的瞬间，幕后会发生一大堆事情。

第一件事是我们会在云端启动一台完整的计算机。这就是所谓的 **智能体沙盒（Agent Sandbox）**——OpenAI 那套几个月前出名的越狱事件中的那种。我们启动这个完整的沙盒，智能体在其中获得代表用户提示的所有文件、用户带来的文件，以及其他关于用户的上下文。

然后我们提示智能体去浏览所有这些文件和提示，并运行某些任务。对我们来说，最初的任务之一通常是弄清楚我们还需要从用户那里获取什么其他信息。所以我们通常会弹出一个表单，问几个问题。比如：这是给谁做的？是学校的教育演示吗？是给成年人吗？还是为了你的工作？我们经常会调用不同的连接器。我们构建了与 **Notion**、**Slack** 或 **Linear** 等工具的集成，可以拉取所有相关的上下文。

仅仅在最初的 10 秒左右，我们就已经用大概三到四种不同的模型进行了调用，包括昂贵和便宜的模型——我们稍后还会讨论如何管理成本——只是为了获取信息并问几个问题。我们通过生成式 UI 运行它，向你展示这些选项。

接下来我们会为你的演示写大纲。这通常又是几次 LLM 调用。我们还会为你设计一个模板。我们有一个不同视觉风格的模板库。我们会使用**视觉模型**来判断哪个模板适合你。我们会做一些很酷的**搜索嵌入（Search Embedding）**来在数千个模板中寻找合适的一个，甚至如果你说“我想让它变成红色或蓝色”之类的，我们还能定制它。

然后我们再次向你展示，让你编辑和检查。**我们甚至还没开始制作演示文稿，就已经大概进行了三四十次不同的 LLM 调用，涉及四到五种不同的模型来完成不同任务。**

现在你点击“生成”按钮，我们会在你眼前构建一个演示文稿。这其实涉及很多环节。我们要写幻灯片上的文字，要布局所有内容。在我们的案例中，我们还会生成大量图像——无论是装饰性的还是更实质性的。我们经常制作图表、信息图或数据图。所以所有这些又都是对更多不同模型的调用，而且经常是并行进行。有一个巨大的性能考虑因素：如果我们一个接一个地做，会非常慢，你会在我们完成之前就离开。所以我们做了大量工作让一切变得相当快。

然后在大约一分钟内，你会看到整个演示文稿在你面前流式生成。此时我们可能已经进行了将近 **100 次不同的模型调用**，我估计沿途使用了大概 **10 到 15 种不同的 AI 模型**。但还没有结束，因为你很可能不会停留在初稿。事实上，我们也不停留在初稿。

生成第一版演示后，我们会让一个 **AI 视觉模型检查每一页幻灯片**，寻找它能发现的问题。文字错位、图像中人的头被裁剪、对比度怪异、内边距不对。一个简单的演示文稿里可能出错的地方多得惊人——这些问题人眼通常一眼就能看出来。有时人眼甚至看不出来，因为那需要设计师的眼光。不是每个人都有，但我们可以训练模型来捕捉。

所以我们会进行一整轮**视觉 QA（质量检查）**。实际上我们会根据 QA 发现的问题进行多轮修复，然后重做。经过所有这些修复轮次之后，我们最终才会把它交付给你。到这个时候，我们可能已经使用了 **20 种不同的模型，进行了大约 200 次不同的调用**，来交付给你看起来只是一个最终成果的东西。

**Greg**：你刚才描述的其实是一个特定领域的工作流。在这个案例里，是创意输出。

**John**：完全正确。

**Greg**：你们从演示文稿开始，现在基本上是一个创意套件。

**John**：是的。

## 垂直 Agent Harness 的机会在哪里？

**Greg**：你认为在 Gamma 之外，创建 Agent Harness 的机会在哪里？如果你明天要创办一家公司，你觉得哪里有机会创建一个**垂直 Agent Harness**？有什么你认为尚未被充分探索的细分领域？

**John**：这是个有趣的问题。仅仅基于我的经验，我认为我们打造自己独特 Agent Harness 的价值，在于那个问题与纯粹的编程看起来非常不同。在我们的案例里，区别在于**它非常主观**。过程中有许多需要判断的地方，两个人会对“好”是什么有不同的看法，这意味着你需要让人类参与其中。而且使用者真的非常在乎输出的具体细节。

所以我会把这两个特征作为判断“这是一个构建自己 Agent Harness 的好案例”的线索。

例如，我想到一些例子。我知道很多人用 Claude Code 制作游戏。我非常看好这个想法：**个人化电子游戏**，几乎像是你自己把它编码出来的。编程智能体已经很擅长制作电子游戏，但我认为它们通常不擅长真正获取玩家对游戏走向和演变的意见。如果你想想 **Roblox** 或 **Minecraft**，有那么多东西是人们在为自己塑造世界。而且通常是非技术型的人，他们自己不是程序员。我怀疑那里是否也能构建一个 Harness，其中整个 Harness 运行在一个 3D 世界或类似的东西里。

我认为人们应该真正打开思路。总的来说，我的商业哲学就是**努力做到与众不同**。尝试做一些和所有人正在做的完全不一样的东西。对我们来说这一直是个挑战，因为我们努力与众不同，但其他人会抄袭我们或做同样的事，我们必须不断寻找更多的不同。

**Greg**：我认为不仅对你们如此，对今天任何构建软件的人都是如此。一旦你抓住了闪电，人们就开始抄袭你。但我认为现实是，他们抄袭的是你六个月前、三个月前的位置。所以作为创始人，你必须问自己：我的坚定观点是什么？我对世界走向的论点是什么？以及我如何创建一个产品工作室，让我每两周从零到一构建一个功能，去探索拼图的新一块？

**John**：完全正确。我认为对于任何想构建自己 Agent Harness 的人来说，真正重要的问题是：**我的优势（Edge）会是什么？** 你可以拥有几种不同类型的优势。

一种优势就是你刚才说的：你对世界有独特的愿景，你正更快地朝它前进，而且那不是别人关注的焦点。

另一种优势是你拥有某种**专有数据**。你有一些别人没有的信息，也许因为你已经有一个成功的平台。

还有一种完全不同的优势：**它不仅仅是软件**。因为软件正变得非常拥挤，这是一个可怕的市场。但还有**硬件**、**实体服务**，以及各种可以以有趣方式融入 AI 的现实生活业务。

**Greg**：你能详细说说实体服务吗？

**John**：需要说明的是，我是做软件的人，所以我对这块并不了解。但如果我不是做软件的人，我会花很多时间思考如何将 AI 融入人们正在体验的某种现实生活场景，其中存在真实的人与人之间的价值交换。无论是一个人给你按摩，还是一家餐厅为你上菜，或者别的什么。我认为有太多真实的业务还没有被 AI 重新发明。我不知道它们是否都需要自己的 Harness，虽然也许有些确实需要。

另一个我看到很多 Harness 出现的领域是**法律科技**。我怀疑**医疗科技**是一个大领域，有大量有趣的数据锁定和监管因素。

**Greg**：是的，我认为法律领域是那种“显然这说得通”的领域之一。会计显然也说得通。但我现在会想：我会在今天构建一个法律科技 AI Agent Harness 吗？可能不会。因为感觉太拥挤了。所以我喜欢你提到的服务业务，甚至是一般意义上的无聊业务，比如为 **HVAC 公司（暖通空调公司）** 构建 Agent Harness。如果有人想在一个细分领域构建 Agent Harness 创业公司，他们应该如何着手设计？我的意思是你需要关键洞察，需要那个细分领域。

**John**：关于什么是 Agent Harness，一个非常简单的答案是：**Agent Harness 就是智能体用来完成一项任务的一堆工具**。所以我认为要问的问题是：哪些是**要么我已经拥有的、要么我可以构建的、且尚未存在的独特工具**？

理想情况下，作为创始人，你应该总是问自己：基于我的人生经历、我在世界上的位置、我认识的人——**我特别适合做什么？**

## AI 气味与创意差异化

**Greg**：你怎么看待 **AI 气味（AI Smell）** 这个问题？

**John**：我确实有强烈的意见。我今年一直在用“AI 气味”这个词。我一直在谈论“除臭”、“喷掉它”之类。可能有些人不知道这个词。**AI 气味**是指：当人们用 AI 制作东西时，你通常能看出他们用了 AI。

我认为它最明显体现在写作中。当有人用 Claude 给你写邮件时，你会觉得：你平时不用那个词，那不是你说话的方式。我现在也经常在 AI 图像中注意到它。我在旧金山到处走，每个咖啡馆、每个餐厅都有一张海报，我就能闻出来——那是 **Nano Banana**，那是 **GPT Image**。我整天做这些事，所以能在一英里外认出它们。而且我认为随着 AI 气味渗透到整个经济和普通人中，越来越多的人开始识别它。

所以对我们 Gamma 来说，这次发布的一个巨大目标就是消除这种气味。作为早期 AI 工具之一，我们有点成了自己成功的受害者：当没人用 Gamma 时，如果你用了它，你的东西看起来很酷、很突出。但一旦所有人都开始用，一切开始看起来像 Gamma，人们就不想被认出在用 AI。

因此，我们这次发布的整个目标就是**快速扩大我们的创意版图**。事实是，AI 气味仍然会存在，但可以有**一千种 AI 气味**，而不是一个单一的、统一的。我们可以帮助人们跳到不同的小口袋中。顺便说一句，这本身就是另一种 Harness。我们需要创建自己的自动化系统，不断循环不同的创意外观。

我们实际上用**时尚**来类比。时尚也有气味。你会想：“我知道你穿的那件 H&M 衬衫，我也有同款。”而在时尚中，存在一种人们不断循环不同外观的动态。比如现在流行特别宽大的牛仔裤，但很快又会回到紧身牛仔裤。所以我们意识到，我们必须驾驭这个循环，并给人们提供适应它的工具。

## 如何评估主观质量：Evals 与 AB 测试

**Greg**：有没有一个评估（Eval）来衡量“这看起来太普通了”？

**John**：评估是个非常有趣的话题，因为我认为**评估对客观事物很有效**。如果你不介意，先解释一下什么是 Eval。

**Greg**：当然。**Eval 意思是评估，你可以把它想象成一种软件测试。它是一个硬编码的问题，你用它来评判。** 在我们 Gamma 的世界里，一个简单的例子是：我们经常希望智能体在你做模糊的事情时提问。所以我们会给它一个评估，比如当用户说“做一个关于老虎的演示”时，智能体应该问“这是给孩子的还是给成人的？”因为关于老虎的演示可以非常不同。所以我们通常用评估来测试新的提示词或新模型。通常你会给它们打分。你可以把一堆评估放在一起组成一个**基准（Benchmark）**，然后说：“结果证明模型 B 比模型 A 高 3%。”每次实验室推出新模型，他们就会说：“Opus 7 在这些 15 项评估中碾压一切。”

问题在于，对于我们这个高度创造性的领域，评估一直很难处理各种主观的、品味导向的事情，比如“这看起来酷吗？”更不用说非常个人化的问题，比如“这是我吗？这听起来像我会说的话吗？”对此没有单一的客观评估。

所以我们试图创建一些评估作为代理指标，比如“它是否遵循指令？例如如果你提供了品牌指南，它是否遵守？”这是一个客观问题，我们确实会测试自己。但我们从来不只局限于评估。我认为这也是一个有趣的洞察：你如何在这个世界上竞争。最终，创始人能带给其领域的是**品味（Taste）**。他们有自己的审美，他们实际上在与用户交流，而那些用户也有自己的审美。一个领域越不可验证——比如时尚——就越有空间容纳这些独特的视角。当谈到服装设计时，应该有 100 种不同的 Harness。我认为 Nike 应该有一个不同于 Adidas 的，因为他们对品味有不同的视角。

此外，因为我们有一个极其多样化的用户群，我们实际上更多依赖 **AB 测试**。我们会大规模运行两个模型或两个提示词，并在广泛的用户群中衡量哪个实际表现更好，因为这样才能捕捉主观性。

**Greg**：在那里最重要的指标是什么？

**John**：我们有好几个不同的指标。举几个例子：我们会在你生成后看**你花多少时间编辑你制作的内容**？你是否最终**分享或导出**了它？是否有一些信号表明你在投入时间？我们还有一个**免费增值**产品，所以人们会免费使用我们的产品，如果喜欢，就会升级到付费。这是我最喜欢的信号，因为它很难伪造。一般来说，人们只有在真正看到工具价值时才会付费。所以我们把它当作北极星指标。有时我们甚至会查看下游留存，比如一周后或一个月后人们是否还会回到产品。它显然更慢才能衡量，但也是那些很难伪造的信号之一。

## AI 付费用户只有 2%？订阅模式的真相

**Greg**：本周疯传的一张图，我记得是 **A16Z** 的图，说只有 **2%** 的人在为 AI 工具付费。你怎么看？

**John**：我并不惊讶。我认为总的来说，订阅制总是有点小众，面向那些在做某种有价值工作的人。我不认为消费者喜欢订阅。作为消费者，我也不喜欢订阅东西。我仍然总是想蹭别人的 Netflix 账号之类的。

**Greg**：不，我不会跟你分享我的密码。

**John**：你确定吗？如果我能解释什么是 Agent Harness 呢？不过我认为工作场景完全不同。在工作场景中，**工作订阅**本质上驱动了过去 10 到 15 年软件行业整个 SaaS 的繁荣，那些东西会持续成功。而那张图也说，当你真正放大到专业人士群体时，为 AI 付费的人数正在疯狂上升。所以这当然是我们关注的重点，我认为也是大多数 AI 从业者关注的重点：**如何找到那些专业消费者（Prosumer），以及如何打入 B2B 市场**，那里有完全不同级别的支出。

## 如何选择你的细分领域？

**Greg**：如果有人想建立“Gamma for X”，你会选什么？如果听众中有人说：“哇，Gamma 在做的事情激励了我。但我想要你刚才描述的东西，只是换成一个不同的细分领域。” 有想到什么吗？

**John**：这是非常个人化的事情，因为如果它是我的领域，我早就已经在做了。我认为你需要去做那些**我完全不了解的事情**，不管是宝可梦卡牌、时尚、球鞋还是别的什么。找到你了解的领域，在那里构建。

**Greg**：你个人，有没有一个你希望存在但尚不存在的 Harness，如果明天出现你就会使用？

**John**：我对整个“个人智能体”领域非常着迷。我还没能使用所有最新的产品，但我觉得**没有人真正解决的是工作协作**。如果我能为任何东西构建一个 Harness，我会选 **Slack**。而且我有点失望 Slack 自己还没有为 Slack 构建 Harness。

**Greg**：你心目中的那个 Harness 会是什么样？

**John**：任何公司使用 Slack 或 Microsoft Teams 的人都会面临绝对的通信洪水。有那么多消息涌进来。你不断试图跟进：“哪些是我实际上需要做什么的？”我见过他们在边缘试探，比如你可以把 30 条 Slack 消息总结成一条。但我想要的是**真正为我运行一切**的东西，它会学习我。它在我回复之前就学会我会怎么回复。我希望能够打开任何有人 @ 我的 Slack 话题，第一版草稿就已经为我写好了。

**Greg**：而且它不是通过让你回答问卷或引导流程来学习你，而是通过你的实际行为。

**John**：通过观察我。我已经发送了大约十亿条 Slack 消息。这些应该足够让你知道我将怎么回复。即使电子邮件也没被完全解决。我见过 Gmail 有一些小功能，比如“是的，我很乐意周四去看牙医”，但那根本不是我会回复的方式。不过我认为在专业环境中**真实地代表我**还有更多可做的事。也许这就是我真正渴望的，也是 Gamma 正在做的一部分：我想要一个能学习我的声音的智能体。

当然，这很难，因为它是个性化的，这就是为什么智能体还没做到这一点。让智能体变得个性化真的很难。

## 在他人模型之上构建的建议

**Greg**：在 Gamma，你们是在其他人的模型之上构建。对于在他人模型之上构建的创始人，你有什么建议？

**John**：我认为在他人模型之上构建**没有什么可羞耻的**。我们从一开始就一直在这么做，经常在 Anthropic、OpenAI、Google 模型之间切换。太多讨论一直是：“不，你必须训练自己的东西。你必须微调，因为你需要护城河。”我一直觉得这对早期创业公司来说不现实。首先，训练自己模型涉及的资金真的很难。而且，市面上的模型一直在变得更好。我很少愿意去和那些模型竞争。

但我认为随着你的发展，情况确实会变化，因为你开始积累真实的使用量。说实话，**积累真实使用量**才是人们应该关注的主要战斗。无论如何，先利用市面上的模型来获得使用量。一旦你做到了，你就可以开始做真正有趣的事情。我们在**微调模型以降低成本**方面取得了很大成功，有些情况下甚至开始为人们做更多个性化。我们也开始识别出大模型不擅长的专门任务。就像我之前提到的 QA 幻灯片并判断好坏的整个过程，我们使用市面上的任何模型效果都不好。所以我们实际上正在做一些自己的研究，为这些专门任务构建模型。我认为人们绝对应该以此为目标，但无论如何，先用市面上那些优秀的模型。

## 前沿模型 vs 开源模型

**Greg**：你对前沿模型或云模型与开源本地模型的看法是什么？

**John**：我认为**云模型被低估了**。开源得到了很多炒作和兴奋，但跟着钱走：所有钱都流向了闭源模型，因为它们真的非常好。很多工作已经为你完成了。而且对我们所有人来说，好消息是闭源模型世界存在激烈竞争。我认为在一个像 Anthropic 可以纯粹一骑绝尘的世界里，情况会完全不同，因为我们将无法在优秀的 OpenAI 模型、优秀的 Gemini 模型之间选择。但我觉得所有这些公司都只是彼此落后几个月。对我们应用层来说，这是最好的事情。它让压力始终在他们身上，让他们不断做得更好。

## 我们的 AI 栈：宽而浅

**Greg**：你曾经说过，你惊讶于自己的 AI 栈是多么浅。现在还是这样吗？

**John**：我会说我们的 AI 栈是**宽而浅**。我意思是，我们使用大量不同的模型，但经常以相当简单的方式使用它们。我们仅靠**提示工程（Prompt Engineering）**——也许你的听众越来越多地听到**上下文工程（Context Engineering）**这个词——只要提供正确的上下文给模型，就能走得很远。我真的把这看作整个游戏的核心：它又回到了 Harness 构建。你能从用户那里获得正确的上下文吗？你能以正确的方式将 AI 的输出呈现给用户吗？你能把所有东西提炼成让 LLM 的工作变得非常容易的东西吗？当你让 LLM 的工作变得非常容易时，你可以使用任何现成的模型并获得好结果。

**Greg**：关于提示词和微调有一个大辩论。你有强烈意见吗？

**John**：有。对我们来说，**98% 的价值来自提示词**。因为提示很简单而且可移植。而且顺便说一句，现在已经没有人手写提示词了。Claude 正在为你写提示词，所以它真的很容易。所以我认为大多数问题都可以用提示词解决，包括把一个提示词拆成不同部分。对我来说，**微调**更多是在你想控制成本或挤出额外 2% 到 3% 的质量时，才在其之上进行的一种优化。

**Greg**：当新模型发布时，你们多快开始采用？你们是等待观望还是如何考虑？

**John**：我通常**一小时内**就会知道。如果这个模型是我有理由相信会很好的。不是每个模型都值得关注，但对我们来说，Anthropic 或 OpenAI 发布的任何模型通常都值得关注。我之前提到，我们的 Harness 中有所有这些不同的工作。其中一些工作我们使用 **Fable 或 Astra 级别**的模型。一些工作我们使用 **Haiku 或 Gemini Flash 级别**的小模型。还有一些我们使用非常小的 **GPT Ludo 级别**模型。所以每当有模型进入这个级别、能帮我们填充那条帕累托前沿（Pareto Frontier），我就想试一试，看看效果如何。而且因为我们的用例非常主观，我们当然会运行一些评估。但我更想直接在用户样本上运行。我们很幸运有一个庞大的用户群，我可以一小时内开始测试，两小时后得到关于它表现如何的数据。

## 实验文化与快速迭代

**Greg**：我学到的其中一点——因为我是设计公司 **LCA** 的联合创始人，我们和 Gamma 合作过一个项目——是你们做了大量实验。我很好奇有没有一个实验结果让你感到惊讶？

**John**：我们运行巨量实验。任何时刻我们大概都有 **10 到 20 个实验在运行**。而且许多实验持续时间不到一天。

**Greg**：能带我走一遍实验的流程吗？我觉得这真的很有意思。

**John**：我带你走一遍我在来和你谈话的 Uber 上刚启动的实验。我刚刚发起了 **8 个不同的实验**，因为 **Claude Haiku 5.5** 昨天发布了。我们很兴奋能使用它，因为之前我提到，我们有很多任务不需要超级 Fable 级别的模型。它们快速且便宜，比如从模板库中挑选模板，或者有时根据内容写大纲。我们一直在期待新的小模型来测试这个。所以今天早上我发起了 8 个不同的测试。在我们结束播客后，我会去检查结果，可能取消其中 4 个，看看表现如何。我们正在测试的内容包括在幻灯片上进行微编辑，或比如说修改大纲等等。

从这些测试中我们学到的东西，通常是：**我们可以用一个成本只有另一个模型一半的模型，但获得完全相同的结果**。但有时我们反而得到相反的发现：我们发现“哇，实际上这个又大又贵的模型对于完成某项任务是必要的”。有时候我们甚至会发现“好的摩擦”这样的东西。我们几天前刚进行了一个关于产品快速模式的实验。快速模式就是跳过我之前告诉你的那些步骤，比如向你展示演示大纲或预先问你问题。假设是：如果你移除过程中的摩擦，人们会更快地完成，并更快地到达那个神奇的价值时刻。我真的为这个测试鼓劲，我想看它赢，但它并没有赢。事实证明，**我们沿途设置的那些减速带**——比如查看你的大纲并审阅它、选择你故事的高层次弧线、回答那些问题——带来了更高的满意度评分。尽管更慢，但完成这些步骤的人对自己的产出更有投入感，行动也更深入。他们转化为付费用户的比例也更高。

但我觉得很酷的一点是，一次测试永远不只是一个答案。你可以再挖深一点。所以我们实际上**为移动端新用户发布了一个快速模式版本**，因为在移动端，你不会想输入一堆问题的答案。

## 营销工程师的崛起

**Greg**：就在刚才，我在 X 上发了一篇关于**营销工程师（Marketing Engineer）**的文章。我的论点是：营销已经变了。想想《广告狂人》时代，那时候你一年做一条大广告，在上世纪五六十年代和七十年代。然后在九十年代和 2000 年代变成了数字营销者，也许多做一些实验。然后我们有了**增长黑客**时代，每周多几个实验。我认为 2022 年可以说进入了**AI 辅助营销者**，更多实验。而现在我们正进入**营销工程师**的时代——你作为营销者每天运行几十个实验。你怎么能这样做？你用 AI 智能体去替你完成。我很好奇你的看法。你认为营销变了吗？你觉得它会走向何方？

**John**：有趣，因为在我去 Gamma 之前，我在一家叫 **Optimizely** 的公司工作。那是我对 AB 测试的热爱来源。我们提供 AB 测试服务。我们很多愿景都是关于**个性化**：随着改变你的网站变得越来越容易，我们会创建一百个微小的变体，每个人都会得到稍有不同的版本，从而以各种有趣的方式优化转化。令我惊讶的是，这个愿景在很大程度上并没有在互联网上实现。我会说**网站仍然大体上是一刀切的**。移动应用也大体如此，除了那些高度个性化并取得成功的专门领域。当我说专门领域时，我指的是像你的 **TikTok 信息流**、**Instagram Reels**。我们知道那些公司正在花费数十亿美元，从你身上榨取每一分钱。

**Greg**：我听说麦当劳在测试个性化定价。你听说了吗？

**John**：哇，那听起来像是在等待一场舆论反弹。

**Greg**：所以我才注意到它。

**John**：但也许麦当劳的例子说明了为什么这没有发生。首先，我认为社会对这种东西有一种真实的过敏反应。就像如果你发现我们俩买了同一张机票，但因为我在旧金山就多收了我五美元。

**Greg**：我认为总的来说，甚至峰时定价也一样。昨晚我回家时遇到了峰时定价，我就觉得……这不是一种好感觉。

**John**：是的。而且我实际上认为，在这个超高效、绩效营销的时代，真正有效的是那些**顽固地投资于品牌的公司**。比如苹果那种心态：不惜一切代价保护品牌。所以我认为这一趋势会抵消你描述的“每个人都用营销智能体疯狂行事”的一部分。

话虽如此，我仍然认同**营销工程师正在崛起**这一论点。而且我喜欢“营销工程师”这个词，因为它听起来像一个矛盾——就像“GTM 工程师”一样。这些本该是不同的部门。但我喜欢看到每个人的技能正在融合。我们在 Gamma 也看到这一点：人们越来越多地使用 Gamma 不只是偶尔做一个演示文稿，而是创建很酷的自动化流程。比如每次 Salesforce 中创建一个新的销售机会，就根据已经发生的通话记录自动创建一个销售提案。

**Greg**：那怎么设置？

**John**：我们其实一直在构建连接器，让你可以自动化更多。你可以直接接入 Salesforce。但我会说仍然有相当多的管道工作。人们可能用 **N8N** 或 **Zapier** 之类的工具来触发并串联起来。这是一个仍然属于专家领域的例子。有一些非常聪明的人或机构知道如何帮助企业完成这些接线。我认为仍然存在一个商业机会：**把那些只有前 1% 到 2% 非常精于此道的公司才使用的实践，变成一个所有人都能使用的超级简单的东西**。

另一个例子，回到个人智能体，就是现在 **Muse** 和 **Instinct** 这样的工具正在发生的事情。如果你能把你的 Linux 盒子设置在正确的地方并避免被黑客攻击，你可以用 **OpenClaw** 或 **Hermes** 做一些惊人的事。就我个人而言，我跳过了那一整个潮流。我当时想：“我是个忙碌的人，没时间设置我的 OpenClaw，我要等几个月让他们直接把它变简单。”现在 Muse 和 Instinct 正在疯狂给我发消息，因为他们让它变简单了。

**Greg**：所以你并没有用 Mac Mini 在运行……

**John**：我从来没有买 Mac Mini。作为一个 AI 创始人，我羞愧地说。

**Greg**：回到营销工程，在你看来，前 1% 的营销工程师是什么样？

**John**：首先想到的是，他们实际上是一个**营销工程师兼数据科学家**。他们极其数据驱动，并且立足于实际表现。而且这一点变得前所未有地容易。Claude 绝对是我的数据科学家。所以我会说，现在我们团队中的每个人都不断武装着关于失败模式和机会的非常细粒度的分析。他们查看我们网站上的流量，寻找差距。我看看我们团队里最接近营销工程师的那个人，他总是一个人就能以令人难以置信的规模不断想出新的 SEO 方法、广告创意。他们从一个个独立创意人，变成了管理一支智能体军队的人。他们处于一个高层的监督角色。

**Greg**：实际上就是一个部门。

**John**：就是一个部门。

**Greg**：我们正在到达一个阶段：如果你是一个前 1% 的营销工程师，你的工作覆盖面积是巨大的。你在关注 **SEO、GEO**，你在关注社交内容，你在关注付费广告，你几乎在关注所有创意品牌相关的东西。

**John**：确实如此。

**Greg**：这对我来说很有趣，因为我认为那些懂得如何成为前 1% 营销工程师的人，在让自己的产品被看到方面拥有不公平的优势。

**John**：而另外 98% 的人正在迅速变成恐龙。如果你跟不上市场上正在做这些事的人。我一直有这样一个想法：在过去一两年里，我们所有使用这些工具的人，都获得了一系列快速晋升。我们从个人贡献者变成了经理、总监，再到 VP。现在我们所有人都拥有层层叠叠的智能体在我们之下，像一个金字塔。事实证明，这份工作其实挺难。很少有人能做是有原因的：你不断被信息轰炸，你必须做出大量决定，你会被这一切淹没和困惑。你甚至需要工具来理解这一切。你也需要人来帮你理解这一切。你需要你的助手，你需要你的幕僚长，你需要所有这些。所以我们所有人都必须迅速提升技能，基本上就是**如何管理一千个人**。建立这种技能是我们能做的最重要的事情之一。而且我认为，构建工具来帮助普通人成为自己生活的 VP，仍然未被充分探索。回到我的 Slack 想法。

## 实验文化：从 Optimizely 学到的事

**Greg**：我也认为，今天构建一家创业公司或任何企业，感觉更像科学而非艺术。那些会赢的人是拥有实验肌肉的人，他们不断尝试不同的事情。这就是为什么我喜欢和你聊天，因为感觉实验肌肉就是你们的特色。你在 Optimizely 学到的、每个 AI 创始人都应该知道的一件事是什么？

**John**：好问题。我想到的一件事是：多年帮助其他公司做实验的经历让我明白，**这在很大程度上就取决于你有多少次击球机会**。这一切都只是个数字游戏，就像销售、约会、生活中几乎任何其他事情一样。你必须真正尝试很多不同的东西，而不是期望自己运行一个大测试就能奇迹般地解锁业务。我喜欢你把它称为肌肉，因为我确实认为它是。首先因为它是可以训练的。也许有些人天生肌肉更多，但如果你付出努力，那块肌肉就会增长。

**Greg**：我也认为你的第一个实验不会成功。就像你试图健身、试图增肌一样。你必须每天去健身房，付出努力，然后两个月后你可能才会看到六块腹肌。但你不能指望第一天就看到。我认为这是作为实验者最难的部分：你必须经历一段**悲伤低谷（Trough of Sorrow）**。

**John**：绝对如此。顺便说一句，社交媒体发帖、写博客、发送冷邮件也都一样。所有这些都有悲伤低谷。我认为人生中所有成功都来自于穿越某种**悲伤之海（Rasa Sara）**。

## 被低估的机会：AI 图像模型

**Greg**：现在有什么被低估了，而你觉得人们谈论得不够多？我和一个朋友谈到**语音 AI**，那感觉被低估了。现在人们都在谈论个人智能体。有什么在你脑海中浮现吗？

**John**：也许这是一个陈词滥调的答案，但我真的认为 **AI 图像模型被低估了**。说它陈词滥调是因为我们讨论图像模型已经好几年了。自从 2022 年 **Stable Diffusion** 问世以来，人们就一直在制作很酷的东西。但我认为讽刺的是，当它们变好时，人们就停止谈论它们了。当它们停止在很多方面出错，并变成了一种基础设施般的存在，我们某种程度上忘记了我们拥有这种可以制造任何东西的不可思议技术。

我认为如果你看看人们使用 ChatGPT 图像和其他一些工具的方式，基本上就是反复使用三四种相同的用例。他们可能在为小企业制作菜单，为爸爸的副项目制作标志。他们在做的事情只有少数几件。但这些模型的能力远不止于此。我们在 Gamma 对此有一个非常酷的观察视角。我们之前没怎么谈论图像，但我们也可能为不同任务使用大概 10 种不同的图像模型。那里的创新速度如此之快，还有大量未被探索的能力。对我们来说，这些事情包括为演示制作漂亮的图表或信息图、制作可以作为演示背景的很酷纹理、制作自定义图标。所有这些现在都是可能的，而大多数人只是没有意识到它的存在。

我认为你可以关注几乎任何创意领域，找到你可以使用这些东西的方式。尤其是普通人完全没有概念。即使是我认为许多 AI 原住民已经在做、但大多数人不知道的事情，就是用 AI 图像模型处理服装和家居装饰。比如你在亚马逊上找到一个想买的新沙发，你实际上可以让 ChatGPT 说：“这放在我家里会是什么样？”然后让它再去帮你找几个其他的，也把它们可视化。太多这种事情只是在等待被更深度地产品化。

**Greg**：你认为在这些领域构建垂直产品有机会吗？比如室内设计。还是你认为大模型公司会直接占据那些用例，所以不值得尝试？

**John**：我认为这些垂直用例有大量空间，关键是要理解使用它们的人的具体需求。就拿家具这个例子来说。我最近刚买了一个沙发，恭喜我。

**Greg**：恭喜。

**John**：谢谢。它真的很舒服。我经历了这个过程，非常有趣。结果发现，AI 图像模型在向我展示沙发会是什么样子方面很出色，但它们并没有真正向我展示它实际尺寸如何。一个 68 英寸的沙发和一个 58 英寸的沙发，如果你的墙是某个尺寸，两者有天壤之别。所以你能不能真正在展示中显示单位？这是一个很好的 Harness 例子。模型实际上有能力完成很多这类事情。一种方式是：你可以渲染沙发在我房间里的图像，然后用一些老式的编程画一条线穿过，以像素为单位测量它的长度，看看它是否真的尺寸正确，并提示模型进行微调以做到完全准确。我不认为大模型实验室会很快做这种事。

**Greg**：或者提示：“嘿，这个沙发并不适合你。不过这是 Restoration Hardware 的另一款沙发，我觉得这些原因让它很完美。”

**John**：完全正确。而且我在买沙发的过程中学到的是，**有数百个网站在卖沙发**，你必须在所有这些网站上点击很多小按钮。我最后用上了 Google Shopping。体验并不愉快。也许有人已经为这个构建了一个很好的产品而我错过了，但我还没看到。

**Greg**：我认为有一些例子。我记得 **levels.io** 有一个室内的……我觉得是叫那个。

**John**：是的，他有一个。

**Greg**：但我认为还有空间。特别是随着模型越来越好，图像模型越来越好，Harness 的概念也越来越成熟。我觉得这里还有更多东西。而且可以肯定地说，今天消费者在购买沙发或家具方面的体验并不优化。

**John**：完全正确。而且这个特定用例很酷的一点是**客单价高**。

**Greg**：对，有利润空间。比如，和 Restoration Hardware 达成协议，他们给你 5% 的佣金作为推荐产品的回报，这并不疯狂。

**John**：绝对可以。我认为这个用例的另一个版本，当你思考什么能在与模型公司的竞争中存活下来时——我们在 Gamma 也一直在面对这个问题——有纯消费者版本，用沙发类比就是“帮我买一个沙发”。但还有**专业消费者（Prosumer）版本**：嘿，我是一名室内设计师。也许我是兼职室内设计师，但我家里有两个孩子，这是我的工作，但我按小时收费。那些人需要一个工具，他们会去寻找最好的。如果它帮助他们更好地完成工作，他们会很乐意为其支付订阅费。然后还有**真正的专业人士**。Restoration Hardware 本身有员工在那里工作。他们使用什么工具？我敢打赌不是只用 ChatGPT 来做这一切。我认为实际上有机会为这些人群构建公司。而且我确实怀疑，最高层的专业人士——那些更大的公司——才是你可以真正构建持久事物的领域。

**Greg**：我也认为这被低估了。因为现在的叙事是：创建垂直 SaaS 或垂直 AI 产品没有那么多机会。这是不幸的，因为我认为机会是存在的。

**John**：而且世界很大。这也许是我们从 Gamma 历程中学到的另一件事。我们的用户群非常广泛，因为只要想想地球上做演示文稿的人有多少，那是很多不同类型的人。对我们来说，**我们不到四分之一的收入来自美国**。收入分布在许多不同的工作角色中，从顾问到教师，到营销人员，到销售人员，到律师。我过去不知道律师做演示文稿，事实证明他们确实做。而且你越能切入那些小细分领域——在许多方面，一家大公司就是一千个小细分领域堆叠在一起。所以如果你能找到跨越性的东西，你不必一开始就做得广，你可以只从其中一个开始，然后寻找你可以应对的相邻领域。

**Greg**：100% 是这样。而且你实际上不知道它会把你引向何方。比如你没有意识到律师在创建演示文稿，然后谁知道呢，你最终会为律师创建一些具体的东西。然后突然之间它成为你业务的一大块。这就是为什么我总是说：开始行动吧。把东西放出去。把东西放出去。你必须去发现。这又回到了实验精神。实验并不意味着必须运行一个每组一万用户的 AB 测试。它通常只是放一个落地页，做一个人们可以试用的产品，而这从未如此容易。

## 如果离开 Gamma，会做什么？

**Greg**：我知道你不会离开 Gamma，但假如你明天离开，你会创办什么公司？

**John**：这是个好问题。我就是喜欢围绕**赋能人们创造力**这个领域。我认为还有其他类型的创造力让我很感兴趣。尽管这个领域很拥挤，但我对**氛围编程（Vibe Coding）**的实践非常着迷。我今年早些时候有过这样的经历：作为一个认识很多科技圈人士、住在旧金山的人，每次我和三四个月没见的朋友叙旧，我问“你在忙什么”，他们会说“看看我做的应用”。

这某种程度席卷了世界。我想知道**下一个氛围编程是什么，或者氛围编程的下一个前沿是什么**。随着人们可以创造任何东西，这会把我们带向何方？在这个领域中，我肯定对**视频模型**终于变好很感兴趣。我对**语音模型**变好也很感兴趣。比如某个你可以打电话过去、它会为你做某事的东西会是什么版本？**游戏**对我来说也非常有趣。我只是觉得电子游戏行业已经成熟，适合某种颠覆。但我还没有破解它。我不知道。

**Greg**：我认为在视频方面，我们确实正在达到“视频的氛围编程时刻”。

**John**：是的，**Opus 5.5** 显然有一些很酷的东西。

**Greg**：它能制作一些很酷的内容。所以我认为问题是：在一个任何人都能创造视频的世界里，他们能创造哪些类型的视频？然后作为创始人我也感兴趣的是：在一个任何人都能创造视频的世界里，我可以在其上创建哪些创业想法？

**John**：完全正确。

**Greg**：这又回到了 Agent Harness。

## 给创业者的最后建议

**Greg**：非常感谢你来参加播客。你有什么想留给观众的一句话吗？

**John**：我总是鼓励那些考虑创业的人要明白，**这是一段漫长且有时孤独的旅程**。正因为如此，你必须真正热爱你正在做的事情。我在创办 Gamma 之前给自己定的一个原则，如果我再做一家创业公司，这条原则仍然会保留：**它必须是我自己能够亲自使用（Dog Food）的东西，我能成为它的用户，并且我能相信它**。说实话，这排除了很多无聊的业务，但这对我的灵魂有好处。我需要有一样我想每天花数小时沉浸其中的东西。所以我总是鼓励人们深入挖掘，思考你的热情是什么，那件**只有你知道的、你愿意每天花八小时去做、而你身边的朋友却不愿意花八小时去做的事情**，并把它作为你的北极星。

**Greg**：这是很重要的一点：你愿意每天花八小时做的、别人却不愿意的事情。你可能真的很喜欢体育，但很多其他人也喜欢体育，那可能会非常有竞争。我认为如果你在选择一个创业想法或选择一门生意，我总是说：**与细分领域结婚，与产品约会。**

**John**：完全正确。你知道，**Jeff Bezos** 有一句非常相似的话：**“在愿景上固执，在细节上灵活。”**
